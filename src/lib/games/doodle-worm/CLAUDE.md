# らくがきパレード

らくがきパレード（`doodle-worm`）は、描きためた線を「うごけ！」で子にする。
線は指ごとに持つので 2 人で同時に描け、外枠が重なるか近い線どうしを 1 匹にまとめ（`engine.ts` の `groups`）、離れて描いた絵は別々の子になる。
1 匹の中では（`hatch`）いちばん大きな輪が体で、ほかの線は半分以上が体の中なら顔（顔があれば目を足さない）、外なら体の中心から見た向きで足・はね・触角・しっぽ（片側だけに長く伸びた線）になる。
体から離れた線や下へ長く伸びた線（棒人間の胴や足）は振るとつないだ線が外れて見えるので `still` として体といっしょに動かすだけにする。
動き方は手足で決まり、しっぽなら這い、足なら歩き、はねなら飛び、何もなければ跳ねる。
輪のない絵は全体をくねらせて這う。
動かした絵はずかん（`stock.ts`、`asobibako:doodle-worm:stock`）に新しい順で 48 枚まで残り、あふれたら ★（おきにいり）のない古い絵から落とす。
まとまり全体がタップ程度の大きさしかない子（押しそこねた指の跡）は動かすがずかんには入れない（`engine.ts` の `speck`）。
ずかんのシート（共通の `src/lib/components/Sheet.svelte`）から絵を呼ぶ・消す・画面の絵をかたづける・パレード（`parade`。新しい 12 枚が足もとをそろえて 1 列で右へ行進し、右へ抜けた子は列のうしろへ回る）・写真アプリへ保存する（`src/lib/share.ts` の `saveImage`。白地に描き直した大きな絵を共有シートへ渡す）ができ、消すのは「けす」を押しているあいだだけにして押し間違いを防ぐ。
画面に出す自由な子は 12 匹までで、あふれたら古い子から下がるが、パレードの列の子は数えず下げない（`add`）。
画面の子は指をほとんど動かさずに離すと跳ねる（`poke`）。
描きかけの絵のそばでは目などの点を打てるよう、跳ねさせない。
絵柄（ペン・けいと・クレヨン・ネオン・きりがみ）は同じ線の描き方だけを変えるもので、`looks.ts` の `ink()` が 1 本ずつ塗って描き、盤面・ずかんのカード・保存する写真の地も絵柄が決める。
選んだ絵柄は `asobibako:doodle-worm:look` に覚える（好みなのでバックアップの「記録あり」には数えない）。
ずかんのシートからはバトルも開ける。
バトル（`Battle.svelte`）は、ふたりで対戦（上下から 1 体ずつ選び、それぞれの側のボタンを連打する。向かいの子は上下を逆さに立てる）・ひとりで対戦（2 体を選び、相手はコンピュータが応援する）・トーナメント（`rivals.ts` の回戦ごとの組から 1 体ずつ選んだ相手と 3 回戦う）で、戦いは `battle.ts` の `Fight` が自動で進める。
強さは絵の形で少しだけ変わり（大きい体は体力、足は速さ、はねはよける、しっぽは力、頭の上の線は会心）、連打でたまるゲージが当たる強さとひっさつわざを決める。
ひっさつわざは「ため」のあいだ相手が攻撃せず、帯（`CutIn.svelte`）で技の名前を見せる。
ガードは構えてから短いあいだに受けた攻撃を弱め、続けては構えられない。
コンピュータの側は攻撃を受けるたびに決まった確率でガードする。
技の動き（跳ねる子はのしかかり、飛ぶ子は急降下、這う子はしっぽで回り打ち、歩く子は蹴り）とハート・輪などの演出は `arena-draw.ts` にある。
勝った回数と優勝はずかんの絵（`stock.ts` の `wins` と `crown`）に覚え、ずかんと選ぶ画面にしるし（`Medal.svelte`）を出す。

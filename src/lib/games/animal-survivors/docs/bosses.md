# アニマルサバイバーのボスとヌシ

アニマルサバイバーのボス・ヌシ・強化個体・きらきらハリネズミの仕様。全体の決まりとほかの話題の文書の一覧は `src/lib/games/animal-survivors/CLAUDE.md` にある。

火山のボスは溶岩の巨人（地ならしと、自分のまわりへの岩。当たったところに池を残す。予告の `Hazard.lava`）と不死鳥（大ワシと同じく空へ上がって急降下し、それと交互に火の羽根の予告を降らせる。体力が尽きると一度だけ体力半分でよみがえり、そのあいだは当たらない。`bosses-volcano.ts` の `rebirth()` を `damageEnemy` が倒す手前で見る）。
海岸のボスは巨大ガニ（`bosses-coast.ts` の `crab()`。表の体力 900、二つ名は「浜辺の大はさみ」）と大ダコ（`octopus()`。体力 550、二つ名は「渦をまく大足」）で、2:00 と 4:00 に出て 6:00 と 8:00 に攻撃を速めてまた出て、9:00 は「海岸の主」の 2 体になる（時刻と体力の掛け方は `bossRun()` のまま）。
巨大ガニは横に歩いて近づき、3.5 秒（`CRAB.every`）ごとに突進とはさみの地ならしを交互に使う。
突進は横にだけ走り（斜めだと矢印の先を避けにくい）、0.7 秒の矢印の予告のあと 0.9 秒、秒速 210 ドットで走って、その長さは 120 ドット。突進中に体が当たると強さ 32（`CRAB.dashAtk`。ふだんの体当たりは 22）で、巨大ベア・大イノシシの突進の強さの比にそろえてある（`world.ts` の `touch()`）。
はさみは自分の左右 40 ドットに半径 36 の地ならしを 1.2 秒の予告のあと同時に落とし、強さは 24 になる。
大ダコは女王グモと同じ（`queen()`）7 方向の糸の玉（絵は `web`）と手下（クラゲ、`minion`）を出しながら離れて回り、6 秒（`OCTOPUS.every`）ごとに立ち止まって、いま狙っている動物の足もとに半径 40 の墨だまりの予告を出す。
予告は 1 秒で、場所は始めた瞬間の動物の位置なので、動けば外れる。
墨だまりは当たっても傷つかず、5 秒のあいだ浅瀬（`World.shallows` の `ink`）と同じに中の自分の速さを 5 割にし、遺物の渦巻き貝を持つと 7.5 割になる（`tide.ts` の `wadeFactor`）。
墨だまりは満ち潮の浅瀬と同じ 24 個の枠を使い、いっぱいのときは残りの短いものから置き換わる。
予告のあいだに大ダコが倒れると予告ごと消える。
夜の街の下水の大ワニ（`bosses-city.ts` の `gator()`。表の体力 700、二つ名は「マンホールの主」）は巨大ベアの `bear()` をそのまま呼び、突進と地ならしの合間に 5 秒（`GATOR.every`、`rage` で割る）ごとのマンホールもぐりを使う。
もぐりは state 5（1 秒潜る）・6（1 秒の予告）・7（0.4 秒、マンホールから顔を出す）で、5 と 6 のあいだは `airborne()` が true になり、武器も体当たりも当たらず、描かない。
予告の円は半径 36 の地ならし（`slam`）で、予告を始めた瞬間の動物の位置（協力プレイでは近い動物）に置いて動かさず、大ワニはその中心に出てくる。当たるのは円の中の動物だけで、強さは巨大ベアの地ならしと同じ。
もぐりまでの経過秒は `Enemy.phase` に持つ。
巨大カラス（`bosses-city.ts` の `raven()`。表の体力 1400、二つ名は「夜空の見張り番」）の動きは大ワシの `eagle()` そのままで、同じ影の予告・急降下・羽根を使い、急降下 2 回に 1 回、帯「カラスの群れが来る！」を出して 1 秒後に、群れ（`world.ts` の `swarm()`。出来事の群れと同じ帯）としてカラス 8 体を呼ぶ。
待ちの秒は `Enemy.wait` に持ち（`phase` は大ワシの回り込む向きを決める乱数なので触らない）、止まっているあいだは進まず、待ちのあいだに倒されたら群れは出ない。
魔法の森の森の大ジカ（`bosses-grove.ts` の `stag()`。表の体力 1400、二つ名は「月夜の角持ち」）は大イノシシの `boar()` をそのまま呼び、3 回突進した休みが明けたとき、追う代わりに state 6 の角ふりへ入る（残り秒は `Enemy.wait`）。
角ふりは、いま狙っている動物の向きに、自分の位置から長さ 130 の扇を 1 秒予告してから 1 回だけ当てる（強さ 24、`STAG`）。扇は氷の竜の息（`Hazard` の `breath`、`breathe()`）を使い回し、向きは予告を置いたときに決まって動かず、竜と違って遅くしない。終わると `STAG.every`（`rage` で割る）の間をおいて追いはじめる。
突進中の体当たりの強さは大イノシシと同じ 34（`STAG.dashAtk`）。
ボスは敵の表の `ai`（巨大ベア型の突進と地ならし、女王グモ型の飛び道具と手下、雪山の大雪男と氷の竜、1 面の大イノシシ・大ワシ・大木のおばけ・大ヘビ、海岸の巨大ガニと大ダコ、夜の街の下水の大ワニと巨大カラス。この 2 体の動きは `bosses-city.ts`）で動き方を選び、手下（`minion`）と飛び道具の絵（`shot`）も表に持つので、墓地のかぼちゃ大王とガイコツの騎士は今の動きを使い回す。
ボスは墓地・雪山・火山・海岸では 2:00 と 4:00 に面の 2 体が出て、6:00 と 8:00 に同じ 2 体が攻撃の間を短くして（`rage`）また出る（`stages/forest.ts` の `bossRun()` が作る `bosses`、3 秒前に WARNING）。
1 面だけは 6 体が順に出る（2:00 巨大ベア・4:00 女王グモ・6:00 大イノシシ・8:00 大ワシ、面の主は大木のおばけと大ヘビ）。
1 面の新しい 4 体の動きは `bosses-forest.ts` で、絵は `art/bosses-forest.ts`（今のボスより大きい）。
大イノシシは予告の矢印のあと画面を端から端まで 3 回続けて突進して休み、通ったあとに中で遅くなる土ぼこり（`Hazard` の `mud`）を残す。
大ワシは影の予告を出して空へ上がり（`airborne()`、そのあいだは当たらない）、予告の場所へ急降下して羽根（`feather`）を 8 方向にばらまく。
大木のおばけはゆっくり近づき、自分の近くに根っこ（`root`）を生やし、2 回に 1 回おばけの手下を出す。
大ヘビの体の節は敵の表の `part`（`snakeSeg`）で、敵の入れ物に入れて武器が狙えるようにし、頭が通った道（`Enemy.trail`）の上に並ぶ。
節に当たった分は頭の体力を減らし（範囲の一撃が頭と節にまとめて当たっても 1 回、`Enemy.bitten`）、節は倒れず、押し合い・遠くの敵の置き直し・十字架・枠の使い回し・倒した数・図鑑から外す。
頭を倒すと節も消える。
今の `Enemy` に攻撃の状態を足したもの。
2:00〜8:00 のボスと面の主が出ると（延長戦のボスでは出さない）、World の `bossIntro` を `Prompts.intro` が受けてゲームを 2.4 秒止め（`busy`。3 択・宝箱・一時停止も待たせ、時間は端末の dt で進める）、`Prompts.focus()` が返す寄る先へ `draw()` がカメラを動かし（0.6 秒で寄り、1.8 秒から戻る）、足もとの土ぼこりの輪と画面の縁の赤い光（`draw-boss.ts` の `introDust`・`introEdge`）、地響きの音、二つ名（敵の表の `epithet`）と名前の札（`BossIntro.svelte`）を出す。
面の主の 2 体は同じ場所の左右に並べて出し（`bosses.ts` の `PAIR_GAP`）、カメラは 2 体のあいだへ寄り、札は「森の主」などの `title` と 2 体の名前を 2 行に出す。
登場のあいだも移動の指は置ける。
画面は揺らさない。
動きを減らす設定ではカメラを動かさず、札だけを 1.2 秒出す。
ヌシが出るとゲームは止めず、王冠の上にきらめきを散らし、大きな帯（「ヌシ出現！」、`Prompts.chief`）を出し、画面の外にいるあいだは画面の端に王冠つきの矢印（`draw-events.ts` の `chiefArrows`。宝の地図の矢印と描き方を共用）を出す。
動き方と攻撃は `bosses.ts`（雪山の 2 体は `bosses-snow.ts`）にあり、予告（地ならしの輪・突進の矢印・飛びかかりの円・氷の柱の円・息の扇）と飛び道具（糸の玉・転がるほど大きくなる雪玉）は `World.hazards` に置いて、予告が終わってから当たる。
大雪男は雪玉と飛びかかりを交互に使い、飛びかかりは自分のいた位置に 1 秒予告してから落ちて、ちび雪だるまを 3 匹出す。
宙にいるあいだ（`airborne()`）は武器も体当たりも当たらない。
氷の竜は離れて回り込み、自分のまわり 5 か所の氷の柱と、正面の扇の冷たい息（当たると遅くなる）を交互に使う。
予告は持ち主が倒れたら消え、息は持ち主の竜の番号で見る。
ボスは吹き飛ばされず、押し合いでも押されない。
体力は表の値に、その行の `hp`（2:00 は 0.6、4:00 は墓地・雪山・火山・海岸が 0.6・1 面が 0.8）と、出る時刻の `toughness` を 1.2 倍にしたもの（`bosses.ts` の `BOSS_HP`）を掛ける（後半のボスが一瞬で溶けないように、遅く出るほど硬い）。
倒すと赤い玉と宝箱を落とし、宝箱は吸い寄せずに歩いて拾う。
強化個体は 2:40 から出る敵の 2% で、`eliteOf()` が表を写して強くし、`bake()` の金色の版を 2 倍で描く。
1:00・3:00・5:00・7:00 には面の表の `chiefs` のヌシ（`chiefOf()` がふつうの敵を 3 倍の大きさにし、王冠を頭のいちばん上に載せて描く。体力は表の値、経験値 20 倍、押されず十字架で消えず、倒すと宝箱）が出る。
9:00 は面の主で、その面の 2 体のボスが攻撃を速めていっしょに出る（墓地・雪山・火山・海岸は体力 1.5 倍、1 面の新しい 2 体は表の体力のまま。`bossRun()` の最後の 2 行。同じ時刻の行は WARNING を 1 回だけ出し、名前は行の `title` の「森の主」「墓地の主」「雪山の主」「火山の主」「海岸の主」）。
3 割の回には 2〜8 分のどこかにきらきらハリネズミ（敵の表の `metal`）が 1 匹出る。
出るかと時刻は別の乱数で決め（`World.metalAt`。同じ種の回の流れを変えない）、どんな攻撃でも 1 しか減らず（十字架も 1）、逃げて、ゲームの時間で 20 秒たつと去る。
倒すと大きな経験値の玉とコインの大袋 2 つを落とし、実績になる。

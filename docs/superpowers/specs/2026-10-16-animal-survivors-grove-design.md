# Animal Survivors 魔法の森 設計

## ねらい

夜の街をクリアしたあとに向かう 7 つめのステージ「魔法の森」と、魔法の森をクリアすると仲間になる 13 匹めの動物「ユニコーン」を足す。
海岸・夜の街・魔法の森の 3 面を順に足す計画の 3 面めで、作り方は夜の街（`docs/superpowers/specs/2026-10-15-animal-survivors-city-design.md`）と同じにする。

魔法の森の仕掛けは「妖精の輪」で、今の 6 面の仕掛け（吹雪・噴火・満ち潮・停電）がどれも邪魔をするものだったのに対し、自分から取りに行くと得をする。
ただし魔力をためるあいだは輪の中に閉じ込められるので、囲まれる危なさと引き換えになる。

遊ぶのは大人 2 人と子ども、端末は iPad Air。

## 1. ステージ

- 夜の街をクリアすると開く（`after: 'city'`）。id は `grove`、名前は「魔法の森」、9:00 の 2 体は「魔法の森の主」。
- 時刻の流れは森の表を写す（10 分、ボス・ヌシ・出来事の時刻は同じ）。敵の硬さと攻撃は森の 1.5 倍（ボットで決めた。11 章）。同時に出る数の上限は森の 1.2 倍、コインの倍率は 4。
- 敵の 7 種は森の 7 種と同じ動き方で、見た目と名前を魔法の森の顔ぶれにする（`SWAP`）。

| 森       | 魔法の森       | id           |
| -------- | -------------- | ------------ |
| ネズミ   | キノコぼうや   | `shroomling` |
| コウモリ | いたずら妖精   | `pixie`      |
| ヘビ     | ツタヘビ       | `vineSnake`  |
| イモムシ | 宝石カタツムリ | `gemSnail`   |
| イノシシ | イバライノシシ | `thornBoar`  |
| クモ     | 跳ねガエル     | `hopFrog`    |
| ワニ     | 切り株おばけ   | `stumpGhost` |

- ヌシも同じ入れ替えで出す（体力は硬さの倍率と同じだけ上げる）。
- 出来事は森の表のまま、敵の名前だけ入れ替える。
- 地面は苔と花、飾りは小さなキノコ・花・木の根・光る粒。障害物は「大きな光るキノコ」（`shroom`）と「魔法の石の柱」（`runestone`）の 2 種で、今の面と同じく 160 ドットの区画におよそ 4 つに 1 つ、位置のハッシュで置く。

## 2. 妖精の輪

- 吹雪・噴火・満ち潮・停電と同じ時刻（95・215・335・455 秒）に、輪が 1 つ現れる。現れたときに帯「妖精の輪が現れた！」を出す。
- 輪は半径 30 ドットで、倒れていない動物のどれかから 60〜120 ドット先の、障害物にかからない場所に置く（協力プレイでは置く相手を順に回す）。20 秒で消える。
- 輪が画面の外にあるあいだは、画面の端に輪の矢印を出す（宝の地図の矢印と同じ描き方）。
- 動物が輪に入ると魔力をため始める。ためるのは 3 秒で、そのあいだ輪の中にいる動物は輪の外へ出られない（輪の中は歩ける）。
- 魔力が満ちると、輪のまわりの画面の大きさの範囲で、ふつうの敵（群れも）がまとめて倒れ、ヌシとボスは最大 HP の 1 割を受ける。ランタンは壊さない。倒した数は `fairyKills` に数える。
- 満ちた輪はそこで消える。1 つの輪で満たせるのは 1 回だけ。協力プレイではどちらの動物が入っても始まり、輪の中にいる動物はどちらも閉じ込める。
- 輪の時計とためる時計は step の中で進めるので、3 択・一時停止・時計の品のあいだは止まる。
- ためているあいだは輪が下から光で満ちていき、満ちた瞬間に白い光が広がる。動きを減らす設定では光の広がりを出さない。

## 3. ボス

どちらも今のボスと同じくらいの大きさ（40 ドット前後）で、動き方は `bosses-grove.ts` に置く。今の動き方（`ai`）を使い回し、技を 1 つずつ足す。

- 魔女（女王グモ型、id `witch`）
  - 魔法の弾と、いたずら妖精の手下を出す（今の女王グモの飛び道具と手下）。
  - 足す技は「魔法陣」。自分のいちばん近い動物のまわりに予告の円を 3 つ、0.4 秒ずつずらして置き、それぞれ予告のあと円の中に当たる。円の場所は置いたときに決まり、動物を追わない。
- 森の大ジカ（大イノシシ型、id `stag`）
  - 予告の矢印のあと、画面を端から端まで 3 回続けて突進する（今の大イノシシ）。
  - 足す技は「角ふり」。立ち止まって、いちばん近い動物の向きに扇の予告を 1 秒出し、そのあと扇の中に当たる（竜の息の扇の形。遅くはしない）。
- 2:00 と 4:00 に 2 体が出て、6:00 と 8:00 に攻撃を速めてまた出る（`bossRun()`）。9:00 は面の主として 2 体いっしょに出る。

## 4. 動物「ユニコーン」

- 強さの段は最強（★4）。魔法の森をクリアすると仲間になる（実績「魔法の森をクリア」に付ける）。id は `unicorn`。
- 名前は 3 段階で「子どものユニコーン」「虹のユニコーン」「星のユニコーン」。
- とくい（`bonus`）は移動の速さ +10%。
- 最初の武器は専用の「虹のビーム」（id `rainbowBeam`、`exclusive`、ほかの動物の 3 択には出ない）。
  - 新しい動き方 `beam`。いちばん近い敵の向きへ、長さ 120 ドット（範囲で伸びる）・太さ 8 ドットの光の線を一瞬出し、線にかかる敵にまとめて 1 回ずつ当たる。線は 0.25 秒で消える絵で、当たりは出た瞬間だけ。
  - 狙うのは画面の中の敵だけで、空にいるボスやもぐっているボスは狙わない。
  - 本数は Lv1 で 1 本、Lv5 で 3 本（近い順に別の敵の向きへ）。
- 専用進化形は「虹の大砲」（id `rainbowBeamSp`）。線の太さが 2 倍になり、画面の端まで伸びる。強さは今の最強の段と同じく、同じ型のふつうの進化形のおよそ 1.5 倍に合わせる。
- 絵は 16・20・24 ドットの 3 段階（今の動物と同じ）。白い体にパステルのたてがみと金の角。

## 5. 遺物・曲・キャラ選択

- 遺物を 2 つ足す（今の遺物と同じく、始めの位置から 700 と 1500 ドットほどの決まった場所に置く）。
  - 妖精の粉（`dust`、700 ドット）を持っていると、妖精の輪で魔力がたまる時間が 3 秒から 2 秒になる。
  - 月のしずく（`moon`、1500 ドット）を持っていると、魔力が満ちたとき、倒れていない動物の HP が最大 HP の 3 割回復する。
- 曲は魔法の森の 1 曲を `songs.ts` に足す（ふしぎで明るい曲）。ボス戦は今のボスの曲。
- キャラ選択の顔のタイルは 13 匹になる。今の 5 列 × 3 段のまま（5・5・3）収まる。

## 6. 記録と実績

- ステージの記録・図鑑・延長戦・釜・アルカナ・今日のお題は、今のしくみのまま魔法の森でも効く。
- 実績を 3 つ足す。「魔法の森をクリア」（`groveClear`、ユニコーン）、「魔女と森の大ジカを倒す」（`groveBosses`）、「妖精の輪で敵を 500 体倒す」（`fairy500`、記録の `fairyKills`。夜の街の `blackoutKills` と同じ通り道）。
- 図鑑には敵 7 種・ボス 2 体・ユニコーンの姿 3 つ・遺物 2 つが加わる（表に足せば載る）。

## 7. 協力プレイ

- 輪の場所・残りの時間・ためている秒を様子（`snap.ts`）に載せる。子の端末は届いた輪で、ためているあいだ自分の動物を輪の中に留める（子の動きは子の端末で計算するので、留め方は親と同じ関数を使う）。
- 魔力が満ちたときの敵の倒れ方は親が決め、様子で届く。白い光は両方の端末で出す。
- 知らせの形が変わるので `COOP_VERSION` を 7 から 8 に上げる。

## 8. 確かめ方

- vitest で確かめる。
  - 魔法の森の表（敵とボスが表にある・時刻が森と同じ・強さ）。
  - 妖精の輪の時刻と帯・置く場所（障害物を避ける・動物から 60〜120 ドット）・20 秒で消える・入るとためはじめ 3 秒で満ちる・ためるあいだ出られない・満ちるとふつうの敵が倒れてヌシとボスは 1 割・ランタンは残る・1 回だけ・止まっているあいだは進まない・妖精の粉と月のしずく。
  - 魔女の魔法陣（3 つの円が時間差・置いた場所に当たる）、森の大ジカの角ふり（扇の中だけに当たる）。
  - 虹のビーム（線にかかる敵だけに当たる・1 回だけ・本数・空のボスを狙わない）と専用進化形。
  - 実績、遺物、協力プレイの様子に輪が載り、子の動物も輪から出られないこと。
- ボットで、犬・キツネ・パンダを遊ばせ、クリアの割合と 1 回のコインを測る。夜の街と同じボット（輪が出ていて予告が無いときは輪へ向かう動きを足したもの）で、夜の街より少し低いクリアの割合（店半分）に硬さの倍率を合わせる。店半分は種 1〜96 の 96 回ずつ、店全部は種 1〜24 の 24 回ずつ。ユニコーンは竜の子・火の鳥のひな・ラッコ・アライグマと、森と魔法の森の店なしと店半分で、種 1〜72 の 72 回ずつ比べる。結果は 11 章に書く。
- `pnpm verify` を通し、headless の Chrome で妖精の輪・ボス・ユニコーンを撮る。

## 9. 絵の進め方

- 新しく描くもの。敵 7 種（16 ドット、2 コマ）、ボス 2 体と魔女の魔法の弾、地面と飾り（苔・花・小さなキノコ・木の根・光る粒）、障害物 2 種、妖精の輪（キノコの輪）、ユニコーンの 3 段階、虹のビームと虹の大砲のアイコン、遺物 2 つ。
- 絵は使う前に見本を見せて決める。敵・ボス・地面とユニコーンを 1 回にまとめて見せる。

## 11. 調整の結果

ボットで魔法の森とユニコーンを測り、硬さの倍率とユニコーンの虹のビームの数を直した。ボットは夜の街のときと同じ（`animal-survivors` の世界を 30fps で 10 分進め、敵・予告・飛び道具・突進の線に当たりにくい向きを選び、安全なときだけ経験値の玉へ寄る）で、輪の動きを足してある。輪が出ていて、自分から 200 ドット以内に予告の円や突進の線が無く、130 ドット以内にボスもいないときは、輪の中心へ寄る。ためはじめたあとは、予告があっても輪の中心へ寄る動きを続ける（閉じ込められて出られない）。

店の段は、半分は各品の最大の段の半分（切り上げ。復活と数は 1 段）、全部は最大の段。測った動物は犬・キツネ・パンダ。

| 夜の街          | 半分 | 288  | 58/96 | 46/96  | 72/96  | 176/288 | 61%          | 545                | 8505         |
| 魔法の森（1.5） | 半分 | 288  | 41/96 | 39/96  | 81/96  | 161/288 | 56%          | 517                | 7049         |

### ユニコーンとほかの最強の動物

種 1〜72 の 72 回ずつ（36 回ずつを 2 組）。動物はユニコーン・竜の子・火の鳥のひな・ラッコ・アライグマ。かっこの中は平均の生き延びた秒、1 回のコインの平均の順。魔法の森は硬さ 1.5。

| 面       | 店   | ユニコーン         | 竜の子             | 火の鳥のひな       | ラッコ              | アライグマ         |
| -------- | ---- | ------------------ | ------------------ | ------------------ | ------------------- | ------------------ |
| 森       | なし | 35/72（514、1522） | 41/72（533、1831） | 33/72（516、1553） | 40/72（525、1819）  | 39/72（500、1831） |
| 森       | 半分 | 72/72（600、3794） | 71/72（599、3734） | 71/72（599、3594） | 71/72（600、3802）  | 71/72（600、3883） |

ユニコーンのクリアの数と生き延びた秒は、森の店半分のクリア（72 で、ほかの最大 71 より 1 多い）を除いて、4 つの面と店の組のどれでも、ほかの 4 匹の範囲に入る。魔法の森の店半分のクリアは 55 で、ラッコと並んで最も少ない。1 回のコインは、森の店なしで 1522（ほかは 1553〜1831）、魔法の森の店半分で 9279（ほかは 9306〜10109）と、ほかの 4 匹の最小よりそれぞれ 31 と 27 だけ少ない。ほかの 2 つの組では範囲に入る。

### 変えた値と変えなかった値

変えたのは次の 4 つで、魔女と森の大ジカの体力と攻撃、妖精の輪の数（半径・ためる秒・ボスへの割合）、ユニコーンの体力・速さ・力、虹のビームの長さと太さは変えていない。

| 値                                       | 今の値 |
| ---------------------------------------- | ------ |
| `HARDER`（`stages/grove.ts`）            | 1.5    |
| 虹のビームの威力（`rainbowBeam` の Lv1） | 24     |
| 虹のビームの間隔（`rainbowBeam` の Lv1） | 1.1 秒 |
| 虹の大砲の間隔（`rainbowBeamSp`）        | 0.9 秒 |

硬さの倍率は、夜の街の店半分（61%）より少し低い、9 割ほどのクリアの割合に合わせた。1.5 は 56% でちょうどその位置になり、1.45 は 58% で夜の街に近すぎ、1.55 は 51% で 8 割ほどまで下がる。倍率を上げるほど単調に下がり、1.65 では夜の街の 7 割ほどになる。回ごとのばらつきが大きいため、種 1〜48 と 49〜96 を足した 288 回で選んだ（48 回ずつだけだと 1.5〜1.65 の並びが入れ替わって見えた）。ボスの体力は硬さの倍率に掛かるので、魔女と森の大ジカの数は触らずにこの 1 つで合わせた。

輪の数は触らなかった。輪へ向かうボットは向かわないボットより 7 ポイント高く、倒した敵は 1 回に 21 体から 63 体に増える。輪は使うと得をするが、クリアの割合を大きく動かすほどではなく、使えなくてもクリアが大きく落ちるわけではない。役に立たない、または効きすぎる証拠は出なかった。

虹のビームは、最初の値（威力 20・間隔 1.4 秒）では、森の店なしで 22/72、魔法の森の店半分で 47/72 と、ほかの範囲（33〜41 と 55〜59）の下に出た。威力だけを 24 や 28 に上げても森の店なしは 25/72 と 22/72 のままで、間隔だけを 1.0 秒に縮めると 28/72 まで上がった。威力より撃つ回数のほうが効いたので、間隔を 1.1 秒に縮めて威力を 24 に上げた。種 1〜144 で、威力 22・間隔 1.2 秒は森の店なし 61/144・魔法の森の店半分 105/144、威力 24・間隔 1.1 秒は 73/144 と 106/144、威力 24・間隔 1.0 秒は 61/144 と 101/144、威力 26・間隔 1.1 秒は 68/144 と 90/144 で、差は回ごとのばらつきの中に収まる組が多かった。威力 24・間隔 1.1 秒を選んだのは、森の店なしがほかの範囲の中ほどになったため。

虹の大砲の間隔は、1.1 秒から 0.9 秒に縮めた。ビームだけを直した状態では、魔法の森の店半分が 53/72 とほかの範囲（55〜59）の少し下だった。大砲の威力を 46 や 50 に上げる案は魔法の森の店半分で 107/144 と 111/144、間隔を 0.9 秒に縮める案は 113/144 で（ビームだけの状態は 106/144、ほかの動物は 110〜118/144 に相当）、間隔のほうがよく効いた。竜王の業火が 0.9 秒の間隔で扇を 3 つ吐くのと同じ間隔で、大砲の 3 本もそろう。

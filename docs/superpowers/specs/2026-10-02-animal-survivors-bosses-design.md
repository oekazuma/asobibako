# Animal Survivors ボス 設計

## ねらい

Animal Survivors に、5 分の巨大ベアと 10 分の女王グモの 2 体のボスを足す。大群をなぎ倒す流れの中に、予告を見てよける山場と、倒したときの宝箱のごほうびを入れる。15 分の最後のラッシュとクリアの条件は今のまま。

## 決めたこと

| 問い         | 決めたこと                                                                   |
| ------------ | ---------------------------------------------------------------------------- |
| ボスの数     | 2 体。5:00 に巨大ベア、10:00 に女王グモ                                      |
| 作り方       | ボスは今の `Enemy` に状態を足したもの。攻撃の型と予告は `bosses.ts` に分ける |
| 倒しきれない | 次のボスが来たら 2 体とも残る。15:00 のクリアで全部倒れる                    |
| ごほうび     | 赤い玉 10 個と宝箱 1 つ。宝箱は持っているものを 1・3・5 つ上げる             |
| 絵           | 巨大ベア・女王グモ・子グモ・糸の玉を描き、作る前に見本を見せる               |

## 1. 出かた

- 出る 3 秒前（4:57 と 9:57）に、画面の上へ赤い帯で「WARNING!」とボスの名前（「巨大ベアが出現！」）を 3 秒出し、警告の音を鳴らす。
- 決めた時刻に、ボスを画面の外の輪の上（`spawnPoint`）に置く。
- ボスがいるあいだは、HUD の HP の棒の下にボスの HP の棒（`BOSS` の字と残りの割合）を出す。2 体いるときは 2 本並べる。
- ボスは吹き飛ばされない（`heavy: 1`）。遠く離れたときは、ふつうの敵と同じく進む先の画面の外へ回り込む。
- ほかの敵との押し合いでは、ボスは押されず、相手だけを押し返す。

## 2. 巨大ベア（5 分）

| 項目   | 値                               |
| ------ | -------------------------------- |
| HP     | 700（`toughness` は掛けない）    |
| 当たり | 半径 15。触れたら 20 のダメージ  |
| 速さ   | 28 px/秒で追う                   |
| 攻撃   | 4 秒ごとに突進か地ならしを交互に |

- 突進。0.7 秒、自分への向きを覚えて止まり、その向きに床の赤い矢印（長さ 120）で予告する。予告が終わると 210 px/秒で 0.9 秒走る。走っているあいだに触れると 30 のダメージ。
- 地ならし。1 秒、ボスの足もとに半径 0 から 56 まで広がる赤い輪で予告する（ボスは止まる）。終わると輪の中に 28 のダメージを与え、外へ広がる衝撃波を見せる。
- 地ならしの予告のあいだは地ならしのコマ（両手を上げた形）を見せる。

## 3. 女王グモ（10 分）

| 項目   | 値                                                   |
| ------ | ---------------------------------------------------- |
| HP     | 900                                                  |
| 当たり | 半径 16。触れたら 25 のダメージ                      |
| 動き   | 自分から 110 px ほどを保ち、横へ回り込む（38 px/秒） |

- 糸の玉。3 秒ごとに、自分のいる向きを真ん中に 5 発を 15° ずつ広げて飛ばす（90 px/秒、3 秒で消える、半径 4）。当たると 6 のダメージと、1 秒間の足の遅さ（速さ 0.85 倍）。
- 子グモ。8 秒ごとに、女王グモの周りに子グモを 4 匹生む。子グモは新しい敵の種類で、HP 8・速さ 50・攻撃 6・半径 4・経験値 1・追う動き。敵の数の上限に数える。

## 4. 倒したとき

- 画面全体が 0.25 秒白く光り、大きな破裂と粒を出し、ファンファーレを鳴らす。
- 経験値 25 の赤い玉を、倒れた所の周り（半径 24）に 10 個ばらまく。
- 宝箱を 1 つ落とす。宝箱は吸い寄せる範囲と磁石で寄ってこず、自分で取りに行く。

## 5. 宝箱

- 拾うと `World.chests` が 1 増え、3 択と同じく `step` が止まる。宝箱と 3 択が重なったら、宝箱を先に開ける。
- 開けると、上がる数を 1（6 割）・3（3 割）・5（1 割）から決め、持っている武器とパッシブのうち Lv5 未満のものからでたらめに選んで 1 Lv ずつ上げる（同じものが何度選ばれてもよく、Lv5 で打ち止め）。上げられるものが無くなったら、残りは肉（HP を 30% 回復）と経験値の袋（+25）に置き換える。
- 画面では、ふたが開く演出のあと、上がったものをアイコン・名前・新しい Lv で 1 つずつ並べて見せ、「OK」で再開する。出た直後の誤タップは 3 択と同じ `Lock` で防ぐ。

## 6. しくみ

### ルール（DOM を使わない）

| ファイル           | 持つもの                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `bosses.ts`        | ボスの表（名前・HP・半径・攻撃力・速さ）と、ボスごとの動き方。攻撃の予告と飛び道具を作る |
| `chest.ts`         | `openChest(w)`。上がる数を決めて当て、上がったものの一覧を返す                           |
| `stages/forest.ts` | `bosses: [{ at: 300, id: 'bear' }, { at: 600, id: 'spiderQueen' }]`                      |
| `enemies.ts`       | 子グモ（`spiderling`）と、ボスの絵と当たりのための項目                                   |

- ボスは `Enemy` に `boss` の状態（攻撃までの時間・いまの攻撃・突進の向き）を足したもの。`moveEnemy` はボスなら `bosses.ts` の動き方を呼ぶ。
- 予告と飛び道具は `World.hazards` に置く。種類は `slam`（広がる輪）・`dash`（突進の矢印）・`web`（糸の玉）で、予告の残り時間・位置・速さ・半径・ダメージを持ち、プールで使い回す。予告が終わってから当たる。
- 自分は `slow`（遅くなる残り時間）を持ち、移動の速さに 0.85 を掛ける。
- 出来事に `warning`（ボスの id）・`bossdown`・`chest` を足す。

### 画面

- `draw-boss.ts` がボス・予告・飛び道具・ボスの HP の棒を描く（`draw.ts` は 270 行あるので分ける）。
- `BossWarning.svelte` が「WARNING!」の帯（日本語の名前があるので HTML）。`ChestOpen.svelte` が宝箱を開ける画面（`retro.css` の枠）。
- `Play.svelte` は 2 つを重ねるだけにして、200 行未満を保つ。

## 7. 確かめ方

- vitest で次を確かめる。
  - 300 秒と 600 秒にボスが出て、その 3 秒前に `warning` が出る。
  - 突進と地ならしは、予告のあいだは当たらず、予告が終わってから当たる。
  - 糸の玉で遅くなり、2 秒で戻る。
  - 子グモが 6 秒ごとに生まれる。
  - ボスを倒すと宝箱と赤い玉 10 個が落ちる。
  - 宝箱は Lv5 を超えて上げない。上げるものが無いときは肉と袋になる。
  - 宝箱と 3 択が重なったら、宝箱が先に開く。
- 前回のボット（scratchpad の `sim/survivors.sim.ts`）で、ボスを倒すまでの時間と生存時間を測り、HP と攻撃の強さを合わせる。目安は、ふつうに強くなっていれば 1 分前後で倒せること。
- headless Chrome で、WARNING・2 体の攻撃・宝箱の画面を撮って確かめる。ボスと子グモがいる場面の重さも測る。
- `pnpm verify` を通す。

## 8. 調整の結果

ボット（敵から逃げつつ近い玉を拾い、予告の輪から出る）で、巨大ベアは出てから 75〜110 秒で倒れた。女王グモは、距離を取って回り込むぶん近くの敵ばかり撃たれて削れにくく、HP 900 でも倒せた回は 90〜180 秒だった。女王グモが出たあとに倒れる回が多く、生存時間の中央値は 10〜12 分。ボットはボスから大きく逃げて玉を拾いそびれるので、最後は実機の手ざわりで直す。

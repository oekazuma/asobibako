# Animal Survivors 装備とガチャ 設計

## ねらい

遊んだ回の外に残る、ローグライクの装備を足す。装備はガチャで手に入れ、ガチャの券は遊んでいる回の中で拾う。釜が高いほど良い券が落ち、倒れると拾った券を失うので、釜の賭けと同じリスクとリターンになる。コインでも引けるので、店を買い切ったあとのコインの使い道にもなる。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い       | 決めたこと                                                                         |
| ---------- | ---------------------------------------------------------------------------------- |
| 手に入れ方 | 回の中でガチャ券を拾い、クリアで持ち帰る（倒れたら失う）。コインでも引ける         |
| つける数   | あたま・からだ・おまもりの 3 か所に 1 つずつ。10 匹で共通                          |
| 中身       | 名前つきの品 18 種 × レア度 3 段（ふつう・レア・伝説）。レア以上は特別な効き目つき |
| 強さ       | 伝説 3 つで店のおよそ半分の上乗せ                                                  |
| 持ち物     | 40 個まで。同じ品・同じレア度 3 つで 1 段上へ合成、いらないものはコインに換える    |
| 見た目     | 12 ドットのアイコンだけ（キャラの絵は変えない）。レア度は枠の色                    |
| 今日のお題 | 店と同じ扱い。しばり「店の強化なし」の日は装備も外す                               |

## 1. ガチャ券

- 券は 3 種類で、出る品のレア度の割合が違う。

| 券     | ふつう | レア | 伝説 |
| ------ | ------ | ---- | ---- |
| 銅の券 | 80%    | 17%  | 3%   |
| 銀の券 | 0%     | 85%  | 15%  |
| 金の券 | 0%     | 50%  | 50%  |

- 9:00 のステージの主は毎回 1 枚、2:00〜8:00 のボスとヌシは 1/4 で券を落とす。クリア 1 回でおよそ 3 枚になる。
- 落ちた券は宝箱と同じく吸い寄せず、歩いて拾う。拾うと帯「銀の券を拾った！」を出す。
- どの券になるかは釜の強さで決める。2.0 以下は銅だけ、9.0 で銅 30%・銀 50%・金 20%。そのあいだは直線でつなぐ。
- 拾った券は 10:00 のクリアで持ち帰る。倒れたとき、一時停止の「やめる」「最初からやり直す」では失う。延長戦で拾った券は、引き上げれば持ち帰り、倒れると失う。
- リザルトに、持ち帰った券と、持ち帰れなかった券（線で消して）を出す。
- お題の回は釜 2.0 として銅の券が落ちる。

## 2. ガチャ

- キャラ選択の下の段に「装備」を足し、装備の画面からガチャを開く。
- 引き方は 4 つ。券は種類ごとに 1 枚ずつ使う。

| 引き方         | 払うもの    | 中身                                     |
| -------------- | ----------- | ---------------------------------------- |
| 銅の券で引く   | 銅の券 1 枚 | 銅の券の割合で 1 つ                      |
| 銀の券で引く   | 銀の券 1 枚 | 銀の券の割合で 1 つ                      |
| 金の券で引く   | 金の券 1 枚 | 金の券の割合で 1 つ                      |
| コインで引く   | 500 枚      | 銅の券の割合で 1 つ                      |
| コインで 10 連 | 4500 枚     | 銅の券の割合で 10 こ。1 つ以上はレア以上 |

- 天井は 50 回。どの引き方でも、伝説が出ないまま 50 回引くと、次の 1 回は伝説になる。伝説が出たら数え直す。数えた回数は記録に残し、ガチャの画面に「伝説まであと N 回」を出す。
- 品はレア度を決めてから、18 種から同じ割合で選ぶ。
- 引くとカプセルが落ちてきて割れ、光の色（白・青・金）でレア度を見せてから品を出す。10 連は 10 こを並べて順に割る。動きを減らす設定では割れる動きを省き、品を並べて出す。
- 持ち物が 40 個を越える分は引けない（引く前に「持ち物がいっぱい」と出す）。

## 3. 品

- つける場所ごとに 6 種。どの品も能力を 1 つ上げ、レア以上は特別な効き目を持つ。
- 能力の量は、伝説が店のその品の最大の半分。レアは伝説の 0.65 倍、ふつうは 0.4 倍。特別な効き目は、伝説がレアの 2 倍。

| 場所     | 品             | 上がる能力 | 特別な効き目（レア／伝説）                   |
| -------- | -------------- | ---------- | -------------------------------------------- |
| あたま   | 勇者のハチマキ | 攻撃       | ボスとヌシへの攻撃 +15%／+30%                |
| あたま   | 鷹のゴーグル   | 会心       | 会心のダメージ +25%／+50%                    |
| あたま   | 麦わら帽子     | 攻撃の範囲 | 経験値の玉を拾う範囲 +20%／+40%              |
| あたま   | とんがり帽子   | 効く時間   | 3 択が 4 択になる割合 +10%／+20%             |
| あたま   | 鬼のツノ       | 攻撃       | HP が半分より下のあいだ攻撃 +15%／+30%       |
| あたま   | 花の冠         | 運         | ランタンから十字架・時計・金の磁石が出やすい |
| からだ   | 騎士のよろい   | 防御       | ボスとヌシから受けるダメージ −15%／−30%      |
| からだ   | 毛糸のマフラー | 最大 HP    | 吹雪で流される量 −50%／−100%                 |
| からだ   | 耐火のマント   | 最大 HP    | 溶岩の池のダメージ −50%／−100%               |
| からだ   | 風のスカーフ   | 速さ       | 当たったあとの無敵 +0.3 秒／+0.6 秒          |
| からだ   | 葉っぱの服     | 回復       | 肉で戻る HP +50%／+100%                      |
| からだ   | 甲羅           | 防御       | 遠くから飛んでくる攻撃のダメージ −25%／−50%  |
| おまもり | 招き猫         | コイン     | 金の磁石が出る割合 2 倍／3 倍                |
| おまもり | 四つ葉のお守り | 運         | 宝箱の中身が 3 つ以上になる割合 +10%／+20%   |
| おまもり | 知恵のふくろう | 経験値     | 育つ Lv が 1／2 早い                         |
| おまもり | 磁石の首飾り   | 拾う範囲   | ランタンから磁石が出る割合 2 倍／3 倍        |
| おまもり | 砂時計         | 効く時間   | 時計の品で止まる時間 +3 秒／+6 秒            |
| おまもり | 不死鳥の羽根   | 回復       | 倒れたとき 1 回だけ HP 25%／50% で起き上がる |

- 不死鳥の羽根の起き上がりは、店の復活とひなのよみがえりのあとに使う。
- 品の名前・能力・効き目は表 1 つ（`gear.ts`）に持ち、1 行足せば加わる。
- 能力は `World.boost` に足すので、パッシブや育ちで能力を作り直しても残る。

## 4. 持ち物と装備の画面

- 持ち物は品とレア度の組ごとの数で持ち、合わせて 40 個まで。
- 装備の画面は、上に 3 か所の枠（つけている品）、真ん中にガチャ、下に持ち物の格子を置く。格子は場所ごとに並べ、同じ組は 1 マスに数を出す。
- 品を押すと詳しい札を出し、「つける」「合成」「売る」を選ぶ。合成は同じ組が 3 つあるときだけ押せ、伝説は合成できない。
- 売ると、ふつう 50・レア 200・伝説 800 枚のコインになる。つけている品の最後の 1 つを売ると、その場所は空く。
- キャラ選択の詳しい札（`AnimalCard.svelte`）の下に、つけている 3 つのアイコンを小さく出す。
- 一時停止とリザルトに、つけている装備を出す。

## 5. ほかのしくみとの関係

- 店の能力・パッシブ・札（アルカナ）・育ちと足し合わせる。
- お題のしばり「店の強化なし」の日は装備も効かない。ほかの日はつけたまま遊ぶ。
- 延長戦にも効く。
- バックアップと自動の控えは `asobibako:animal-survivors` の記録に入るので、そのまま写る。

## 6. しくみ

| ファイル                 | 変えること                                                                     |
| ------------------------ | ------------------------------------------------------------------------------ |
| `gear.ts`（新しい）      | 品の表・レア度の量・券の割合・天井・合成・売る・つけた品から能力と効き目を出す |
| `records.ts`             | 持ち物・つけている品・券・天井までの回数。クリアと引き上げで券を足す           |
| `world.ts`               | その回に拾った券、効き目の口（ボスへの攻撃・受けるダメージ・起き上がりなど）   |
| `drops.ts`・`bosses.ts`  | ボス・ヌシ・ステージの主が券を落とす、券を拾う                                 |
| `Gear.svelte`（新しい）  | 装備の画面（枠・持ち物・詳しい札）                                             |
| `Gacha.svelte`（新しい） | ガチャの画面とカプセルの演出                                                   |
| `art/gear.ts`（新しい）  | 18 種のアイコンと 3 種の券、カプセル                                           |

## 7. 入れないもの

- 図鑑の装備のタブと装備の実績。持ち物がたまってから足す。
- 品ごとに毎回ちがう能力が付く「おまけ」。
- キャラの絵に装備を描くこと。

## 8. 確かめ方

- vitest で、券の割合・天井・10 連のレア以上 1 つ・合成・売る・40 個の上限・つけた品の能力と効き目・倒れたら券を失う・引き上げで持ち帰る・お題の「店の強化なし」で外れる、を確かめる。
- ボットで、店半分に伝説 3 つ（ハチマキ・よろい・ふくろう）を足した夜の墓地と火山のクリアの割合を比べ、店を全部買ったときを越えないようにする。
- 絵は使う前に見本を見せる。
- `pnpm verify` を通し、ガチャの演出・装備の画面・リザルトの券を headless で撮る。

## 9. 調整の結果

ボットで、犬・キツネ・パンダを 8 回ずつ（合わせて 24 回）遊ばせた。装備はハチマキ・よろい・ふくろう。

| 案                | 夜の墓地のクリア | 夜の墓地の主 | 火山のクリア | 火山の主 |
| ----------------- | ---------------- | ------------ | ------------ | -------- |
| 店半分（12 回）   | 7/12             | 4/12         | 5/12         | 2/12     |
| 店半分に伝説 3 つ | 21/24            | 19/24        | 20/24        | 11/24    |
| 店半分にレア 3 つ | ー               | ー           | 18/24        | 4/24     |
| 店を全部          | 24/24            | 16/24        | 23/24        | 7/24     |

- クリアの割合は、伝説 3 つでも店を全部より低い。数はそのまま使う。
- ステージの主を倒す割合だけは、伝説 3 つが店を全部より高い。ハチマキとよろいがボスにだけ効くためで、装備を選んで遊び方を変える効き目として残す。主が簡単すぎると感じたら、ハチマキとよろいの効き目を下げる。

# Animal Survivors 火山 設計

## ねらい

雪山をクリアしたあとに向かう、いちばん難しい 4 つめのステージを足す。溶岩の池が自分にも敵にも当たる「噴火」で、危なさと引き換えに敵をまとめて焼ける場面を作る。ボスは新しい動きの 2 体にする。

10 匹めの動物「火の鳥のひな」は別の回（別の設計書）で作り、火山のクリアで仲間になる形にする。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い     | 決めたこと                                                      |
| -------- | --------------------------------------------------------------- |
| テーマ   | 火山                                                            |
| ボス     | 新しい動きの 2 体（溶岩の巨人・不死鳥）。並びは墓地・雪山と同じ |
| ごほうび | 10 匹めの動物（火の鳥のひな）。動物は次の回で作る               |

## 1. ステージ

- 雪山をクリアすると開く（`after: 'snow'`）。名前は「火山」、9:00 の 2 体は「火山の主」。
- 時刻の流れは森の表を写す（10 分、ボス・ヌシ・出来事の時刻は同じ）。敵の硬さと攻撃は森の 1.3 倍、同時に出る数の上限は森の 1.2 倍、コインの倍率は 2.5。
- 敵の 7 種は森の 7 種と同じ動き方で、見た目を火山の顔ぶれにする（雪山と同じ入れ替え）。

| 森       | 火山       |
| -------- | ---------- |
| ネズミ   | トカゲ     |
| コウモリ | 火の玉     |
| ヘビ     | 溶岩ヘビ   |
| イモムシ | 岩ムシ     |
| イノシシ | 火イノシシ |
| クモ     | 炎グモ     |
| ワニ     | 岩ワニ     |

- ヌシも同じ入れ替えで出す（体力は 1.3 倍）。

## 2. 噴火

- 雪山の吹雪と同じく、決まった時刻（95・215・335・455 秒）に 20 秒ずつ起きる。3 秒前に帯（「噴火が来る！」）を出す。
- 噴火のあいだは、1 秒ほどごとに自分のまわり（30〜90 ドット）の地面に割れ目の予告を出し、1.2 秒で溶岩が噴き出す。噴き出したところに溶岩の池が 6 秒残る。
- 溶岩の池は、中にいる自分と敵に 0.5 秒ごとに当たる（自分には決まったダメージ、敵には時刻の硬さに合わせたダメージ）。ボスとランタンには当てない。敵を池へ誘えば、まとめて焼ける。
- 噴火の時計は step の中で進めるので、3 択・一時停止・時計の品のあいだは止まる。時計の品で止まっているあいだは池も当たらない。
- 予告と池の絵は、地面の上・敵の下に描く。

## 3. ボス

どちらも今のボスより大きな絵（40 ドット前後）で、動き方は `bosses-volcano.ts` に置く。

- 溶岩の巨人
  - ゆっくり近づき、地ならし（予告の輪のあと輪の中に当たる）と岩投げを交互に使う。
  - 地ならしのあとは輪の中に溶岩の池が残り、岩が落ちたところにも小さな池が残る（池は噴火の池と同じ）。
- 不死鳥
  - 大ワシと同じく空に上がり（そのあいだは当たらない）、予告の場所へ急降下する。
  - 急降下と交互に、自分のまわりへ火の羽根を降らせる（予告の円のあと当たる）。
  - 体力が尽きると一度だけ、体力半分でよみがえる（光る演出と帯「よみがえった！」）。よみがえったあとに倒すと倒したことになる。よみがえるあいだは当たらない。

## 4. 絵と曲

- 新しく描くもの。敵 7 種（16 ドット、2 コマ）、ボス 2 体、地面と飾り（黒い岩・溶岩の割れ目・煙を上げる岩）、溶岩の池と割れ目。
- 絵は使う前に見本を見せて決める。敵・ボス・地面の 3 回に分けて見せる。
- 曲は火山の 1 曲を `songs.ts` に足す（低い音で急かす曲）。ボス戦は今のボスの曲。

## 5. 記録と実績

- ステージの記録・図鑑・延長戦・釜・アルカナは、今のしくみのまま火山でも効く（4:00 と 8:00 のボスの行に札の印）。
- 実績を足す。「火山をクリア」「溶岩の巨人と不死鳥を倒す」「溶岩の池で敵を 300 体倒す」。
- 火の鳥のひなは、次の回で「火山をクリア」の実績に付ける。

## 7. 確かめ方

- vitest で、火山の表（敵とボスが表にある・時刻が森と同じ・強さ）、噴火の時刻と帯・割れ目から池・池が自分と敵に当たりボスとランタンに当たらない・止まっているあいだは進まない、溶岩の巨人の地ならしと岩と池、不死鳥の空・急降下・羽根・一度だけのよみがえり、実績、を確かめる。
- ボットで、店半分と全部の火山のクリアの割合と 1 回のコインを測り、雪山より一段難しいくらい（店半分で雪山のクリアの割合より少し低い）に合わせる。
- `pnpm verify` を通し、headless の Chrome と webkit で噴火とボスを撮る。

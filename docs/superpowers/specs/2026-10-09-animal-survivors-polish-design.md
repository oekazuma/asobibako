# アニマルサバイバー 仕上げのまとめ 設計

## 目的

合体・探索・限界突破・協力プレイを足したあとに残った小さな点を直し、新しい仕組みに触れる実績と手がかりを足す。実機で遊ぶ前に、重さと見た目のずれの不安を減らす。

## 1. 手ざわりと不具合

| 点                                   | 決め方                                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| 合わせ技のツタと炎が増えすぎる       | 芽吹きの森のツタと炎の疾走の炎は、合体武器 1 つにつき同時に 24 個まで。超えたら新しく置かない         |
| 限界突破の待ち時間に下限が無い       | 限界突破で縮める待ち時間は、元の 4 割より短くしない                                                   |
| 協力プレイで画面が隠れても止まらない | 画面が隠れたら、1 人で遊ぶときと同じく一時停止する（3 択・宝箱のあいだは止めない）                    |
| 子が自分の育つ演出のあいだ動けない   | 子の端末では、育つ演出とボスの登場のあいだも動ける（親の World は子の育つ演出では止まらないので）     |
| 延長戦を聞く画面で親の ✕ が効かない  | 親の ✕ は「延長戦へ進まない」を選んだことにする                                                       |
| 吹雪で倒れた親だけが流される         | 倒れた動物は吹雪で流さない                                                                            |
| 2 人が同時に一時停止を押す           | 今も親の側にそろうので変えない。確かめるテストを足す                                                  |
| 大きなヌシが狭いすき間で引っかかる   | ヌシが障害物から押し出されるときの丸は半径 16 までにする（すき間は 40 ドット以上あるので通れる）      |
| 遠くに落ちた品が残り続ける           | 動物のどちらからも画面の対角線 3 つぶん以上離れた品は消す。宝箱・ガチャ券・遺物・ボスの大袋は消さない |

## 2. 見た目のずれ

- 合体武器の印は、一時停止とダメージ表でも HUD と同じ「+」にする。
- 宝箱で合体したときは、「遠吠え＋雷撃の合体！」のように元の 2 つの名前を出す。
- 遺物の矢印が画面の下半分にあるときは、遺物の絵を矢印の上に出す（ほかの矢印と同じ）。
- 祠のご利益の印の間を、3 けたの秒でも重ならない広さにする。
- 火の羽根の折り返しの炎にも、限界突破の大きさを効かせる。

## 3. 実績と手がかり

実績を 5 つ足す（48 → 53）。

| 実績           | 条件                        | コイン | 見出し   |
| -------------- | --------------------------- | ------ | -------- |
| はじめての遺物 | 遺物を 1 つ拾う             | 100    | ステージ |
| 遺物をすべて   | 遺物を 8 つ集める           | 500    | ステージ |
| 祠めぐり       | 1 回で祠を 10 か所使う      | 200    | ステージ |
| 合体の名手     | 1 回で 3 種の合体武器を作る | 300    | 育てる   |
| 限界の先へ     | 1 回で限界突破を 50 回      | 300    | 育てる   |

- 図鑑の遺物のタブで、まだ拾っていない遺物の手がかりに、ステージとだいたいの向きと遠さを出す（例: 「森の北東の遠く」）。向きは画面の上を北とする。
- 合体・遺物・祠・限界突破が初めて起きたときだけ、帯でひとこと説明を出す（例: 「合体！ 2 つの武器が 1 つになり、枠が 1 つ空いた」）。出したかどうかは記録に覚える。

## 確かめ方

- 1 と 2 の点はそれぞれ vitest で確かめる（ツタと炎の数・待ち時間の下限・協力プレイの一時停止と移動・✕・吹雪・ヌシの丸・遠くの品・印・合体の文・矢印の位置）。
- 実績の条件と、手がかりの文、初めての説明が 1 回だけ出ることを vitest で確かめる。
- 画面で、合体の宝箱・一時停止の印・図鑑の手がかり・初めての説明の帯を撮って見せる。

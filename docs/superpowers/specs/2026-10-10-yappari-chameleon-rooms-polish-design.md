# やっぱりカメレオン 部屋の作り込み 設計

## 目的

2b で足したロビーの部屋と屋敷の 3 部屋（書斎・図書室、キッチン、ランドリー）を、本家の画面に近い見た目へ作り込む。遊び方・当たり・知らせの形は変えない。全体の設計は `2026-10-08-yappari-chameleon-design.md`、本家の仕様は `2026-10-08-yappari-chameleon-original.md`、2b の決めごとは `2026-10-09-yappari-chameleon-stage2b-design.md` に従う。

ユーザーは外出中で、この段は遊んでもらう前に進める。決めごとは本家の画面を根拠にし、根拠の無いところは控えめにして、あとで iPad で見てもらう。

## 部屋ごとの作り込み

| 部屋         | 本家に寄せるところ                                                                                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| キッチン     | 灰緑がかった暗めの冷たい光、浮き模様のある白いタイル、黒い金属の棚、脂の筋が入った生々しい肉の塊、口金の付いたガスボンベ、ヘアラインのステンレス、鍋・積んだ盆・木箱などの物の多さ                     |
| ランドリー   | 暗い赤のダマスク柄の壁（今の赤レンガから替える）、木の天井、蛍光灯の細い管、木の台に高く積んだタオルの山（白・青・黄、少しずつずれて重なる）、形のある服（シャツやズボンの形）、消火器、掃除機、バケツ |
| 書斎・図書室 | 暖色の暗めの光、背の高さと色がばらつく本、肖像画、頭と肩のある胸像、じゅうたん、ひじ掛け椅子                                                                                                           |
| ロビー       | 白いアーチを壁から浮き出させて影を付ける、壁ごとにしぶきの配置を変える、水色の台をはっきり見せる                                                                                                       |

- 光は本家に寄せて暗めにするが、隠れる・探すが見えなくならない明るさを残す（暗すぎたら iPad で直す）。
- 動く物（`props.ts` の候補）の大きさと当たりは変えない。見た目だけ作り込む。大物の家具を足すときは、戸口・人の出る場所・動く物の候補と重ならないことをテストで確かめる。
- 模様は canvas で描き、線と目は 2cm 以上（屋敷の決まり）。外の素材は使わない。

## 守ること

- 描く回数は 2a の大広間の 1.5 倍（1354 回）を超えない。今の最悪は 284 回。物を足したら `mergeStatic` でまとめる。点光源は部屋ごとに 1〜2 個のまま（光の数を変えるとシェーダーを作り直す）。
- 3D スポイトで、足した物と模様の色が取れる（`userData.pick`）。
- 透かし窓（`xray.ts`）が足した物にも効く。
- ひとりで試す画面・2a と 2b の遊び方・知らせの形は変えない。`CHAMELEON_VERSION` は上げない（当たりを変えないため）。
- テクスチャの GPU メモリを増やしすぎない（同じ模様の canvas を共有する）。

## 確かめ方

- 部屋ごとに、本家の画面と同じ向きから撮って横に並べたシートを作る（キッチンとランドリーは本家と、ほかは作り込みの前と後）。
- 描く回数と三角形の数を、作り込みの前と後で部屋ごとに表にする。
- 3 ページの通しの試合（2b の e2e）が今のまま通る。`pnpm verify` が通る。
- ユーザーが戻ったら、シートを見てもらい、iPad で遊んでもらう。

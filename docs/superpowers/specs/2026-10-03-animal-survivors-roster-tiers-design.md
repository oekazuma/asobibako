# Animal Survivors キャラの段と専用進化 設計

## ねらい

今は動物がすぐ仲間になり、仲間になったうれしさが小さい。動物を 9 匹にして強さに段をつけ、先の面へ進むほど強い仲間が増えるようにする。あわせて、3 段階めまで育てた動物だけが使える専用進化を足し、育てる楽しみを強くする。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い       | 決めたこと                                            |
| ---------- | ----------------------------------------------------- |
| 段         | 基本 3・中 3・強 2・最強 1                            |
| 足す動物   | 強にトラ、最強に竜の子                                |
| 解放の条件 | 面の進みに合わせる                                    |
| 専用進化   | 3 段階めに育ち、最初の武器が Lv5 になった瞬間に起きる |

## 1. 段と解放の条件

| 段        | 動物   | 解放の条件         |
| --------- | ------ | ------------------ |
| 基本 ★    | 犬     | 最初から           |
| 基本 ★    | 猫     | 最初から           |
| 基本 ★    | 狼     | 最初から           |
| 中 ★★     | キツネ | 森をクリア         |
| 中 ★★     | クマ   | 森の面の主を倒す   |
| 中 ★★     | ウサギ | 合計 20000 体倒す  |
| 強 ★★★    | パンダ | 夜の墓地をクリア   |
| 強 ★★★    | トラ   | 雪山の大雪男を倒す |
| 最強 ★★★★ | 竜の子 | 雪山をクリア       |

- 動物の表（`animals.ts`）に段（`tier: 1 | 2 | 3 | 4`）を持ち、キャラ選択に★の数を出す。
- 解放は今と同じく実績のごほうびで、実績の条件と文を書き換える。森の面の主を倒したことは、記録に「面の主を倒した面」（`finales`）を足して数える。
- すでに仲間になっている動物は取り上げない。

## 2. 段ごとの強さ

- 段が上がるほど、もとの値と「とくい」を強くする。基本と中は今の値を土台に、中を少し上げる。

| 動物   | 体力 | 速さ | 攻撃 | とくい                          |
| ------ | ---- | ---- | ---- | ------------------------------- |
| 犬     | 100  | 1    | 1    | なし                            |
| 猫     | 90   | 1.25 | 0.9  | なし                            |
| 狼     | 110  | 1    | 1.2  | なし                            |
| キツネ | 90   | 1.15 | 1.05 | 会心率 +10%                     |
| クマ   | 155  | 0.85 | 1.2  | 受けるダメージ -2               |
| ウサギ | 80   | 1.35 | 0.9  | 拾う範囲 +50%                   |
| パンダ | 150  | 0.9  | 1.15 | 毎秒 HP +1 回復                 |
| トラ   | 135  | 1.2  | 1.35 | 会心率 +10%                     |
| 竜の子 | 140  | 1.1  | 1.35 | 受けるダメージ -1、毎秒 HP +0.3 |

- ボットで段ごとの強さを測り、強化なしの生存とクリアが「基本 < 中 < 強 < 最強」になるよう値を整える。

## 3. 新しい 2 匹

- トラ。最初の武器は「トラの爪」（引っかき型、前後を大きく 2 回裂く重い攻撃）。3 段階の名前は子トラ・白虎・雷虎。
- 竜の子。最初の武器は「竜の息」（新しい扇型。いちばん近い敵の向きへ扇形の炎を吐き、扇の中の敵をまとめて焼く）。3 段階の名前は竜の子・若竜・竜王。3 段階めは翼のある竜になる。
- 絵は 16・20・24 ドットの 3 段階（歩く 4 コマ・攻撃・被弾）、武器のアイコン、炎の扇。かわいさを残す（黒い丸目とほっぺ）。見本を見せて止まる。

## 4. 専用進化

- 3 段階めに育っていて、最初の武器（`Animal.weapon`）が Lv5 になった瞬間に、その動物の専用進化形へ入れ替わる。育つのと武器が Lv5 になるのはどちらが先でもよい。パッシブも宝箱も要らない。
- 最初の武器をふつうに進化させていたら、その進化形を専用進化形へ入れ替える。
- 専用進化形はそれ以上上がらず、元の武器・ふつうの進化形とともに 3 択に出ない。
- 帯「勇者の犬の 専用進化！」と、育つときと同じ光と効果音を出す。記録の進化の表にも残す。

| 動物   | 専用進化               | 中身                                 |
| ------ | ---------------------- | ------------------------------------ |
| 犬     | 勇者のホネ             | 骨を 6 本ずつ、敵を貫いて投げる      |
| 猫     | ねこまたの百裂ひっかき | 全方向を連続で引っかく               |
| 狼     | 月の大狼の咆哮         | 画面を覆う輪で強く吹き飛ばす         |
| キツネ | 九尾の狐火             | 9 つの火の玉が敵を追う               |
| クマ   | 横綱の張り手           | 巨大な張り手で遠くまで吹き飛ばす     |
| ウサギ | 月の兎の流星           | 分身が流れ星のように何本も駆け抜ける |
| パンダ | 達人の竹林             | 広い竹林で足止めして削る             |
| トラ   | 雷虎の牙               | 4 方向を雷の爪で裂く                 |
| 竜の子 | 竜王の業火             | 大きな扇の炎で焼き、焼け跡が残る     |

- 段が上の動物ほど専用進化も強くする（ダメージの目安は、ふつうの進化形に対して基本 1.2 倍・中 1.35 倍・強 1.5 倍・最強 1.7 倍）。
- 絵は、進化形の金色のアイコンに王冠を重ねる。弾や炎は進化形と同じ金色で描く。HUD の Lv は ♛ にする。

## 6. 確かめ方

- vitest で次を確かめる。
  - 9 匹の段と解放の条件。古い記録で仲間になっている動物は残る。
  - 専用進化が、育つのが先の場合と武器 Lv5 が先の場合の両方で 1 回だけ起き、ふつうの進化形からも入れ替わる。専用進化形は 3 択に出ず、上がらない。
  - 竜の息が扇の中の敵にだけ当たる。トラの爪が前後に当たる。
- ボットで、強化なしの森の生存とクリアが段の順に並ぶよう値を整える。
- headless Chrome で、2 匹の 3 段階、専用進化の瞬間、竜の息を撮る。
- `pnpm verify` を通す。

## 7. 調整の結果

- トラの爪と竜の息は、その動物だけの武器にした（ほかの動物の 3 択に出さない）。段の違いがぼやけないため。
- 最初の値でボットを 9 匹 16 回ずつ回すと、トラが 1/16（爪が届く前にやられる）、竜の子が 16/16 だった。
- トラは爪を速く・広く・重くし（ダメージ 20、待ち 0.8 秒、大きさ 1.6）、体力を 135 にした。竜の子は攻撃を 1.35 にし、「弾 +1」を外した。雷虎の牙はトラの爪の Lv5 の 1.6 倍（48）にした。

| 段   | 動物                       | 強化なしの森のクリア |
| ---- | -------------------------- | -------------------- |
| 基本 | 犬 4・猫 2・狼 9           | 15/48（31%）         |
| 中   | キツネ 7・クマ 6・ウサギ 8 | 21/48（44%）         |
| 強   | パンダ 11・トラ 9          | 20/32（62%）         |
| 最強 | 竜の子 14                  | 14/16（88%）         |

# おえかきリレー 設計

## ねらい

おえかきのもりに 4 つ目の遊び方「おえかきリレー」を足す。お題を描く → 次の人が絵だけを見て言葉で当てる → その言葉を次の人が描く……と回し、最後に最初のお題とくらべて笑う。点数は付けない。2〜3 人の家族（子どもも入る）で、待ち時間なく遊べることを目指す。

## 決めたこと

| 問い       | 決めたこと                                                                      |
| ---------- | ------------------------------------------------------------------------------- |
| 回し方     | 人数ぶんのリレーを同時に回す。1 だんごとに全員がいっせいに描くか当てる          |
| 最初のお題 | いまのお題（字数の上限も効く）から、リレーごとにちがうものをランダムに配る      |
| ふりかえり | 親の「つぎ」で 1 こまずつ全員の画面でめくる。最後に最初と最後の言葉を大きく出す |
| 点数       | 付けない                                                                        |

## 1. 遊びの流れ

- 遊び方選び（`ModeSelect.svelte`）に「おえかきリレー」のカードを足す。長さと字数の設定はそのまま使う。
- 遊ぶ人が N 人（2 か 3）なら、リレーを N 本作る。リレー c の最初のお題は、字数で絞ったお題からちがうものをランダムに選ぶ。
- だんの数は、みじかめ 4・ふつう 6・ながめ 8。偶数のだんは「描く」、奇数のだんは「当てる」で、最後は必ず「当てる」になる。
- リレー c の k だん目は、遊ぶ人の並び `players` の `(c + k) % N` 番目の人が受け持つ。2 人なら交互、3 人なら順に回る。どのだんでも、1 人がちょうど 1 本のリレーを受け持つ。
- 描くだんは、みじかめ 45 秒・ふつう 60 秒・ながめ 80 秒。当てるだんは 30 秒。
- 受け持った人が「できた」を押すとそのこまは終わる。全員が終わるか時間が切れたら、全員がいっせいに次のだんへ進む。終わった人には「ほかの ひとを まっています」を出す。
- 当てるだんで時間が切れたら、打ちかけの字（`typing` の知らせで届いている最後の字）を答えにする。何も打っていなければ「（わからなかった）」と残す。その次の描くだんでは、受け持つ人に新しいお題をランダムに配る。
- 最後のだんが終わったら、ふりかえりに入る。

## 2. ふりかえり

- 親の画面に「つぎ」を出す。押すたびに、全員の画面で 1 こまずつめくる。並びはリレーの順で、リレーの中は「さいしょの おだい → 絵 → 答え → 絵 → … → 答え」。
- 1 本のリレーをめくり終えたら、「さいしょは『りんご』→ さいごは『とまと』」を大きく出す。次の「つぎ」で次のリレーへ移る。
- それぞれのこまには、受け持った人の動物（`Face`）を添える。
- 全部めくり終えたら、全員の画面に「しゃしんに ほぞん」と、親には「あそびを えらぶ」を出す。保存する 1 枚は、リレーごとに縦の列を作り、列を横に並べる（`relay-album.ts`）。

## 3. しくみ

### ルール（`relay.ts`、DOM を使わない）

- `Relay` の状態は、遊ぶ人の並び・だんの数・いまのだん・残り秒・段階（`play` / `reveal` / `done`）・リレーの並び・いまのだんで終わった人・ふりかえりの位置を持つ。
- リレーは `{ start: string; entries: Entry[] }`。`Entry` は `{ kind: 'draw'; by: Seat; strokes: Stroke[] }` か `{ kind: 'guess'; by: Seat; text: string | null }`（null は わからなかった）か、空の答えのあとに配り直したお題 `{ kind: 'prompt'; text: string }`。
- 主な関数は次のとおり。
  - `createRelay(players, rand, words, length, chars)`
  - `assignee(s, chain, step)`（受け持つ人）と `taskOf(s, seat)`（いまのだんでその人がすること。描くなら言葉、当てるなら前のこまの絵）
  - `addInk(s, seat, ink)`（描くだんの線をためる）と `finish(s, seat, text?)`
  - `tick(s, dt, rand, words, typed)`（時間を進め、だんを進める。`typed` は人ごとの打ちかけの字）
  - `leave(s, seat)` と `rejoin(s, seat)`
  - `next(s)`（ふりかえりを 1 こま進める）

### 親の審判（`relay-referee.ts`）

- 遊ぶ人の操作は次の 4 つ。
  - `{ t: 'ink', ink }`：描くだんの線。今のエゴコロクイズと同じ形。
  - `{ t: 'typing', text }`：打ちかけの字。時間切れのときに使うため、親が人ごとに覚える。
  - `{ t: 'relayDone', text }`：「できた」。描くだんは text なし、当てるだんは答え。
  - `{ t: 'relayNext' }`：ふりかえりの「つぎ」。親だけが送る。
- 知らせは次の 3 つ。
  - `{ t: 'relayTask', step, task }`：だんが替わるたびに 1 人 1 回だけ送る。`task` は `{ kind: 'draw', word }` か `{ kind: 'guess', strokes }` か `{ kind: 'wait' }`。
  - `{ t: 'relayView', phase, step, steps, left, done }`：変わったときだけ全員へ送る小さな見え方。
  - `{ t: 'relayPage', chain, index, entry, last }`：ふりかえりで 1 こまずつ送る。絵をまとめて送ると、DataChannel の 1 回の上限を超えることがあるため。
- 描くだんの線は、今と同じく 1 フレームごとに親へ送り、親がリレーごとにためる。端末が途中で落ちても、そこまでの絵が残る。

### 画面

- `OekakiMori.svelte` の遊び方選びから `relay` を選ぶと、親は `RelayReferee` を始め、全員へ `{ t: 'screen', screen: 'relay' }` を送る。
- `Relay.svelte`（新）がリレーの画面の入口で、知らせを受けて `RelayPlay.svelte` と `RelayReveal.svelte` を切り替える。
- `RelayPlay.svelte` は、描くだんでは言葉の札・盤面・道具・「できた」、当てるだんでは前の絵（読むだけの盤面）・50 音盤、待つときは「ほかの ひとを まっています」を出す。上には残り秒とだんの数（「3 / 6」）を出す。
- `RelayReveal.svelte` は、これまでにめくったこまを縦に並べ、いちばん新しいこまへ寄せて見せる。親には「つぎ」を出す。

## 4. 抜けたとき・戻ったとき

- 誰かが抜けても、リレーは続ける。抜けた人がいまのだんで受け持っていたこまは、すぐに埋める。描くなら白紙、当てるなら「（わからなかった）」。そのあとのだんで受け持つこまも、だんが始まるときに同じように埋める。
- 遊ぶ人が 1 人になったら、そこでふりかえりへ進む。
- 呼び直しで戻った人は、次のだんから受け持ちに戻る。いまのだんのこまがまだ埋まっていなければ、`relayTask` を送り直す。戻った人の画面には `screen` と `relayView` も送り直す。

## 確かめ方

テストで固めること。

- `relay.test.ts`
  - 受け持ちの回し方：2 人と 3 人で、どのだんも 1 人が 1 本だけ受け持ち、自分のリレーを続けて受け持たないこと（3 人のとき）。
  - だんの進み方：全員が「できた」で進むこと、時間切れで進むこと、最後のだんのあとにふりかえりへ入ること。
  - 空の答え：打ちかけの字を使うこと、何もなければ「（わからなかった）」になり、次の描くだんに新しいお題を配ること。
  - 抜けた人：こまを埋めること、1 人になったらふりかえりへ進むこと、戻った人が次のだんから受け持つこと。
  - ふりかえり：`next` でこまとリレーが順に進み、最後に `done` になること。
- `relay-referee.test.ts`：だんの頭に `relayTask` を 1 人 1 回送ること、`relayView` を変わったときだけ送ること、ふりかえりで `relayPage` を 1 こまずつ送ること。
- `relay-album.test.ts`：列の並べ方が重ならないこと。

通しで確かめること。3 ページと偽カメラの仕組みで、「みじかめ」のリレーを 1 回（4 だん）遊び、ふりかえりを最後までめくって、保存する 1 枚を撮る。

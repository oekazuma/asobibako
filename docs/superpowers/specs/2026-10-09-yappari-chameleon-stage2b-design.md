# やっぱりカメレオン 2b 設計（ロビーの部屋・屋敷の 3 部屋・ダブル・見落としポイント）

## 目的

2a のつないで遊ぶ試合に、本家にあって 2a で回したものを足す。全体の設計は `2026-10-08-yappari-chameleon-design.md`、本家の仕様は `2026-10-08-yappari-chameleon-original.md`、2a の決めごとは `2026-10-09-yappari-chameleon-stage2a-design.md` に従い、この書面は 2b で足すものと変えるものだけを書く。

| 足すもの           | 中身                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------ |
| ロビーの部屋       | ペンキのしぶきの部屋と、乗るとハンター希望になる「HUNTER」の赤い台                   |
| 屋敷の 3 部屋      | 書斎・図書室、キッチン、ランドリー（大広間と緑の廊下に足して 5 部屋）                |
| 小物の置き方の乱数 | 試合ごとに小物の置き場所が変わる。親が種を配り、全員の画面と当たりがそろう           |
| ダブル             | 全員で隠れてから全員で探し、ほかの全員を最初に見つけた人の勝ち                       |
| 見落としポイント   | ハンターの視界にいて見逃された隠れる人に点が入る。見逃しランキングと答え合わせの順位 |
| ええやん           | 答え合わせで隠れた人をほめるボタン（1 試合 1 回）                                    |
| ハンターの三人称   | 一人称と三人称の切り替え                                                             |
| 埋まりすぎの警告   | 体が物に深く埋まると本人に警告し、5 秒続くとハンターに場所を知らせる                 |

知らせの形が変わるので `CHAMELEON_VERSION` を上げる。

## ロビーの部屋

- 屋敷と控室から離れた所に置く、16m 四方・高さ 6m の部屋（出口なし）。床は白黒の市松、壁と天井は白で、壁に白いアーチを並べる。壁・床・天井に赤・黄・緑・紫の大きなペンキのしぶきを canvas で描く（本家のロビーの見た目）。
- まん中に、直径 2.4m・高さ 0.3m の赤い丸い台を置き、上面に白いペンキの筆の字で「HUNTER」と描く。台は乗れる箱として当たりに入れる。
- 台の上に立っている人（足もとが台の上面にあり、中心が台の円の内側）がハンター希望になる。親がロビーのあいだ届いた体の位置から決めて配る（`phase` の `wishes`）。2a の「ハンター希望」ボタンと頭の上の赤い印はなくし、台の縁を、乗っている人がいるあいだ明るく光らせる。
- つないだあと・試合のあと・ロビーへ戻るときは、この部屋の席ごとの場所に出る。ロビーでも歩く・塗る・ポーズ・挑発ができる。
- 部屋の端に本家と同じ水色の台を飾りとして置き、親の「マップの設定」と「ゲームを始める」は 2a のまま画面のボタンで開く（本家の水色のボタンのそばで E を押すのは、タッチでは画面のボタンに置き換える）。

## 屋敷の 3 部屋

大広間（x −7〜7、z 0〜12）と緑の廊下（x −23〜−7）に、戸口でつながる 3 部屋を足す。並びと当たりは `mansion/layout.ts`、組み立ては `build.ts` と `furniture.ts`、模様は `textures.ts` の canvas（線と目は 2cm 以上）で作る。

| 部屋         | 場所                                | 中身（本家の画面から）                                                                                                                                     |
| ------------ | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 書斎・図書室 | 大広間の東の壁の戸口から（x 7〜17） | 茶色の木の床、壁一面の本棚（背表紙の模様）、緑の笠のバンカーズランプの机、折りたたみ椅子、地球儀、肖像画、胸像、木の柱                                     |
| キッチン     | 緑の廊下の北の壁の戸口から          | 白いタイルの壁、青い六角タイルの床、ステンレスの台とシンク、積み上げた皿、肉が並ぶ棚（吊るした肉と、肉を並べた段）、ガスボンベ、天井のダクト、黄色の注意線 |
| ランドリー   | 緑の廊下の南の壁の戸口から          | 赤い壁、赤と黄色のドラム式洗濯機、洗濯ひもに吊るした服、たたんだタオルの山（白・青・黄）、青い洗濯カート、バケツ、白黒の床                                 |

- 部屋の大きさは 8〜10m 四方・高さ 3.5〜4m を目安に、計画で決める。戸口は幅 1.5m・高さ 2.4m（今の大広間と廊下の戸口と同じ）。
- 照明は部屋ごとに明るさを変える（書斎は暖色のランプ、キッチンは白い天井灯、ランドリーは少し暗め）。点光源の数は描く重さに効くので、部屋ごとに 1〜2 個にする。
- 部屋ができたら、本家のスクショと横に並べたシートを撮ってユーザーに見せる。

## 小物の置き方の乱数

- 本家（v2.2.0）は家具とほかの物の置き方を変える。こちらは、風船・椅子・丸テーブル・ソファ・ベンチ・洗濯カート・タオルの山・段ボール箱・本の山・バケツを「動く物」にし、額の絵は試合ごとに絵柄を差し替える。部屋ごとに置き場所の候補（位置と向き）を用意し、試合ごとに候補から選ぶ（候補の数より少なく置く）。壁に付いた大物（本棚・ピアノ・洗濯機・キッチンの台と棚・大階段）は動かさない。
- 親が試合の始め（紹介に入るとき）に乱数の種を決めて `phase` で配る。各端末は種から同じ置き方を作り、小物の 3D と当たりを作り直す。ロビーへ戻ると既定の置き方に戻す。
- 乱数は種から作る決まった計算にし、端末ごとに同じ結果になることをテストで確かめる。戻った子も種で同じ置き方を作る。
- 作り直しは紹介の 3 秒のあいだに済ませる。

## ダブル

- マップの設定のゲームモードに「ダブル」を足す。紹介はマゼンタのモード名と、本家の説明「最初に全員で隠れる。」「その後全員で探索し、最初に全員見つければ勝利」。
- ハンターの人数の設定は使わない（全員が隠れて全員が探す）。設定の画面ではダブルのとき人数の項目を薄くする。
- 隠れタイムは全員が隠れる人（控室にいる人はいない）。隠れタイムが終わると、各自の隠れた体はその場に残り（2a の答え合わせの体と同じ作りで、塗りとポーズを持つ）、全員が新しい白い体のハンターになって屋敷の入口から探す。
- 撃って当てる相手は、ほかの人が残した体だけ。自分の残した体と、動いているハンターの体には当たらない。見つけた体はその人の画面からだけ消え、ほかの人の画面には残る（ほかの人もまだ見つけていないので）。
- ほかの全員の体を最初に見つけた人の勝ち。そこで探索を終えて答え合わせへ入る。時間切れのときは見つけた数の多い人、同じ数なら先にその数に届いた人の勝ち。誰も見つけていなければ勝者なし（「勝者なし」）。
- 探索のあいだのフェーズの言葉は、全員「全員を見つけよう」（本家の言葉）。隠れタイムは「探索開始まで」。
- HUD の左に順位表を出す（`#1 プレイヤー2 2/2` のように、見つけた数／見つける数）。上の人形は全員が赤。
- 勝者の言葉は「勝者 プレイヤー2!」、勝者がいなければ「勝者なし」。
- 見つけた体はその人の画面からだけ消す決めは、本家で確かめられなかった（推）。本家の分身は撃たれると本体も撃たれた扱いなので、ダブルの残した体も撃たれると持ち主が脱落する仕組みの見込みがある。2 台で遊んで決め直す。
- 答え合わせは、残した体を全員の画面に出し、まだ誰にも見つかっていない体は赤、誰かに見つかった体は青に光らせる。

## 見落としポイント

- 親が、探索のあいだ毎フレーム、ハンターごと・隠れる人ごとに点を足す。点が入るのは次のすべてが合うとき。
  - 隠れる人の体の真ん中か頭が、ハンターの視野（縦 72 度、横は 16:9 で 105 度相当の半角 52 度）の中にある。
  - ハンターの目からその点までの線が、壁や家具に遮られない（弾と同じ屋敷の当たり）。
  - 隠れる人が動いていない（直前 0.2 秒の位置の変化が 0.05m 未満で、ペイントモードでもよい）。
  - 距離が 15m 以内。
- 1 秒あたりの点は `10 × (1 − 距離 / 15)`。近くで長く見逃すほど多い。本家は式を出していないので、遊んで直す。
- ダブルでは、探している人の視界に入った、ほかの人の残した体に点が入る（残した体は動かない）。
- 設定の「ハンターに見逃しランキングを表示」（既定オン）を足す。オンなら、ハンターの画面の左に見出し「見落とした敵」で、隠れる人の名前と点の順位を出す。一覧には「隠す」のボタンを付ける（本家 v1.2.2 で隠すキーがある）。
- 答え合わせでは「見落とされた場所」として、隠れる人の点の順位と、その人のいた場所を出す。
- 点は親が `phase` で 1 秒ごとに配る。

## ええやん

- 答え合わせのあいだ、隠れた人（ダブルでは全員）の名前の札の横に「ええやん」のボタンを出す。自分以外の 1 人に、1 試合 1 回だけ押せる。
- 押された数を名前の札の横に、親指のアイコン（`icons.ts` に足す）と数で出す（本家は頭の上に親指と数）。数は親が数えて配る。通算は持たない（本家の通算といいねのリセットは入れない）。
- 札は 3D の体の上にあるので、ボタンは画面の右の一覧（名前とボタン）に並べる。

## ハンターの三人称

- ハンターの右端のボタンに「TPS視点」を足す（本家の告知の言葉。三人称のあいだは「FPS視点」と出す）。押すと、ハンターの体の後ろ上からのカメラ（隠れる人の歩きのカメラと同じ追い方）になり、もう一度押すと一人称に戻る。三人称のあいだは自分の体（銃を構えたポーズ）を出す。
- 三人称でも画面の中央に十字を出し、弾はカメラから十字の向きへ飛ばす（線の始まりはカメラの位置、壁の当たりは今と同じ）。
- 控室と、観戦のあいだは出さない。

## 埋まりすぎの警告

- 親が、隠れる人の体の当たり（骨ごとのカプセル、`shots.ts` の形）が屋敷の箱にどれだけ入っているかを見る。胴か頭のカプセルの軸の真ん中が箱の中にあるとき「埋まっている」とする。
- 埋まり始めたら、本人の画面の中央に赤みの字で「体が埋まりすぎている！この状態が続くと位置が公開されます」と出す。5 秒続くと、ハンターの画面にその人の場所の印（赤い下向きの矢印、壁を透かして見える）を出す。埋まりが解けたら印を消す。
- 時計は親が持ち、隠れタイムと探索のあいだだけ数える（ロビーと答え合わせでは数えない）。

## BGM

- ロビー・隠れタイム・探索の 3 曲を、`$lib/music/loop.ts` の `Loop` と `tune.ts` の楽器で鳴らす（曲はこのゲームの `songs.ts`）。本家の曲は使わず、雰囲気（ロビーは明るく、隠れタイムは軽い緊張、探索は張りつめた感じ）を新しく作る。
- フェーズが変わると曲を変える。答え合わせはロビーの曲。効果音と同じく共通のミュートで止まる。
- ペイントモードのあいだは小さくして流し続ける。

## 通信で変わるもの

| 知らせ  | 変わること                                                                                       |
| ------- | ------------------------------------------------------------------------------------------------ |
| `phase` | 小物の種、台の上の人（`wishes`）、ダブルの見つけた数、見落としポイント、ええやんの数、埋まりの印 |
| `iine`  | 子 → 親。ええやんを押した相手                                                                    |
| `wish`  | なくす（台の上にいるかで決める）                                                                 |
| `shot`  | 三人称のときは、弾の始まり `o` をカメラの位置、向き `d` を十字の向きにする                       |

- 屋敷の部品が増えて描く回数と点光源が増えるので、計画の終わりに iPad Air 相当の重さを headless で測り、描く回数が 2a の 1.5 倍を超えたら材質と形をまとめる。

## 確かめ方

- vitest で次を確かめる。
  - ダブルで、全員が隠れてから全員がハンターになり、残した体だけに当たり、最初にほかの全員を見つけた人が勝つ。時間切れのときの勝ち方。
  - 見落としポイントが、視野の外・壁の向こう・動いている人・15m より遠い人には入らず、近いほど多く入る。
  - 小物の置き方が同じ種で同じになり、置いた小物が壁や大物の家具や戸口にかぶらない。
  - 埋まりの判定と 5 秒の時計、ロビーと答え合わせで数えないこと。
  - 台の上にいる人がハンター希望になり、降りると外れる。
  - ええやんが 1 試合 1 回、自分には押せない。
- headless の Chrome で、ロビーの部屋と 3 部屋のシート（本家のスクショと横に並べたもの）、3 ページの通しの試合（ダブルを 1 回と、増え鬼を 1 回）を撮る。
- iPad 2 台で遊んでもらい、部屋の見た目・見落としポイントの効き方・BGM を聞く。

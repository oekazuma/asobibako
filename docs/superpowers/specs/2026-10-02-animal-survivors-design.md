# Animal Survivors 設計

## ねらい

動物版のヴァンサバ系サバイバル「Animal Survivors」を、あそびばこの 1 人用ゲームとして足す。犬・猫・狼から 1 匹を選び、攻撃は自動、押し寄せる大群を倒して経験値を集め、レベルアップの 3 択で強くなりながら 15 分を生き延びる。いちばん大事なのは、自分がどんどん強くなって大量の敵を一気に倒していく気持ちよさ。

遊ぶのは大人（利用者と妻）で、端末は iPad Air（縦長の盤面）。PC のキーボードとゲームパッドでも遊べる。

## 決めたこと

| 問い         | 決めたこと                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 置き場所     | `src/lib/games/animal-survivors/`。`SoloShell` を `levels: 1` で使い、「ひとりで」のタブに入れる |
| 文字         | 漢字まじり。絵文字は使わない                                                                     |
| 1 プレイ     | 15 分を生き延びればクリア                                                                        |
| 絵           | ドット絵を文字の格子で手で打つ。ゲームを作る前に見本のシートを見せて水準を確かめる               |
| 描画         | 幅 260 ドット前後の仮想画面に canvas 2D で描き、ぼかさずに整数倍で拡大する                       |
| 進め方       | 最小版を作ったら実機で触ってもらい、手ざわりの感想を直してからボスなどを足す                     |
| 地形の当たり | 木や岩には当たり判定を付けない（大群に囲まれたときに引っかかって詰まないように）                 |

## 1. 遊びの流れ

- シェルのタイトル → キャラ選択 → プレイ → リザルト。リザルトからは「もう一度」（同じ動物）か「キャラ選択へ」を選ぶ。タイトルへはシェルの ✕ で戻る。
- キャラ選択は 3 匹のドット絵（歩きのアニメ）、HP・速さ・攻撃力の棒、初期武器の名前と説明を並べる。
- 0〜3 分は弱い敵がまばらで、3 分ごとに敵の種類・数・硬さが上がる。12 分から最後のラッシュになる。画面に出る敵は最大 400 体前後。
- 15:00 になったら残りの敵が一斉に倒れ、「生存成功」のリザルトを出す。HP が 0 になったら「GAME OVER」のリザルトを出す。
- リザルトには、生存時間・Lv・撃破数・獲得経験値・使ったキャラ・取った武器とパッシブ（Lv つき）を出す。
- 画面が隠れたら一時停止する。

## 2. 成長

- 経験値が次の Lv の必要量に届いたら、ゲームを止めて 3 択のカードを出す。1 つ選ぶと再開する。一度に複数の Lv が上がったら、続けて 3 択を出す。
- 武器は 6 枠、パッシブは 6 枠。どちらも Lv5 まで。
- 3 択は「持っていない武器・パッシブ（枠が空いているとき）」と「持っていて Lv5 未満のもの」から重みつきで選ぶ。候補が 3 つに満たなければ、「肉（HP を 30% 回復）」と「経験値の袋」の札で埋める。
- 武器の Lv2〜5 は、武器ごとの表で上がる（例は骨ブーメランで、Lv2 ダメージ +20%、Lv3 発射数 +1、Lv4 大きさ +25%、Lv5 貫通 +1）。カードには次の Lv で何が上がるかを書く。
- パッシブは 1 Lv ごとに決まった割合を足す。

## 3. 最小版に入れるもの

### 動物

| 動物 | 型              | HP  | 速さ | 攻撃力 | 初期武器                                   |
| ---- | --------------- | --- | ---- | ------ | ------------------------------------------ |
| 犬   | バランス        | 100 | 1.0  | 1.0    | ワンワンショット（近い敵へ骨を投げる）     |
| 猫   | 速い・HP が低い | 70  | 1.25 | 0.9    | ネコパンチ（向いている側を引っかく。速い） |
| 狼   | 攻撃力が高い    | 120 | 1.0  | 1.3    | 遠吠え（周りに衝撃の輪を広げる）           |

数値は最初の目安で、バランスのボットと実機で直す。

### 武器

| 武器             | 動き方     | あらまし                                 |
| ---------------- | ---------- | ---------------------------------------- |
| ワンワンショット | 投げる     | いちばん近い敵へまっすぐ飛ぶ骨           |
| ネコパンチ       | 近接       | 向いている側に扇形の引っかき             |
| 遠吠え           | 輪         | 自分を中心に広がる輪。触れた敵を押し返す |
| 骨ブーメラン     | ブーメラン | 向いている側へ飛んで戻る。貫通する       |
| 羽根の嵐         | 周回       | 体の周りを羽根が回る                     |
| 雷撃             | 落雷       | 画面内のでたらめな敵へ落ちる             |
| 魚ミサイル       | 追尾       | 近い敵を追いかけて当たると小さく爆ぜる   |

### パッシブ

最大HP・攻撃力・攻撃速度（待ち時間を縮める）・移動速度・防御（受けるダメージを減らす）・経験値・攻撃範囲・クリティカル率・回復（毎秒の自然回復）・取得範囲の 10 種。

### 敵

| 敵       | 動き方                           | あらまし               |
| -------- | -------------------------------- | ---------------------- |
| ネズミ   | 追う                             | 弱くて速め。群れで出る |
| コウモリ | 追いながら左右に波打つ           | 速い・HP が低い        |
| イモムシ | 追う                             | 遅い・硬い             |
| ヘビ     | くねりながら追う                 | ふつう                 |
| イノシシ | 近づくと止まり、まっすぐ突進する | 硬く、当たると痛い     |

### 落とすもの

- 経験値の玉。値によって 3 色。取得範囲に入ると吸い寄せられる。
- 肉。低い確率で落ち、HP を回復する。
- 磁石。低い確率で落ち、拾うと画面中の玉が一気に集まる。

### 演出

- 当たった敵は白く点滅して少し押し返される。ダメージ数字を浮かべ、会心は大きく黄色にする。
- 倒した敵は小さく破裂して粒を散らす。
- 玉を続けて拾うと、拾う音が少しずつ高くなる。
- レベルアップでは自分の周りが光ってから 3 択を出す。
- プレイヤーには影と白いふちを付け、エフェクトは半透明にして、大群の中でも自分の位置を見失わないようにする。
- 被弾したら自分が赤く点滅して少し無敵になり、画面が小さく揺れる。

### 絵

- 犬・猫・狼は 16×16 前後で、歩き 4 コマ・攻撃 1 コマ・被弾 1 コマ。左右は反転で作る。
- 敵は 12〜16 ドットで歩き 2 コマ。
- 弾・玉・肉・磁石、森の地面のタイル（草の濃淡・土）と飾り（花・草むら・木・岩・切り株）。
- 色は 1 枚あたり 16 色前後、外側に濃い線を引く。

## 4. あとで足すもの

実機の感想を直したあとで、それぞれ別の計画にする。

- ボス（5・10 分の巨大ベアなど、WARNING の演出、専用の攻撃、撃破で宝箱と大量の経験値）
- 宝箱（複数の強化をまとめてもらう）と一時強化アイテム（攻撃力・移動速度）
- 残りの武器（爪・ダッシュアタック・どんぐりショット・野生の炎・ツタ）と敵（クモ・ワニ・強化個体）
- 追加の動物（キツネ・クマ・ウサギなど）と解放の条件、記録の保存
- ステージ（雪山・火山・海岸・夜の街・魔法の森）

## 5. しくみ

### データ

新しい動物・武器・敵・ステージは、それぞれの表に 1 項目を足せば加わるようにする。

| ファイル           | 持つもの                                                                         |
| ------------------ | -------------------------------------------------------------------------------- |
| `animals.ts`       | 動物ごとの HP・速さ・攻撃力の倍率・初期武器・絵の名前                            |
| `weapons.ts`       | 武器ごとの動き方（7 種のどれか）・Lv1 の数値・Lv2〜5 で上がる量の表              |
| `passives.ts`      | パッシブごとに、どのステータスへ 1 Lv あたり何を足すか                           |
| `enemies.ts`       | 敵ごとの HP・速さ・攻撃力・大きさ・経験値・動き方                                |
| `stages/forest.ts` | 地面のタイルと飾りの並べ方、時間ごとの出現表（何分から何を、毎秒何体、上限何体） |

### ロジック（DOM を使わない）

- `world.ts` は 1 ゲームの状態と `step(world, input, dt)` を持つ。移動 → 出現 → 武器 → 当たり → ドロップ → 経験値の順に進め、レベルアップが溜まったら止めて知らせる。
- `arms.ts` は武器の 7 種の動き方を持つ。発射して弾を作る側と、弾が当たる側。
- `choices.ts` はレベルアップの 3 択を、枠の上限と Lv5 の打ち止めを守って選ぶ。
- 乱数は種から作り、テストで同じ展開を再現できるようにする。
- 座標は仮想画面のドットを単位にする。

### 描画と入力

- `pixels.ts` はドット絵を文字の格子（1 文字 = 1 色）で持ち、初回に小さな canvas へ焼いて控える。左右反転と白い点滅の版も焼いておく。
- `draw.ts` は仮想画面に、地面 → 影 → 玉 → 敵 → 自分 → 弾・エフェクト → ダメージ数字の順で描く。仮想画面の幅は 260 ドット前後で、端末の画素数を割り切れる整数の倍率で拡大する（`imageSmoothingEnabled = false`）。数字は 3×5 の自作のドット字。
- 地面と飾りは、タイルの座標から決まる乱数で並べる。どこまで歩いても同じ森が続き、端はない。カメラは自分を追う。
- `input.ts` はキーボード（WASD・矢印キー）・指とマウス（置いた所からずらした向きへ進む、浮き出るスティック）・ゲームパッド（`navigator.getGamepads()` の左スティック）を 1 本の向きにまとめる。指は `pointerdown` と `pointerId` で扱い、最初の 1 本だけを使う。
- HUD（Lv・HP・EXP・生存時間・撃破数・武器とパッシブの一覧のアイコンと Lv）は、英数字だけなので `hud.ts` が同じ canvas に 3×5 のドット字で描く。
- 画面は `Survivors.svelte`（キャラ選択・プレイ・リザルトの切り替え）・`Play.svelte`（canvas とループ）・`CharSelect.svelte`・`LevelUp.svelte`・`Result.svelte`。日本語の文字が要る 3 択・キャラ選択・リザルトは HTML で、角ばった枠と濃いふちのレトロな見た目にする。3 択とリザルトは指の下に出るので、`$lib/settle.svelte` の `Settle` で出た直後の合成 click を防ぐ。日本語のドット書体は外部フォントになるので使わず、ヒラギノの太字に枠でレトロさを出す。
- 効果音は `$lib/audio.svelte` の `tone` と `noise` で作る。撃破音や拾う音は 1 フレームに 1 回までにまとめる。ループは `$lib/loop.ts` の `animate`。
- コンポーネントは 200 行未満に保つ。

### 重さ対策

- 敵・弾・玉・粒はそれぞれ配列のプールに置き、死んだものを使い回す。
- 当たり判定は 32 ドット四方の格子に振り分け、近くのものだけを比べる。敵どうしも軽く押し合って団子にならないようにする。
- 自分から遠く離れすぎた敵は消さずに、進む先の画面の外へ回す。
- 玉が 400 個を超えたら、遠いものを 1 つの大きな玉にまとめる。
- 目標は、iPad Air で敵 400 体・玉 400 個・弾 300 発の場面を 60fps で描くこと。

## 6. 作る順番

1. ドット絵の見本。すべての絵を 1 枚のシートにして撮って見せ、ゲームに見えるかを判断してもらう。だめなら描き直す。
2. 最小版。3 章のすべてを入れ、キャラ選択からリザルトまでを通す。
3. 実機で触ってもらい、手ざわり・テンポ・難しさの感想をもらって直す。
4. 4 章のものを、ボス → 宝箱と一時強化 → 残りの武器と敵 → 追加の動物 → ステージの順に足す。

## 7. 確かめ方

- vitest で、出現表どおりに敵が出ること、武器の Lv 表がステータスに反映されること、3 択が枠の上限と Lv5 を守ること、ダメージ・撃破・ドロップ・経験値の曲線、同じ種なら同じ展開になることを確かめる。
- scratchpad のボット（敵から逃げながら回り、3 択はでたらめに選ぶ）で何度も遊ばせ、生存時間と Lv の分布を見る。目安は、でたらめに選ぶと 8〜12 分で倒れること。最後は実機の感想で決める。
- headless Chrome でプレイ中の画面（序盤・敵だらけの終盤・レベルアップ・リザルト）を撮って確かめる。敵 400 体の場面の fps も同じ方法で測る。
- `pnpm verify` を通す。
- 一覧のカードの絵は `pnpm thumbs` で実際の画面から撮る（`scripts/thumbs/scenes.ts` に台本を足す）。

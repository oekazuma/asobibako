# アニマルサバイバー 限界突破 設計

## 目的

ヴァンパイアサバイバーのリミットブレイクのように、武器とパッシブが全部埋まったあとも、武器の能力を 1 つずつ上げ続けられるようにする。延長戦を長く遊ぶほど、自分の組み立てが尖っていく楽しさを出す。

## 札

- 武器とパッシブが全部 Lv の上限まで埋まると、3 択と宝箱の中身は「持っている武器 1 つ × 能力 1 つ」を上げる限界突破の札になる。武器は進化形・合体武器・専用進化形も含む。
- 上限は付けない。1 回の上がり幅は小さめで一定。

| 能力     | 1 回の上がり幅      | 出る武器                                   |
| -------- | ------------------- | ------------------------------------------ |
| ダメージ | +10%                | すべて                                     |
| 待ち時間 | −5%（掛け算で縮む） | すべて                                     |
| 大きさ   | +8%                 | すべて                                     |
| 速さ     | +10%                | 弾・ブーメラン・魚・羽根など、動く攻撃だけ |
| 時間     | +10%                | 羽根・炎・ツタ・輪など、残る攻撃だけ       |
| 数       | +1                  | すべて（ほかの札より出にくい）             |

- 「最大 HP +10 と全回復」の札は候補に残し、3 択に混ざることがある（肉が出ない回は回復なし）。「攻撃 +5%」と「コイン +20」の札はなくす。
- 札には、上げる武器と能力と、今までに上げた回数を出す（例: 「骨の魚群 ダメージ +10%（今 +3 → +4）」）。
- 引き直す・飛ばすは使える。除外は出さない。
- 合体武器は、上げた能力が 2 つの部品の両方に効く。
- 一時停止の画面の武器の並びに、上げた回数の合計を「+12」のように添える。
- 協力プレイでは、今の 3 択と同じく、動物ごとに自分の武器を上げる。

## 作り

- 3 択の画面（`LevelUp.svelte`）は 199 行なので、札の文を作るところを別のファイルへ移してから、限界突破の札を足す。

## 確かめ方

- 札の出方（埋まったときだけ・武器の種類で出る能力・数が出にくい）と、上げた能力が武器の撃ち方（合体武器の両方の部品にも）に効くことを vitest で確かめる。
- ボットで延長戦まで遊ばせ、今のごほうびと限界突破で、延長戦で生き延びる時間と 1 回のコインを比べる。コイン稼ぎが楽になりすぎるなら上がり幅を下げる。

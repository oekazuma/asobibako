# Animal Survivors 一時停止と積み上げ 設計

## ねらい

遊んでいる最中の隅のボタン（✕ で確かめずにタイトルへ、↻ でキャラ選択へ）は押し間違えると 15 分の回が消える。これを一時停止のメニューに置きかえる。あわせて、クリアしてもまた 1 からという感じを減らすため、遊ぶたびにコインが貯まって永久に強くなる店（パワーアップ）と、実績を足す。遊ぶのは大人（利用者と妻）で、端末は iPad Air。

## 決めたこと

| 問い             | 決めたこと                                                       |
| ---------------- | ---------------------------------------------------------------- |
| 積み上げ         | 永久強化（コインと店）と実績                                     |
| コイン           | 敵や宝箱が落とす品を拾う。HUD に枚数を出す                       |
| やめた回         | 倒れたときと同じ。コイン・撃破数・実績を記録してリザルトを出す   |
| 押し間違いの防ぎ | 「やり直す」「やめる」は確かめの画面を出してから効く             |
| 範囲             | Animal Survivors だけ。ほかの 1 人用ゲームの隅のボタンは今のまま |

## 1. 一時停止のメニュー

### 隅のボタン

- `SoloMeta` に `ownMenu?: boolean` を足す。立っているゲームでは、`SoloShell` が遊んでいるあいだ（`screen === 'playing'`）の ✕ と ↻ を出さない。
- `SoloProps` に `onquit?: () => void` を足す。呼ぶと `SoloShell` はタイトルへ戻る。
- キャラ選択の左上に ✕（確かめずに `onquit`。失うものが無いため）、右上に音の入り切りを置く。下に「パワーアップ」と「実績」の入口を置く。
- 遊んでいる最中は、左上にゲームの見た目に合わせた一時停止のボタン「Ⅱ」だけを置く。PC では Esc か P キーでも開く。
- レベルアップと宝箱の画面のあいだはもう止まっているので、「Ⅱ」を出さない。
- 画面が隠れたら、戻ったときには一時停止のメニューが開いている（急に再開しない）。

### メニューの中身

- 見出しは「ポーズ」。今の時間・レベル・この回のコインを出す。
- 持っている武器とパッシブを、レベル付きで並べる。
- ボタンは「つづける」（すぐ効く）・「音 オン／オフ」・「最初からやり直す」・「やめる」。
- 「最初からやり直す」と「やめる」は、確かめの画面（「本当にやめますか？」と「やめる」「つづける」）を出す。確かめの画面は出てから 350ms は押せない（`Lock`）。2 度押しで決まらないようにするため。
- 「やめる」は倒れたときと同じに扱う。記録してからリザルトを出す。
- 「最初からやり直す」も記録してから、リザルトを出さずに同じ動物ですぐ始める（記録しないと、やり直すたびにコインが消えるため）。

## 2. コイン

| 出どころ       | 枚数             |
| -------------- | ---------------- |
| ふつうの敵     | 3% の確率で 1 枚 |
| 金色の強化個体 | 必ず 5 枚        |
| ボス           | 大袋で 50 枚     |
| 宝箱           | 10 枚            |
| 15 分クリア    | ボーナス 100 枚  |

- コインは `Item` の `coin`（値を持つ）として床に落ち、経験値の玉と同じ範囲で吸い寄せられ、磁石でも集まる。拾うと音が鳴る。
- 宝箱の 10 枚は開けたときに、クリアのボーナスは終わったときに足す。
- 「強欲」の段で枚数が増える（端数は切り捨て、1 枚の敵からは 1 枚のまま、合計に掛ける）。
- HUD にコインの絵とこの回の枚数を出す。リザルトに「+123 コイン（もちもの 1,234）」を出す。
- 1 回の目安は、10 分ほど生き延びて 200〜300 枚。

## 3. 店（パワーアップ）

| id       | 名前     | 1 段ごと                                                              | 最大 |
| -------- | -------- | --------------------------------------------------------------------- | ---- |
| `might`  | 攻撃     | +5%                                                                   | 5    |
| `maxHp`  | 最大 HP  | +10                                                                   | 5    |
| `speed`  | 速さ     | +4%                                                                   | 5    |
| `armor`  | 防御     | 受けるダメージ -1                                                     | 3    |
| `regen`  | 回復     | 毎秒 HP +0.1                                                          | 5    |
| `magnet` | 拾う範囲 | +10%                                                                  | 5    |
| `growth` | 経験値   | +5%                                                                   | 5    |
| `crit`   | 会心     | +2%                                                                   | 5    |
| `greed`  | 強欲     | コイン +10%                                                           | 5    |
| `reroll` | リロール | 1 回の遊びで 3 択の引き直し 1 回                                      | 3    |
| `revive` | 復活     | 倒れたとき 1 回だけ HP 半分で起き上がる（周りを吹き飛ばし、2 秒無敵） | 1    |

- 値段は「基本の値段 × 次の段」。全部そろえるのに 30 回ほど遊ぶ見込みで、基本の値段はボットの稼ぎから決める。
- 強化は動物の基本の値に足し、動物の `bonus` とレベルアップのパッシブはその上に重なる。
- リロールは、レベルアップの画面に「引き直す（のこり N）」を出す。押すと 3 択を引き直す。
- 店の画面は、品のアイコン・名前・段（■■□□□）・次の段で増えるもの・値段を並べる。足りない品と最大の段の品は押せない。払い戻しは作らない。
- アイコンは今のパッシブの絵を使い、強欲（コイン）・リロール・復活の 3 つと、床のコインの絵を新しく描く。描く前に見本を見せる。
- 強化なしの強さは変えない。全部そろえた状態でボットに遊ばせ、15 分を楽に越えすぎないよう上げ幅を整える。

## 4. 実績

| 種類           | 実績                    | ごほうび      |
| -------------- | ----------------------- | ------------- |
| 生存           | 1 分生き延びる          | 10            |
|                | 5 分生き延びる          | 50 ＋ キツネ  |
|                | 10 分生き延びる         | 100           |
|                | 15 分生き延びてクリア   | 200 ＋ パンダ |
| 撃破（1 回で） | 100 体                  | 20            |
|                | 1000 体                 | 100           |
|                | 3000 体                 | 200           |
| 撃破（合計）   | 3000 体                 | 100 ＋ ウサギ |
|                | 30000 体                | 300           |
| ボス           | 巨大ベアを倒す          | 100 ＋ クマ   |
|                | 女王グモを倒す          | 150           |
|                | 1 回で 2 体とも倒す     | 200           |
| 成長           | Lv20 になる             | 30            |
|                | Lv50 になる             | 150           |
|                | 武器を 1 つ Lv5 にする  | 50            |
|                | 武器 3 つを Lv5 にする  | 150           |
| 動物           | 7 匹がそろう            | 200           |
|                | 3 匹でクリア            | 150           |
|                | 7 匹すべてでクリア      | 500           |
| 宝箱           | 合計 10 個開ける        | 50            |
| 店             | はじめてのパワーアップ  | 20            |
|                | どれか 1 品を最大の段に | 100           |
|                | 全部の品を最大の段に    | 500           |

ごほうびの数字はコインの枚数で、全部で 23 個。

- 今の 4 匹の解放の条件（`records.ts` の `UNLOCK`）は、この表のごほうびに移す。解放した動物はそのまま残す。
- 表は `achievements.ts` に持ち、1 行が id・名前・条件・ごほうび（コインと、動物があれば動物）・途中経過（合計の実績だけ、「1,234 / 3,000」）を持つ。条件は記録とその回のまとめを見る純粋な関数。
- 判定は 1 回が終わったとき（倒れた・やめた・やり直した・クリア）と、店で買ったとき。同じ実績は 2 度渡さない。ごほうびは自動で受け取る。
- リザルトに、その回に達成した実績を「実績達成！ 巨大ベアを倒す　+100」と並べる（今の「NEW! 〇〇が仲間になった」の帯と並べる）。店で買って達成したときは、店の画面に同じ帯を出す。
- 実績の画面は、上に「12 / 23 達成」、達成したものは色付きでチェック、まだのものは灰色で条件・ごほうび・途中経過を出す。隠し実績は置かない。

## 5. 記録

今の `asobibako:animal-survivors` に足す。

| 項目        | 中身              |
| ----------- | ----------------- |
| `coins`     | もちもののコイン  |
| `ranks`     | 店の品ごとの段    |
| `achieved`  | 達成した実績の id |
| `clearedBy` | クリアした動物    |
| `chests`    | 開けた宝箱の合計  |

- 古い保存は、足した項目を 0 と空で読む。解放した動物は残す。次に 1 回遊び終えたとき、すでに満たしている実績（5 分・ボスなど）はまとめて達成になり、コインも入る。
- 壊れた値（負の数・数でないもの・知らない id・最大を越えた段）は読み飛ばすか 0 にする。
- 記録はリザルトを待たずに決着したとき（倒れた・やめた・やり直した・クリア）に取る。
- 名前が `asobibako:` で始まり `NOT_RECORDS` に入らないので、バックアップと IndexedDB の控えにそのまま入る。

## 7. 確かめ方

- vitest で次を確かめる。
  - 値段と、買える・買えない（足りない・最大の段）。
  - 強化の段が強さに入る。
  - 実績の判定と、同じ実績を 2 度渡さないこと、合計の途中経過。
  - 古い保存と壊れた保存を読めて、解放した動物が残ること。
  - 復活が 1 回だけ効き、リロールの数が減ること。
  - コインの落ち方と強欲の掛け方。
  - `ownMenu` のゲームで `SoloShell` が遊んでいるあいだ隅のボタンを出さず、`onquit` でタイトルへ戻ること。
- headless Chrome で、一時停止 → やめる → 確かめ → リザルト、やり直す、隠れて戻るとメニューが開いていること、店で買う、実績の画面、iPhone の幅の画面を撮る。
- ボットで、強化なしの強さが変わっていないことと、全部そろえたときの生存時間を測る。
- `pnpm verify` を通す。

## 8. 調整の結果

ボット（7 匹 × 2 つの選び方 × 8 回、コインも拾う）で測った。

| 状態       | 生存の中央値 | クリア   | 1 回のコインの中央値 |
| ---------- | ------------ | -------- | -------------------- |
| 強化なし   | 609〜900 秒  | 0〜7 / 8 | 193（22〜1,336）     |
| 全部を最大 | 900 秒       | 6〜8 / 8 | 1,600〜2,200         |

- 強化なしの生存は前の幅（565〜900 秒）から大きく変わらない。
- コインは強くなるほど長く生き延びて多く入る。最初の値段（合計 9,650）では、稼ぎが強化の割合に比べて伸びるとみて、ボットは約 13 回で全部そろう。人はボットより早く倒れて稼ぎも少ないので、基本の値段を一律 1.5 倍（合計 14,475）にした。実績のコインは合計 3,430。
- 全部を最大にするとボットはほぼ毎回クリアする。ボットは人より上手に逃げるので、ここは実機の手ざわりで見る。

# アニマルサバイバー 2 匹で運ぶ重い宝箱 設計

## 目的

協力プレイに、2 人がそろっていないと進まない場面を作る。重い宝箱は 2 匹がそばにいるときだけ動き、大群の中を寄り添って祭壇まで運ぶと、2 匹とも宝箱をもらえる。

協力プレイを良くする 4 つ（連携の技・助け合い・2 人でないと解けないもの・2 人の記録とごほうび）のうちの 3 つめ。1 人で遊ぶときは何も変えない。

## 決まり

### 出方

- 協力プレイのときは、ステージの出来事のうち宝の地図（1 回に 2 度）が重い宝箱に変わる。1 人のときは宝の地図のまま。
- 2 匹のまん中から 120〜160 ドット先に重い宝箱を、そこからさらに 250〜300 ドット先に祭壇を置く。どちらも障害物の外に出す。
- 帯で「重い宝箱だ！ 2 匹で祭壇まで運ぼう」と出す。

### 運び方

- 2 匹がどちらも立っていて、宝箱から 36 ドット以内にいるあいだだけ、宝箱が 2 匹のまん中へ向かって動く。速さはふつうに歩く速さの 5.5 割。障害物には入らない。
- 片方が離れる・倒れるとその場で止まる。
- 宝箱のまわりの輪は、寄っている動物 1 匹ごとに半分ずつ光る（2 匹そろうと全部）。
- 宝箱が祭壇に届くと、2 匹それぞれに中身 3 つの宝箱が 1 つずつ入り、コインが 50 枚入る。
- 出てから 60 秒で間に合わなければ「宝箱が沈んでしまった…」と出して消す。時計の品で止まっているあいだは減らない。

### 見た目

- 宝箱は今の宝箱の絵を 2 倍で描く。祭壇は地面に光る輪で描く（新しいドット絵は作らない）。
- 画面の外にあるときは、宝の地図と同じく端の矢印に宝箱か祭壇の印と残り秒を添える。運んでいるあいだは、宝箱から祭壇への向きに小さな矢印を出す。

## 仕組み

| 置き場所                | 持つもの                                                                            |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `carry.ts`（新規）      | `World.carry`（宝箱と祭壇の位置・残り秒・寄っている動物）、置く・運ぶ・届く・消える |
| `events.ts`             | 協力プレイの宝の地図を重い宝箱に変える                                              |
| `heroes.ts`             | 動物ごとの「次に開ける宝箱は中身 3 つ」の数                                         |
| `chest.ts`              | `openChest` がその数を見て中身を 3 つにする                                         |
| `draw-carry.ts`（新規） | 宝箱・祭壇・輪・矢印                                                                |
| `snap.ts`               | `carry` を運ぶ。形が変わるので `COOP_VERSION` を 5 にする                           |

## 確かめ方

- vitest で次を確かめる。
  - 1 人では重い宝箱が出ず、宝の地図のまま。
  - 2 匹がそばにいるときだけ動き、片方が離れる・倒れると止まる。
  - 祭壇に届くと、2 匹とも中身 3 つの宝箱とコイン 50 枚がもらえる。
  - 60 秒で消え、時計の品のあいだは減らない。
  - 動かしても障害物の中に入らない。
  - snap で子の画面にも宝箱・祭壇・残り秒が届く。
- 2 台の通しで、運んでいるところと届いたところを撮って見せる。

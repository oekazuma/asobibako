# Animal Survivors 3 面め「雪山」 設計

## ねらい

面が森と夜の墓地の 2 つしかなく、遊び慣れると同じ景色が続く。見た目も戦い方も違う 3 面めを足す。墓地は森と同じ戦い方で敵と見た目を替えた面だったが、雪山は吹雪と新しいボス 2 体で、戦い方そのものに変化を付ける。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い   | 決めたこと                                               |
| ------ | -------------------------------------------------------- |
| 場所   | 雪山                                                     |
| 仕掛け | 吹雪（ときどき来て、画面がかすみ、風で流される）         |
| ボス   | 大雪男と氷の竜。どちらも今のボスの動きを使わず新しく作る |

## 1. 面の中身

- 面の表は `stages/snow.ts`（id `snow`、絵 `snow`、曲 `snow`）。墓地をクリアすると選べる（`unlock`）。コインは 2 倍。
- 時刻の流れ（ふつうの敵の出現・1 分ごとの出来事・ヌシ・13:00 の面の主・きらきらハリネズミ）は森の表を写し、敵を入れ替える。
- ふつうの敵 7 種を雪の顔ぶれにする。動き方（`move`）は入れ替える前の敵と同じで、体力・速さは同じ表から少しずつ変える。

| 森の敵   | 雪山の敵 | 動き方         |
| -------- | -------- | -------------- |
| ネズミ   | ペンギン | 追ってくる     |
| コウモリ | 雪ん子   | 波打って飛ぶ   |
| ヘビ     | アザラシ | くねって進む   |
| イモムシ | 雪だるま | 重くてゆっくり |
| イノシシ | トナカイ | 突進           |
| クモ     | 雪ウサギ | 跳ねる         |
| ワニ     | シロクマ | 硬くて遅い     |

- ヌシは雪だるま・トナカイ・シロクマから時刻ごとに選ぶ。
- 強さは墓地より一段上げる。ボットで、強化なしのクリアが墓地（12/84）より少なく、店を半分買えば多くの回でクリアできる（墓地の半分買いは 74/84）くらいに合わせる。

## 2. 吹雪

- 1 回の遊びで 4 回、150・330・510・690 秒に来る（ボスとヌシの時刻を避ける）。面の表の `storms`。
- 3 秒前に帯「吹雪が来る！」を出し、20 秒続く。
- 風の向きは吹雪ごとに乱数で決める。
- 吹雪のあいだは次のようにする。
  - 自分は風下へ、ふつうの速さの 2 割で流される。
  - 敵は動く向きと風の向きが近いほど速く、逆なら遅い（最大 ±4 割）。ボスとランタンは流されない。
  - 画面が白くかすみ、横なぐりの雪が風の向きに流れる。HUD はかすめない。
- 一時停止・3 択・宝箱のあいだは吹雪の残り時間を進めない（ゲームの時間で数える）。

## 3. ボス

### 5:00 大雪男（`ai: 'yeti'`）

- ふだんはゆっくり追ってくる。4 秒ごとに次の 2 つを交互に使う。
- 雪玉。自分のほうへ大きな雪玉を転がす。雪玉は転がるほど大きくなり（半径 6 から 14 まで）、当たると痛く、4 秒で溶ける。
- 飛びかかり。自分のいる位置に影の予告を 1 秒出してから、高く跳んでそこへ落ちる。着地のまわり（半径 48）にダメージを与え、ちび雪だるまを 3 匹出す。跳んでいるあいだは当たり判定がない。

### 10:00 氷の竜（`ai: 'dragon'`）

- 女王グモのように少し離れた所を保って回り込む。3.5 秒ごとに次の 2 つを交互に使う。
- 氷の柱。自分の今の位置と、そのまわり 4 か所に予告の円を出し、1 秒後に氷の柱が突き出して、円の中にいると痛い。
- 冷たい息。自分のほうへ向いた扇形（60 度、長さ 120）の予告を 0.8 秒出し、そのあと 1 秒息を吐く。扇の中にいると痛く、少し遅くなる（女王グモの糸と同じ遅さ）。

### 面の主

- 13:00 に大雪男と氷の竜が体力 1.5 倍でいっしょに出る（森・墓地と同じ）。

## 4. 絵と音

- 地面（雪の原・踏まれた雪）と飾り（雪をかぶった針葉樹・岩・氷のかけら・雪の吹きだまり）。
- 敵 7 種（2 コマ）、ボス 2 体（大雪男は跳ぶコマを含む 3 コマ、氷の竜は 2 コマ）、ちび雪だるま、雪玉と氷の柱と息の絵。
- 絵は 3 回に分けて見本を見せて止まる。地面と飾り、敵 7 種、ボス 2 体と弾の順。
- 曲は `songs.ts` に雪の面の曲を足す（明るめで少し寂しい、鈴の音）。
- 面を選ぶ画面に 3 枚めの札を足す。
- 実績を 2 つ足す。「雪山をクリア」（コイン 400）と「雪山の 2 体のボスを倒す」（コイン 300）。

## 6. 確かめ方

- vitest で次を確かめる。
  - 雪山の表の敵とボスがすべて敵の表にあり、出来事とヌシの時刻が森と同じ。
  - 墓地をクリアするまで雪山を選べない。
  - 吹雪が表の時刻の 3 秒前に予告され、20 秒続き、そのあいだ自分が風下へ流され、敵が風で速さを変え、ボスとランタンは流されない。一時停止のあいだは残りが減らない。
  - 大雪男の雪玉が大きくなって当たり、飛びかかりは予告の 1 秒後に落ちて、跳んでいるあいだは当たらない。
  - 氷の竜の柱は円の中だけに当たり、息は扇の中だけに当たって遅くする。
  - 予告のあいだにボスが倒れたら予告ごと消える。
- headless Chrome で、雪の地面・吹雪・2 体のボスの攻撃を撮る。
- ボットで、強化なし・店を半分の雪山の生存とクリアの割合を測る。
- `pnpm verify` を通す。

# Animal Survivors 1 面のボスと育ちの見直し 設計

## ねらい

1 面を遊んだ感想は 3 つ。10 分ほどで武器とパッシブが全部上限になり、上げるものがなくなる。ボスが弱い。ボスの種類が少なく、大きくて怖いボスもほしい。

育ちを遅くして 15 分の最後まで「次に何を上げるか」を選ぶ楽しみを残し、全部埋まったあとも 3 択にうれしいものを出す。ボスは硬く、攻撃も激しくする。1 面のボスを 6 体にし、新しい 4 体は大きくて怖い姿にする。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い       | 決めたこと                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| 上限       | 育ちを遅くして 15 分ごろに埋まるようにし、埋まったあとの 3 択はごほうびにする                           |
| ボスの強さ | 体力を上げ、攻撃の数と速さも増やす                                                                      |
| 1 面のボス | 6 体。3:00 巨大ベア、6:00 女王グモ、9:00 大イノシシ、12:00 大ワシ、13:30 の面の主は大木のおばけと大ヘビ |
| 新しいボス | 大木のおばけ・大イノシシ・大ワシ・大ヘビ。絵は見本を見せて止まる                                        |

## 1. 育ち

- 経験値の伸び（`drops.ts` の `xpNeed`）と、宝箱で上がる数（`chest.ts` の `chestSize`、今は 1・3・5 が 6・3・1 割）を見直す。
- 目安は、ボットが武器を優先して選んだとき、10:00 で埋まった割合（取った Lv の合計 ÷ 枠の Lv の合計）が 6〜7 割、全部埋まるのが 14〜15 分。人はボットより玉を拾うので、ボットで少し遅めに合わせる。
- 全部埋まったあとの 3 択は、肉と経験値の袋の代わりに次の 3 枚にする。
  - 攻撃 +5%（その回だけ。何回でも重なる）
  - 最大 HP +10 と全回復（その回だけ）
  - コイン +20（強欲と面の倍率は掛かる）
- 宝箱で上げるものがなくなったときも、同じごほうびから選ぶ。

## 2. ボスの強さ

- 体力の倍率（`bosses.ts` の `BOSS_HP`）を上げ、攻撃の間を縮め、飛び道具の数を増やす。
- 目安は、店を半分にしたボットで、ボスを倒すまでの秒の中央値が 40〜70 秒、面の主は 2 体で 90 秒前後。
- 今の巨大ベアと女王グモも同じ考えで強める。墓地と雪山のボスは、今の数字のまま（その面のボットの結果を見て、ずれたら同じ式で直す）。

## 3. 1 面のボス

| 時刻  | ボス                           | 二つ名             |
| ----- | ------------------------------ | ------------------ |
| 3:00  | 巨大ベア                       | 森の暴れん坊       |
| 6:00  | 女王グモ                       | 糸を操る女王       |
| 9:00  | 大イノシシ                     | 地鳴りの突進王     |
| 12:00 | 大ワシ                         | 空からの狩人       |
| 13:30 | 大木のおばけ・大ヘビ（面の主） | 森の古木・森のぬし |

- 今の 9:00 と 12:00 の「同じ 2 体が攻撃を速めてまた出る」は、新しいボスに置きかえる。
- 延長戦は 6 体を順に 1 分ごとに出す。

## 4. 新しい 4 体の動き

どれも予告を出してから当たる（今のボスと同じく `World.hazards` に置く）。ボスは吹き飛ばされず、押し合いでも押されない。

- 大イノシシ（画面の幅の半分ほど）：足を踏み鳴らして向きを決める予告（矢印、1 秒）のあと、画面の端から端まで一直線に突進する。3 回続けて突進したあと少し休む。突進の通ったあとに土ぼこりを残し、その中は遅くなる。
- 大ワシ（翼を広げて画面の幅の 3 分の 2 ほど）：画面の外から影が自分に近づき（予告の円、1.2 秒）、急降下する。降りたあと羽根を 8 方向にばらまく。空にいるあいだは攻撃が当たらない（大雪男の宙と同じ）。
- 大木のおばけ（画面の 3 分の 1 ほどの高さ）：ゆっくりしか動かない。自分の足もとの近くに根っこの予告（円、1 秒）を 3〜5 か所出し、地面から根っこが突き出す。ときどき実を落とし、実からちびおばけ（手下）が出る。
- 大ヘビ（頭と 10 節ほどの体）：頭が自分を追い、体は頭の通った道をなぞる。体に触れても痛い。ときどき頭を引いてから噛みつきの突進（予告の扇、0.8 秒）。体の節にも攻撃が当たり、頭への当たりと同じに体力が減る。

## 5. 絵

- 新しい 4 体は、今のボス（24〜32 ドット）より大きく描く（大木のおばけ 48、大イノシシ 40、大ワシ 48、大ヘビの頭 24・節 16）。怖さを出しつつ、目やふちの描き方は今のボスにそろえる。
- 描く前に見本を見せて止まる。延ばしていた狼の顔とパッシブのアイコン（鼻・毛皮・ひげ）の見本も、同じときに見せる。

## 7. 確かめ方

- vitest で次を確かめる。
  - 1 面のボスの並びと二つ名、延長戦の順。
  - 新しい 4 体の予告と当たり（予告が終わってから当たる、空・突進の休み・体の節の当たり）。
  - 全部埋まったあとの 3 択と宝箱のごほうび、その回だけの強化が重なる。
- ボットで、10:00 の埋まった割合と全部埋まる時刻、ボスを倒すまでの秒、店を半分と全部の 1 面のクリアの割合を測り、§1・§2 の目安に合わせる。今の強化なしのクリア 40/84 から大きく下がりすぎないよう見る。
- headless Chrome で新しい 4 体の登場と攻撃を撮る。
- `pnpm verify` を通す。

## 8. 調整の結果

### 育ち

ボットに武器を優先して選ばせ、犬・キツネ・パンダの 1 面で、10:00 に埋まった割合（取った Lv の合計 ÷ 枠の Lv の合計）と全部埋まる時刻を測った。

| 数字                              | 店を半分の 10:00 | 全部埋まる時刻 | 店なしのクリア           |
| --------------------------------- | ---------------- | -------------- | ------------------------ |
| 前（宝箱 6・3・1 割）             | 100%             | 568 秒         | 11/18                    |
| 伸びを強め、宝箱 8.5・1.3・0.2 割 | 82%              | 707 秒         | 5/18                     |
| 序盤（Lv20 まで）を少し戻す       | 83%              | 654 秒         | 7/18（ボスを強めたあと） |

- 10:00 までに上がる約 46 段のうち、約 15 段は宝箱（11 個ほど）から来る。Lv30 から上の伸びは 10:00 にほとんど効かない。
- これ以上遅くすると店なしで遊ぶときに弱くなりすぎるので、全部埋まるのは 11 分ごろで止め、そのあとは攻撃 +5% が重なるごほうびで強くなり続けるようにした（目安の 14〜15 分には届いていない）。

### ボスの強さ

体力の倍率 `BOSS_HP` を 0.7 から 1.2 にし、巨大ベアの攻撃の間を 4 秒から 3.2 秒、女王グモの糸の玉を 5 発から 7 発・3 秒から 2.4 秒ごとにした。女王グモは離れて回り込むので倒すのに長くかかり、元の体力を 900 から 550 に下げた。新しい 4 体の元の体力は、大イノシシ 1400・大ワシ 1400・大木のおばけ 1500・大ヘビ 2200。

| ボス（店を半分） | 倒すまでの秒の中央値             |
| ---------------- | -------------------------------- |
| 巨大ベア         | 46                               |
| 女王グモ         | 67                               |
| 大イノシシ       | 52                               |
| 大ワシ           | 44                               |
| 大ヘビ           | 31（このあと体力を 2200 にした） |
| 大木のおばけ     | 48                               |

- 範囲の一撃が大ヘビの頭と 10 の節にまとめて当たり 11 倍のダメージになっていたので、同じ時刻の同じ武器は 1 回にした（10 秒 → 31 秒）。
- 1 面のクリアは店を半分で 16/18、店なしで 7/18。墓地は店を半分で 14/18、店なしで 1/18、雪山は店を半分で 15/18。

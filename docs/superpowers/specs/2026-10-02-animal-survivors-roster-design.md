# Animal Survivors 動物の追加 設計

## ねらい

Animal Survivors に、キツネ・クマ・ウサギ・パンダの 4 匹を足す。最初は今の 3 匹（犬・猫・狼）だけを選べ、新しい 4 匹は遊んで条件を満たすと仲間になる。くり返し遊ぶ目標を増やす。

## 決めたこと

| 問い       | 決めたこと                                                                     |
| ---------- | ------------------------------------------------------------------------------ |
| 何匹       | 4 匹（キツネ・クマ・ウサギ・パンダ）                                           |
| 選べる時期 | 条件を満たすと解放。記録を端末に保存する                                       |
| 個性       | ステータス・最初の武器（今ある武器から）・特別な強み 1 つ（パッシブ 1 つぶん） |
| 絵         | 今の 3 匹と同じ 16×16 の手打ち。作る前に見本を見せる                           |

## 1. 4 匹

| id       | 名前   | 型           | HP  | 速さ | 攻撃 | 最初の武器 | 特別な強み                      |
| -------- | ------ | ------------ | --- | ---- | ---- | ---------- | ------------------------------- |
| `fox`    | キツネ | テクニック型 | 85  | 1.15 | 1.0  | `flame`    | 会心率 +10%（`crit: 0.1`）      |
| `bear`   | クマ   | タンク型     | 150 | 0.85 | 1.15 | `claw`     | 受けるダメージ -2（`armor: 2`） |
| `rabbit` | ウサギ | 逃げ足型     | 75  | 1.35 | 0.85 | `dash`     | 拾う範囲 +50%（`magnet: 0.5`）  |
| `panda`  | パンダ | 回復型       | 130 | 0.9  | 1.0  | `vine`     | 毎秒 HP +0.5（`regen: 0.5`）    |

- 特別な強みは `Animal.bonus`（`Partial<Stats>`）で持ち、`stats()` が基本値に足す。キャラ選択のカードに 1 行で出す。
- 動物の id `bear` は敵の巨大ベアの id と同じだが、表が別なのでぶつからない。

## 2. 解放と記録

| 動物   | 条件                             |
| ------ | -------------------------------- |
| キツネ | 5 分（300 秒）生き延びる         |
| クマ   | 巨大ベアを倒す                   |
| ウサギ | これまでの撃破数の合計が 3000 体 |
| パンダ | 15 分生き延びてクリアする        |

- 記録は localStorage の `asobibako:animal-survivors` に JSON で持つ。中身は、いちばん長い生存時間（`best`）・撃破数の合計（`kills`）・倒したボスの集合（`bosses`）・クリアの回数（`clears`）・解放した動物（`unlocked`）。
- 1 回が終わってリザルトを出すときに記録を更新し、新しく条件を満たした動物を解放する。読めない・壊れた保存は空の記録として扱い、落ちない。
- 名前が `asobibako:` で始まるので、今のバックアップと IndexedDB の控えにそのまま入る。`src/lib/backup.ts` の `NOT_RECORDS`（好みの設定）には入れないので、控えから戻すときの「記録あり」にも数えられる（変えるところは無い）。
- リザルトで、その回に解放した動物ごとに「NEW! キツネが仲間になった」とその動物の絵を出す。

## 3. キャラ選択

- 7 匹を縦に並べる。カードは今より小さく（絵 `min(14cqw, 8cqh, 80px)`、ステータスの棒は細く）し、画面に収まらなければスクロールする（`as-screen` はすでに `touch-action: pan-y`）。
- 解放前の動物は、絵を黒い影（`filter: brightness(0)`）にし、名前を「？？？」、ステータスと武器の代わりに解放の条件を出し、押せなくする（`disabled`）。
- 特別な強みがある動物は、武器の下に「とくい: 会心率 +10%」のように 1 行出す。

## 4. しくみ

| ファイル            | 変えること                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------ |
| `animals.ts`        | 4 匹と `bonus`、`AnimalId` に 4 つ、解放の条件の文（`unlock`）                                               |
| `passives.ts`       | `stats()` が `bonus` を足す                                                                                  |
| `records.ts`（新）  | `Records` の型、`loadRecords()`・`saveRecords()`、`record(r, run)`（更新して新しく解放した動物を返す。純粋） |
| `world.ts`          | `World.bossKills`（その回に倒したボス）、`RunSummary.bosses`                                                 |
| `Survivors.svelte`  | リザルトを出すときに記録を更新して保存し、解放した動物を `Result` に渡す                                     |
| `CharSelect.svelte` | 7 匹、解放前の表示                                                                                           |
| `Result.svelte`     | NEW の帯                                                                                                     |
| `art/animals.ts`    | 4 匹の絵                                                                                                     |

## 5. 確かめ方

- vitest で次を確かめる。
  - 4 匹のステータスと特別な強みが `stats()` に入る。
  - `record()` が、生存時間・撃破数・ボス・クリアを更新し、条件を満たした動物だけを新しく解放し、すでに解放したものは返さない。
  - 壊れた保存を読んでも空の記録になる。
- headless Chrome で、キャラ選択（解放前と後）とリザルトの NEW を撮る。
- ボットで 4 匹の生存時間の中央値が、今の 3 匹の幅（9〜15 分）から大きく外れないことを測る。
- `pnpm verify` を通す。

## 6. 調整の結果

ボットで 4 匹の生存時間の中央値は 10.4〜15 分で、今の 3 匹の幅（9.4〜15 分）に収まった。パンダは自然回復と HP でいちばん強めだが、クリアして仲間になるごほうびなので、そのままにした。

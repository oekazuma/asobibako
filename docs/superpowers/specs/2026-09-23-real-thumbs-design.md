# 一覧のカードを実際のゲーム画面にする 設計

一覧のカードの絵を、各ゲームを実際に動かして撮った画面の画像にする。いまの CSS で描いた `Thumb.svelte` は実際の画面と印象がずれるので置き換える。

## 画像

| 項目       | 値                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 置き場所   | `static/thumbs/<id>.webp`                                                                                                         |
| 大きさ     | 幅 680px・高さ 256px（カードの絵の枠 340 × 128 の 2 倍）                                                                          |
| 形式       | WebP（品質 0.85 前後）。1 枚 60KB 以下を目安                                                                                      |
| 表示       | `GameCard.svelte` が `<img>` で出し、`object-fit: cover` で枠の幅に合わせて左右を切り詰める。`$app/paths` の `asset()` で参照する |
| オフライン | `static/` の中身は Service Worker の `files` に入るので、そのままキャッシュされる                                                 |

`Thumb.svelte` は全ゲームから消し、`GameMeta` の `Thumb` もなくす。画像の `alt` は空にし、カードの見出しに名前を任せる。

## 撮り方

`pnpm thumbs`（`node scripts/thumbs.ts`）の 1 コマンドで全ゲームを撮り直す。本番のゲームのコードには撮影用の分岐を足さず、撮影スクリプトの側で実際のゲームを操作して場面を作る。

| 手順 | 内容                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| 1    | Vite の dev サーバーを空きポートで起動する                                                                                  |
| 2    | `playwright-core` で端末の Google Chrome（`channel: 'chrome'`）を開く。iPad 縦（768 × 1024）で、タッチ端末として開く        |
| 3    | ページを開く前に、`Math.random` を種つきの乱数に差し替え、`page.clock` で時計を止める。場面は毎回同じになる                 |
| 4    | 1 人用は `localStorage` の到達レベルを入れてからタイトルの「タップで スタート」を押す。2 人用は両側を同時に長押しして始める |
| 5    | ゲームごとの場面の台本どおりに、`pointerId` つきの Pointer Events を送り、`page.clock` で時間を進める                       |
| 6    | 決めた範囲を切り出して撮り、ページの中の canvas で WebP にして保存する                                                      |

場面の台本はゲームごとに `scripts/thumbs/scenes.ts` に置く。ゲームの見た目や操作が変わって場面が崩れたら、台本を直して撮り直す。

`playwright-core` は devDependencies に足す（ブラウザはダウンロードせず、端末の Chrome を使う）。撮るのは開発者の手元だけで、CI では撮らない。画像はリポジトリに入れる。

## 撮る場面

1 人用の場面は次のとおり。

| ゲーム         | 場面                                                                              | 切り出す部分                     |
| -------------- | --------------------------------------------------------------------------------- | -------------------------------- |
| ピンぬき       | ピンを 1 本抜いた直後で、金貨が流れ落ちている。下にマグマの部屋、その下に男の子   | 流れる金貨から男の子まで         |
| 数のゲート     | 「×2」と「+N」の門の直前で、仲間の群れが走っている。奥に敵の群れと城              | 群れと門を中心に奥の城まで       |
| 線を引いて守る | 犬をドームの線で囲み、ハチが何匹か飛んできてはね返っている                        | 線とハチと犬                     |
| 雪原サバイバル | 主人公がクマに斧を振っていて、手前にたき火と客が並ぶキャンプが見える              | 狩り場の下半分からキャンプまで   |
| はいしゃさん   | 虫歯から出たバイキンをピンセットでつまみ、ゴミ箱へ運んでいる。吹き出しが出ている  | 顔と口とゴミ箱、道具トレイの一部 |
| らくがきムシ   | 描いたまるとせんがムシになって歩き出し、まだムシになっていないらくがきも 1 つある | 画面の中央                       |

2 人用の場面は次のとおり。手前（1P）側を中心に切り出し、向かい側の気配が少し見えるようにする。

| ゲーム         | 場面                                                                                                    | 切り出す部分                         |
| -------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| せめぎあい     | 境界線が少し向こうへ押し込まれ、手前の陣地に玉が 3 つ（1 つは長押し中で輪がたまっている）。境界に金の玉 | 境界線を中心に手前の陣地を多め       |
| ばくだんリレー | 熱く赤く光る爆弾がはじかれて境界線を越えていく。両側のメーターが見える                                  | 爆弾と境界線と両側のメーター         |
| ホッケー       | 手前のマレットがパックを打った瞬間で、パックが相手のゴールへ向かう                                      | 手前のマレットから相手のゴール口まで |
| 虫送り         | 両側に虫がいて、手前から虫が 1 匹飛んでいく。カブトムシもいる                                           | 境界線をまたいで両側                 |
| ライトニング   | 真ん中にスワイプの指示が出ていて、手前の指が動き出したところ                                            | 真ん中の指示と両側                   |

## テスト

| テスト     | 確かめること                                                                               |
| ---------- | ------------------------------------------------------------------------------------------ |
| 画像の有無 | `games` のすべての id について `static/thumbs/<id>.webp` がある（`src/lib/games.test.ts`） |
| カード     | `GameCard` が `/thumbs/<id>.webp` の画像を出す（既存の `GameCard.svelte.test.ts` を直す）  |

撮影そのものは手元の操作なので自動テストにはせず、撮った画像を目で確かめる。

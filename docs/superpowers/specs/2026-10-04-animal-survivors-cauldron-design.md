# Animal Survivors 釜（のろいの強さ）設計

## ねらい

店を買い進めると、2.0（今の難しさ）では危なげなくクリアできるようになる。ステージを選んだあとに「まじょの釜」で強さを決め、コインを賭けて強い敵に挑めるようにする。強いほどコインと宝箱が増え、倒れると賭けたコインを失う。リスクとリターンを自分で選ぶ遊びにする。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い       | 決めたこと                                                       |
| ---------- | ---------------------------------------------------------------- |
| 選ぶ場所   | ステージを選んだあとの釜の画面（新・光神話パルテナの鏡の形）     |
| 賭け       | 2.0 より上げるとコインを賭ける。クリアで戻り、倒れると戻らない   |
| 強さの幅   | 0.0〜9.0。2.0 が今の難しさ                                       |
| ごほうび   | コインの倍率、宝箱の中身、クリアしたいちばん高い強さの記録と実績 |
| 装備の要素 | 釜のあとの別の回で考える（強さが高いほど良い装備が出る形）       |

## 1. 流れ

- キャラを選ぶ → ステージを選ぶ → 釜 → プレイ。釜の画面の ✕ はステージを選ぶ画面へ戻る。
- 日替わりお題の回は釜を出さず 2.0 で始める（しばりと重ねない）。
- 「もう一度」と「最初からやり直す」は同じ強さで、もう一度賭ける。コインが足りなければ払える強さまで下げる。
- 最後に選んだ強さを覚え、次に釜を開いたときの初めの位置にする（払えなければ払える強さまで）。

## 2. 強さで変わるもの

強さ `h`（0.0〜9.0、0.1 刻み）から `cauldron.ts` の純粋な関数が倍率を出す。数はボットで合わせる（7 章）。目安は次のとおり。

| もの               | 0.0      | 2.0（今）   | 9.0          |
| ------------------ | -------- | ----------- | ------------ |
| 敵の体力           | ×0.6     | ×1          | ×2.75        |
| 敵の攻撃           | ×0.7     | ×1          | ×1.8         |
| コイン             | ×0.5     | ×1          | ×4           |
| 宝箱の中身 1・3・5 | 今と同じ | 85・13・2 % | 50・35・15 % |
| 賭けるコイン       | 0        | 0           | 1500         |

- 体力と攻撃は面の表を写して `toughness` と `fury` に掛ける（お題のしばりと同じ写し方。ボスとヌシの体力も toughness を通るので強くなる）。出る数は変えない（iPad の重さを増やさない）。
- 2.0 から下は宝箱を今と同じにし、賭けない。
- コインの倍率は 1 回のコイン（`coinsOf`、延長戦のぶんも）に掛ける。図鑑・お題・実績のごほうびには掛けない。

## 3. 賭け

- 賭けるコインは強さから決まり、2.0 より上で増える。持っているコインより上には動かせない。
- 「はじめる」を押した時点で記録のコインから引いて保存する。遊んでいる途中でアプリが閉じても戻らない（倒れたのと同じ）。
- クリアすると、記録するときに賭けたコインを戻す（延長戦の終わりの記録では戻さない）。
- 倒れたとき・一時停止の「やめる」・「最初からやり直す」では戻さない（負けそうなときにやめて逃げられないように）。
- その回に拾ったコインは、倒れても倍率を掛けてもらえる。
- リザルトに「釜 4.5 クリア 賭け +300 戻る」か「賭けた 300 は戻らない」を出す。

## 4. 記録と実績

- ステージごとにクリアしたいちばん高い強さ（記録の `heat`）と、最後に選んだ強さ（`heatLast`）を覚える。古い記録は空と 2.0 で読む。
- ステージを選ぶ画面の札に「釜 6.5」を出す（クリアしたことがあるとき）。
- 実績を 2 つ足す。「釜 5.0 以上でクリア」「釜 9.0 でクリア」。

## 5. 画面

- 釜の画面（`Cauldron.svelte`）。上に釜のドット絵（強さで火の色が青 → 紫 → 赤に変わる）、大きな強さの数字、指で動かすつまみと −0.1・+0.1 のボタン、その下に変わるもの（敵の体力・攻撃・コイン・宝箱）と賭けるコイン、持っているコイン、「はじめる」。
- 釜のドット絵は新しい絵なので、作る前に見本を見せて決める。
- つまみは Pointer Events で動かし、横向きの回転は `BoardInput` と同じく盤面そのものの大きさで直す。

## 7. 確かめ方

- vitest で、強さごとの倍率と賭け、払える上限、宝箱の割合、引き落としと戻し（クリア・倒れた・やめた・延長戦）、古い記録の読み込み、お題の回は 2.0、を確かめる。
- ボットで、森・墓地・雪山の店半分と全部で、強さ 2.0・4.0・6.0・9.0 のクリアの割合と 1 回のコインを測る。店を全部買って 9.0 の森を 18 回中 2〜4 回クリアできるくらい、強さを上げるほど勝ったときのコインが賭けより十分大きくなるよう合わせる。
- `pnpm verify` を通す。

# アニマルサバイバー 地形の障害物 設計

## 目的

ヴァンパイアサバイバーのステージは、壁や狭い道で逃げ方が変わる。アニマルサバイバーの 4 ステージは見た目と敵が違うだけの広い野原なので、通れない障害物を置いて、障害物を盾にしたり追い込まれたりする駆け引きを足す。

## 決めたこと

| 項目             | 決め                                                                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 置くステージ     | 今の 4 ステージ（森・夜の墓地・雪山・火山）。新しいステージは足さない                                                                                           |
| 置き方           | 位置から決まるハッシュで、毎回同じ場所に置く（協力プレイでも 2 台で同じ）                                                                                       |
| 量               | 160 ドットごとの区画に、およそ 4 区画に 1 つ。始めの位置のまわり（半径 80 ドット）には置かない                                                                  |
| 大きさ           | 当たりは丸で半径 14〜24 ドット                                                                                                                                  |
| 通れないもの     | 自分とふつうの敵。敵は障害物に沿って滑って回り込む                                                                                                              |
| 通り抜けるもの   | 弾・炎・輪などの武器、ボス、群れ（`drift`）、きらきらハリネズミ、ランタン                                                                                       |
| 吹雪             | 流されても障害物の中には入らない                                                                                                                                |
| 中に置かないもの | 経験値の玉・落ちた品・宝箱・ランタン・宝の地図の宝箱・敵が出る位置。中に来たら外へずらす                                                                        |
| 飾り             | 障害物と重なる飾りは描かない                                                                                                                                    |
| 絵               | ステージごとに 2 種類。森は大岩と倒木、夜の墓地は大きな墓石と崩れた柵、雪山は氷の岩と雪に埋もれた木、火山は黒い溶岩の岩と湯気の出る岩。使う前に見本を見てもらう |
| バランス         | ボットで、店を半分買った状態のクリアの割合を、障害物の有り無しで比べ、大きく変われば数を調整する                                                                |

## 作り

- `obstacles.ts` が、区画の番号から障害物（位置・半径・絵の種類）を返す。`near(x, y, r)` は、その丸にかかる障害物を返す。DOM を使わない。
- `push(o, r)` は、丸 `o`（位置と半径）を、重なっている障害物の外へ押し出す。自分・ふつうの敵・品の置き直しはこれを使う。
- 敵は動いたあとに押し出す。押し出しで、障害物に向かう速さが消え、沿う速さだけが残るので、回り込む。
- 描くのは `draw.ts` の地面のあと。足もとの影と、絵の下の端を当たりの丸の下にそろえて、奥行きのある順（y の小さい順）に描く。

## 確かめ方

- `obstacles.ts` の置き方（毎回同じ・始めの位置のまわりに無い・量）と、押し出し（中に入らない・沿って滑る）を vitest で確かめる。
- 自分・敵・玉・品・宝箱・ランタンが障害物の中に入らないことを、ボットで 10 分回して確かめる。
- ボットで、店を半分買った状態のクリアの割合を、障害物の有り無しで比べる。
- 絵は見本を撮って見てもらってから使う。

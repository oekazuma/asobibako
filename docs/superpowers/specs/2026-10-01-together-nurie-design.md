# みんなでぬりえ 設計

おえかきのもり（`oekaki-mori`）の 3 つ目の遊び方。つないだ 2〜3 台の端末に同じ線画を出し、全員が同時にタップで塗る。点数も勝ち負けもない。

塗り方と線画の作り方は、ぬりえ（`nurie`、`docs/superpowers/specs/2026-09-30-nurie-design.md`）と同じ。端末のつなぎ方と遊び方選びは、おえかきのもりの設計（`docs/superpowers/specs/2026-09-30-oekaki-mori-design.md`）のまま。

## 流れ

1. 遊び方選びに「みんなでぬりえ」を足す。ほかの遊び方と同じく 2 人から選べる。
2. 親が絵を選ぶ。テンプレート 8 枚か「しゃしんから つくる」（ぬりえと同じ画面）。子には「おやが えを えらんでいます…」を出す。
3. 全員の画面に同じ線画が出る。色を選んでタップすると塗れ、塗った色はすぐ全員の画面に出る。
4. 「1つ もどす」は、押した人が塗ったところを新しい順に戻す。ほかの人が上から塗り直したところは戻さずに飛ばし、その前に自分が塗ったところを戻す。
5. 親だけに「できた！」を出す。押すと全員の画面に出来上がりを見せ、全員のぬりえちょうに同じ絵を入れる（あとで 1 人で続きを塗れる）。
6. 出来上がりの画面では、全員が「しゃしんに ほぞん」で写真アプリへ入れられる。親の「あそびを えらぶ」で遊び方選びに戻る。子には「おやが つぎの あそびを えらぶのを まってね」を出す。

## 仕組み

### 線画を配る

親は、塗る場所を分けた線画（768 × 768 の白黒の画像）を全員に配る。テンプレートも名前だけでなく線画そのものを送る。端末ごとにテンプレートを描き直すと、線のわずかな描き方の違いで場所の番号がずれ、同じ番号が違う場所を指すおそれがあるため。

線画は 1 画素 1 ビットに詰め（ぬりえの `pack`）、`CompressionStream('deflate-raw')` で縮めて base64 にし、1 通の知らせで送る。テンプレートなら数 KB、写真でも数十 KB になる見込みで、DataChannel の 1 通の上限（256 KB）に収まる。

子は受け取った線画で場所の番号を振る。テンプレートの線の見た目は、子の端末でテンプレートのパスから描く（ぬりえと同じく、塗りの上に `Path2D` でなめらかに描く）。

### 塗る・戻す

塗る・戻すは、どの端末の操作も親に送り（`act`）、親が順番を決めて全員に配る（`tell`）。押した端末も、親から届いてから色を変える。同じところを 2 人がほぼ同時に塗ったら、親に後から届いたほうの色になる。

親は「場所の番号 → 色」の表と、塗った手順（だれが・どこを・前の色・塗った色）の並びを持つ。戻すときは、押した人の手順を新しい順に見て、いまの色がその手順で塗った色のままなら前の色に戻す。違う色になっていたら（ほかの人が上から塗った）その手順は捨てて、さらに前の手順を見る。戻せる手順が無ければ何もしない。

この規則は DOM も接続も使わない純粋なモジュール（`src/lib/games/oekaki-mori/together.ts`）にして vitest で確かめる。

### できた

親の「できた！」で、全員に「できた」を知らせる。受け取った端末は、自分のぬりえちょうに新しい作品として入れる（線画・色の表。戻す手順は入れない）。

### 抜けた人

子が抜けても、残りの人で塗り続ける。親が抜けたら、ほかの遊び方と同じく子はロビーに戻る。

## コードの置き場所

ぬりえとみんなでぬりえの両方で使う部品を `src/lib/coloring/` へ移す。1 つのゲームの部品を別のゲームから直接読まないという、このリポジトリの決まりに合わせるため。

| 移すもの                                                                                        | 役目                                                                   |
| ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `regions.ts` / `paint.ts` / `lineart.ts` / `templates.ts` / `art.ts` / `book.ts` と、そのテスト | 場所の番号・塗った状態・写真の線画・テンプレート・描き方・ぬりえちょう |
| `Canvas.svelte` / `Palette.svelte` / `PhotoMaker.svelte` / `Picker.svelte`                      | 線画の画面・色のパレット・写真の画面・絵を選ぶ画面                     |
| `sounds.ts`                                                                                     | 塗る音                                                                 |

ぬりえ（`src/lib/games/nurie/`）には `Nurie.svelte`・`Howto.svelte`・`meta.ts` とそのテストが残り、動きは変えない。

`Palette.svelte` の「できた！」は、渡されたときだけ出す（みんなでぬりえの子には出さない）。線画を縮めて base64 にする関数と戻す関数は `src/lib/coloring/book.ts` の近く（`src/lib/coloring/wire.ts`）に置く。

おえかきのもり側では、みんなでぬりえの画面と親の処理を `Together.svelte` 1 つにまとめる（絵を選ぶ・塗る・出来上がり）。遊び方選び（`ModeSelect.svelte`）に 3 つ目のボタンを足し、`OekakiMori.svelte` はみんなでぬりえのときにクイズの `Referee` を動かさず、全員の画面を `Together.svelte` に切り替える。

入れないもの。だれがどこを塗ったかの印、時間の制限。

## 確かめ方

vitest で次を確かめる。

- `together.ts` で、塗ると全員に配る色が返ること、自分の塗りだけを新しい順に戻すこと、ほかの人が上から塗ったところは飛ばしてその前を戻すこと、戻せる手順が無ければ何もしないこと
- `wire.ts` で、線画を縮めて base64 にし、元に戻せること、テンプレートの線画が 16 KB より小さくなること
- 部品を移したあとも、ぬりえのテストがそのまま通ること

3 ページの通しの確認で、親がテンプレートを選ぶと子 2 人に同じ線画が出ること、子の 1 人が塗った色がほかの 2 人の画面にも出ること、「1つ もどす」で自分の塗りだけが戻ること、親の「できた！」で全員のぬりえちょうに作品が入ることを見る。

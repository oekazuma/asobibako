# やっぱりカメレオン CPU と遊ぶ 設計

## 目的

iPad 1 台だけでも、CPU を相手に 1 試合を最後まで遊べるようにする。全体の設計は `2026-10-08-yappari-chameleon-design.md`、本家の仕様は `2026-10-08-yappari-chameleon-original.md`、試合の決めごとは 2a・2b の設計に従う。

| 遊び方               | 中身                                                                                |
| -------------------- | ----------------------------------------------------------------------------------- |
| 隠れる（CPU が探す） | プレイヤーが塗って隠れ、CPU 1〜2 人のハンターが屋敷を回って探して撃つ               |
| 探す（CPU が隠れる） | CPU 1〜2 人が隠れ場所を選んでまわりの色で自分を塗り、プレイヤーがハンターとして探す |

- モードは通常と増え鬼。ダブルは CPU と遊ぶでは選べない。隠れるを選んだときは隠れる人がプレイヤー 1 人で、増え鬼にしても見つかった時点で終わるので、増え鬼は探すときだけ選べる。
- 強さは「弱い」「普通」「強い」の 3 段（画面の言葉を漢字まじりにそろえる）。
- 本家に CPU 戦は無い。画面の言葉は本家に合わせ、CPU の動き方はこのゲームで決める。
- 人と CPU を混ぜて遊ぶ（2〜3 人のつないだ試合の空いた席に CPU を足す）のは次の段にする。この段の作りは、CPU を席に座らせる形にしてそれを妨げない。

## 全体の形

CPU は「手元でつないだ見えない子」として、親の端末の席 2・3 に座る。

| 部品               | 決めごと                                                                                                                                                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 手元の管           | `Pipe` と同じ口を手元で回す管を 1 本ずつ作り、`Party.add` に渡す。CPU は子と同じ手順（`hello` に `PROTOCOL`、席が決まったら `hi` に `CHAMELEON_VERSION`）で入る。`Party.add` は子を 2 つまで受けるので、CPU は 2 人まで                   |
| CPU のしるし       | `hello` の `look` に `cpu` を入れる。`Party.looks` が顔ぶれと一緒に配るので、札・順位表・見落とした敵は「CPU 1」「CPU 2」と呼べる（席 2 が CPU 1）                                                                                        |
| 審判と画面         | `Host`・`Session`・`Remote`・知らせの形は変えない。CPU の体は人の子と同じく `Remote` で描く                                                                                                                                               |
| 役                 | `Host.start` に「ハンターにする席」を渡せるようにする（`rules.start` の `pickHunters` の前に効く）。CPU と遊ぶでは、隠れるを選べば CPU 全員を、探すを選べばプレイヤーだけをハンターにする。ふつうのつないだ試合は今のまま台の希望で決める |
| CPU の頭脳         | `cpu/` に置き、DOM と three を使わない。屋敷の当たりは `levelOf(mansion(seed))`（種ごとに作り直す）、歩きは `move.ts` の `step`、視野と遮りは `oversight.ts` と `rayLevel` を使う                                                         |
| 目と筆（`Senses`） | 頭脳が 3D に聞く口。「この体はこの目からどれだけ目立つか」「この線の先の面の色」「この席の体の表面の点」の 3 つ。アプリでは親の端末の 3D が答え、テストでは決め打ちの偽物を差す                                                           |
| 回すループ         | `Yappari.svelte` の `hosting` が回す審判のループで CPU も進める。描画を止めても試合と CPU は進む                                                                                                                                          |

CPU が送るものは子と同じにする。

| 知らせ  | 決めごと                                                                                                                                                                                                                                         |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `me`    | 止まっていても 50ms（`SEND_MS`）ごとに送る（親の止まっているかの判定と、撃った時刻へのさかのぼりが体の列を使うため）。ハンターは目の位置（`eye`）を付け、隠れる人は `null`                                                                       |
| `dabs`  | 塗り。隠れる CPU が隠れタイムに送る                                                                                                                                                                                                              |
| `shot`  | 撃つ。始まりは目の位置、筋は銃口から。撃つ間の 2 秒（`COOLDOWN`）は CPU も自分で守る                                                                                                                                                             |
| `ready` | 隠れタイムと答え合わせで自分から押す（押さないと 1 人では「隠れタイムを飛ばす」「ロビーへ戻る」が先へ進まない）。探す CPU は隠れタイムの始めに、隠れる CPU は場所に着いて塗りを送り終えてから、答え合わせは結果を見る間として 5 秒たってから押す |

## 道順の網

- 部屋の真ん中・戸口の前後・大階段の上下・回廊・家具のすき間などに点を手で置き、歩いて行ける点どうしを辺でつなぐ（`cpu/paths.ts`）。
- 探す CPU は網の上で行き先までの道を最短で選び、点から点へ `step` で歩く。止まって進めないときは、ひとつ前の点へ戻って選び直す。
- テストで、全部の辺を `step` で実際に歩けること、ロビー・控室・入口から屋敷の全部屋へ行けることを確かめる。動く物は置き方の種で変わるので、どの種でも通れる道だけを辺にする。

## 探す CPU（ハンター）

| 時           | 動き                                                                                                                                                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 隠れタイム   | 人のハンターと同じく控室で待つ。すぐ `ready` を押すので、いつ始めるかはプレイヤーが決める                                                                                                                                                                                                                     |
| 探索の見回り | 入口から入り、網の上で部屋を順に回る。部屋の中では左右に加えて上下にも首を振り、天井・回廊・家具の上を見る。強いではしゃがんで机や台の下ものぞく。CPU が 2 人なら別々の部屋から回り始める                                                                                                                     |
| 気づく       | 0.25 秒ごとに、隠れている体が視野・届き・遮りを通るかを見る（視野と遮りは見落としポイントと同じ式。届きは点の足し算の 15m とは別に、大広間の端から端まで見える 30m にする）。通れば `Senses` に目立ちを聞き、目立ち・距離・動いたかで怪しさをためる。動いている体は大きく足す。見えないあいだはゆっくり減らす |
| 撃つ         | 怪しさが閾値を超えたら、その体の胴の真ん中へ向いて近づき（見えなくなったら最後に見えた場所までだけ追い、着いても見えなければ見回しに戻る。見えない体の今の位置は使わない）、強さの段のぶん迷ってから狙いをずらして撃つ。外したら怪しさは残して続けて狙う。半端に怪しいところには、ときどき試し撃ちする        |
| 口笛         | 挑発の口笛（`toot`）を聞いたら、その場所へ向かって見回す。向かう先は口笛の場所から、遠いほど大きく、強さが低いほど大きくずらす（本家の ♪ も近いか遠いかが分かる程度）。強いでも隠れる人の上へまっすぐは行かない                                                                                               |
| 答え合わせ   | 撃たずにその場で見回すだけにする                                                                                                                                                                                                                                                                              |
| 埋まりの矢印 | 埋まりの知らせが出た人の場所へ向かう（人のハンターに見える矢印と同じ情報）                                                                                                                                                                                                                                    |

目立ちは、親の端末で CPU の目から 96 × 96 ほどの小さな絵を、その体ありと体なしで 2 枚描き、色がはっきり違う画素の割合で決める。光・壁紙の模様・実際の塗りがそのまま効くので、プレイヤーが溶け込めたと感じるときに CPU も見落としやすくなる。描くのは視野と遮りを通った体だけで、1 体につき 1 秒に 4 回までにする。

## 隠れる CPU

| 時           | 動き                                                                                                                                                                                                                                                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 場所選び     | 隠れタイムの始めに、部屋ごとの候補（壁ぎわ・隅・家具の横・壁や天井の張り付き）から選ぶ。候補はポーズも持つ（本棚の前は立つ、天井は丸まる、壁の隅は寝そべり、など本家の定番の隠れ方。風船は種で位置が変わるので候補にしない）。ハンターは控室にいて見えないので、歩かずにその場所へ置く。2 人なら別々の部屋にする。埋まりにならず（`embedded`）、動く物とかぶらない候補だけを使う |
| 塗り         | 部屋の戸口あたりの目の高さを「見られる位置」にし、体の表面の点ごとに、そこから体を通した先の面の色を `Senses` で取り、その色で吹く。色は 3D スポイトと同じ光の前の色に、背景の面と体の面の向きによる日と半球の光の当たり方の比を掛けて直す（上を向いた床は横の面の 2.6 倍ほど光を受けるので、光の前の色のまま縦の足に塗ると床より暗く浮く）。隠れタイムのうちに少しずつ送る      |
| 探索         | 動かない。強制挑発は今のまま審判が鳴らす                                                                                                                                                                                                                                                                                                                                         |
| 見つかったら | 通常は観戦（何もしない）。増え鬼ではハンターになり、探す CPU の頭脳に切り替わる                                                                                                                                                                                                                                                                                                  |

## 強さ

数字は通しの試合と headless の確かめで直す。

|                | 弱い                          | 普通             | 強い                               |
| -------------- | ----------------------------- | ---------------- | ---------------------------------- |
| 探す・目       | はっきり違う色だけ気づく      | 少し違えば気づく | わずかな違いや塗り残しにも気づく   |
| 探す・撃つまで | 1.5 秒迷い、狙いが 3 度ずれる | 0.8 秒、1.5 度   | 0.4 秒、0.5 度                     |
| 探す・歩き     | ゆっくり、同じ所も見に行く    | 普通             | 走り、まだ見ていない部屋を先に回る |
| 隠れる・場所   | 床に立つ・座る                | 壁ぎわ・家具の陰 | 壁や天井の張り付きも使う           |
| 隠れる・塗り   | 大きな筆で色がずれ、白が残る  | 色は合うが粗い   | 細かく正確                         |

## 画面

- 入口に「CPU と遊ぶ」を足す。押すと、隠れる／探す・CPU の人数（1・2）・モード（通常・増え鬼）・強さを選ぶ画面を出し、「ゲームを始める」で試合を始める。選んだものは `prefs.ts` と同じ形で端末に覚える。
- 始めるとロビーに出ずに紹介へ進む（本家はロビーで全員がそろうのを待つが、1 人では待つ相手がいないため）。答え合わせのあとはふつうと同じくロビーへ戻り、ロビーの上の帯の「マップの設定」の横に「CPU の設定」を出して、同じ選ぶ画面から選び直して始める。ロビーの台はこのモードではハンター希望に使わない。
- CPU と遊ぶでは「なかまを呼ぶ」と「よびなおす」を出さない。
- 左上の ✕ の確かめは今のまま「抜ける」で入口へ戻る。
- 選ぶ画面の言葉は漢字まじり（隠れる・探す・人数・モード・強さ）で、モード名は本家の「通常」「増え鬼」。

## 確かめ方

- 道順の網は、全部の辺を歩けることと全部屋へ行けることをテストで確かめる。
- 頭脳は偽の `Senses` を差して vitest で試す。目立つ体には撃つ、目立たない体は見落とす、口笛へ向かう、隠れ場所が埋まらない、塗りが送られる、増え鬼で見つかった隠れる CPU が探し始める、を見る。
- 審判・CPU・決め打ちのプレイヤーを手元の管でつなぎ、通常と増え鬼が最後まで決着することを確かめる。
- headless の Chrome で本物の 3D の試合を回して撮る。白いまま隠れた体は数秒で見つかり、まわりの色で塗った体は見つかりにくいことを、強さの段ごとに見る。CPU の目の描き足しを入れた重さ（1 コマの時間）も測る。
- 今の 2 台・3 台のつないだ試合（2b の e2e）が今のまま通る。`pnpm verify` が通る。
- ユーザーが iPad で遊んで、強さの段の数字を直す。

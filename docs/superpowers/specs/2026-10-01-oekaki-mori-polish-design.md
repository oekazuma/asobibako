# おえかきのもりの仕上げ 設計

## ねらい

家族で遊んで「とてもおもしろい」となったおえかきのもりを、遊び続けやすくする。いま困っているのは次の 4 つ。

1. 押し間違いで画面から抜けやすく、抜けるとつながりが切れる。切れたら最初からやり直すしかない。
2. メニューと導線が直感的でない。ひとりで れんしゅうは要らない。ひとりで ぬりえをしたいときの入り口は要る。
3. 当てる人が打っている答えが、送るまで誰にも見えない。
4. 描きにくい。Apple Pencil で描けない（手のひらが先に触れると、手のひらが線になる）。

成功の目安は、2〜3 台で 1 回の遊びを最後まで続けられること（途中で 1 台が切れても呼び直せる）、初めて触る人が説明なしで「よぶ」「はいる」「あそびを えらぶ」まで進めること、Pencil で速く描いても線が角ばらず遅れないこと。

## 決めたこと

| 問い                         | 決めたこと                                                             |
| ---------------------------- | ---------------------------------------------------------------------- |
| 打っている答えを誰に見せるか | 描く人には字をそのまま、ほかの当てる人には字数だけ（●）を見せる        |
| つながったあとの抜け方       | ✕ とミュートを消し、隅の「≡」のメニューから、確かめてから抜ける        |
| ひとりで ぬりえの入り口      | つながる前のロビーに置き、今のぬりえのゲームを開く                     |
| 切れた人の戻り方             | 遊びの途中でも、親が QR で呼び直せば同じ番号・同じ点数で次の番から戻る |
| 筆圧                         | 入れない。お絵かきクイズでは効きが小さく、線のデータと送る量が増える   |

## 1. 画面の流れと抜けにくさ

### つながる前のロビー

- 見出しの下に大きなカードを 2 枚並べる。「なかまを よぶ」（この たんまつに QR が でる）と「なかまに はいる」（おやの QR を よみとる）。
- 下に控えめな「ひとりで ぬりえ」を置き、`/games/nurie` を開く。ぬりえちょうはひとりでも、みんなでぬりえでも同じもの。
- ひとりで れんしゅう（`Practice.svelte`）は消す。一覧の絵は今の `static/thumbs/oekaki-mori.webp` をそのまま使い、`scripts/thumbs/scenes.ts` の撮り方は外す。
- まだ誰ともつながっていないので、この画面だけ隅の ✕ とミュートを残す。

### つながったあと

- ✕ とミュートを消し、右上に「≡」を 1 つ置く（遊んでいる最中の画面にも置く）。押すとメニューのシートを開く。
- メニューの中身は、おと（ミュートの切り替え）、なかまを よぶ（親だけ。空きか切れた人がいるとき）、ぬける… の 3 つ。
- 「ぬける…」は確かめのシートを出す。親には「ぬけると みんなの あそびが おわるよ」、子には「ぬけても おやが よびなおせるよ」と書き、「もどる」と「ぬける」を並べる。ぬけるとつながりを閉じて一覧へ戻る。
- あつまった画面は、顔ぶれを 1P・2P・空き（＋）の丸で見せる。親には「もうひとり よぶ」（2 人のとき）と「あそびを えらぶ」、子には「おやが えらぶのを まってね」を出す。
- 遊び方選びは、アイコンと一言の説明のついたカード 3 枚（エゴコロクイズ・はやおし検定・みんなでぬりえ）。今の「なかまを よびなおす」は消す。呼ぶのはメニューから行い、ロビーへは戻らない。

### つなぎ直し

- 親の端末で子のつながりが切れたら、その番号を「切れた人」として覚え、どの画面でも上に「2P の つながりが きれました」と「よびなおす」を出す。
- 「よびなおす」とメニューの「なかまを よぶ」は、いまの画面の上に QR の手順（`Handshake.svelte` の親の役）を重ねて出す。遊びは止めずに進める。
- 親は迎えるとき、切れた人の番号を空いた番号より先に渡す。戻った子は同じ番号になる。
- 親は戻った子に、いまの画面を知らせる。エゴコロクイズとはやおし検定なら、いまの絵の線・これまでの絵・人ごとの見え方を送る。みんなでぬりえなら、線画と塗った色を送る（親が「できた！」を押したあとなら、それも送る）。
- ルールでは、戻った人は当てる人として次の知らせから加わり、点数は抜ける前のものを引き継ぐ。抜けたときに消えた、これから描く番は戻さない（番を増やすと、終わる時間が読めなくなるため）。遊びが終わっていたら何もしない。
- 子の端末でつながりが切れたら「つながりが きれました」と「もういちど つなぐ」を出す。押すと QR を読む画面（子の役）にすぐ入る。
- 親が切れたときは、今どおり子は全員ロビーからやり直す。

## 2. 答えのリアルタイム表示

- エゴコロクイズの当てる人の 50 音盤は、打っている字が変わるたびに、その字を親へ送る（`{ t: 'typing', text }`）。
- 親の審判は、描く人へは `{ t: 'typing', seat, text }` をそのまま、ほかの当てる人へは字を「●」に置きかえて送る。打った本人には送らない。
- 各端末は人ごとの打っている字を持ち、上の帯の点数の丸に「2P りんご▍」のように出す。
- 「こたえる」を押したとき・当てたとき・番が変わったときは、その人の打っている字を消す。当てた人のあとの入力は送らない。
- 外れた答えは今どおり吹き出しで全員に出す。はやおし検定は 4 択なので変えない。

## 3. 描きやすさと Apple Pencil

- 点の拾い方を変える。今は 1 フレームに 1 回、指の位置を読んでいる。これを `pointermove` ごとに `getCoalescedEvents()` の点まで拾うようにする（Pencil は 1 秒に 240 回ほど）。拾った点はたまったぶんをフレームごとにまとめて送る（送る形は今の `add` のまま）。
- 線は、点と点の中点を通る 2 次曲線でつなぐ。送る点も保存する点も今と同じ 0..1 の座標の並びで、描き方だけを変える。
- 描き直しを減らす。今は 1 点足すたびに絵を全部描き直している。これを、最後の線に足された部分だけを描き足すようにする。全部描き直すのは、線が減ったとき（戻す・全部けす）と盤面の大きさが変わったときだけ。
- ペンを指より優先する。指で描いている途中にペンが触れたら、その指の線を取り消し（`undo`）、ペンの線を始める。一度ペンが触れたら、その盤面では指で線を描かない（手のひらを線にしない）。道具のボタンは今どおり指で押せる。

## 部品と流れ

| 部品                           | 変えること                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| `src/lib/net/party.svelte.ts`  | 親は切れた番号を `away` に覚え、`add()` で先に渡す。戻ったら `{ t: 'join' }` を審判へ流す。`close()` で `away` も空にする |
| `engine.ts`                    | `rejoin(s, seat)` を足す                                                                                                  |
| `referee.ts`                   | `join` で `rejoin` を呼び、その人に見え方を送り直す。`typing` を出し分けて配る                                            |
| `OekakiMori.svelte`            | 戻った子に画面・線・これまでの絵を送る。打っている字を人ごとに持つ。✕ とミュートを、つながる前だけにする                  |
| `Menu.svelte`（新）            | ≡ とメニューのシートと、ぬけるときの確かめ                                                                                |
| `Invite.svelte`（新）          | 親の QR の手順を画面の上に重ねる。切れた人の知らせと「よびなおす」も持つ                                                  |
| `Lobby.svelte`                 | つながる前のカード 2 枚とひとりで ぬりえ。あつまった画面の顔ぶれの丸。子の「もういちど つなぐ」                           |
| `ModeSelect.svelte`            | カード 3 枚。よびなおすを消す                                                                                             |
| `Together.svelte`              | 戻った子に線画と色を送る                                                                                                  |
| `KanaPad.svelte`               | 打っている字が変わるたびに `ontype` を呼ぶ                                                                                |
| `TopBar.svelte`                | 点数の丸に打っている字を出す                                                                                              |
| `Board.svelte` と `strokes.ts` | 点の拾い方、曲線の描き方、描き足し、ペンの優先                                                                            |
| `Practice.svelte`              | 消す                                                                                                                      |

コンポーネントは 200 行未満に保つ。`OekakiMori.svelte` がふくらむときは、戻った子へ送る処理を別の `.ts` に分ける。

## まちがったとき

- 呼び直しの QR の手順がしくじったら、重ねた画面に今と同じ知らせを出し、閉じれば遊びに戻れる。
- 戻った子への送り直しが届く前に知らせが来ても、見え方は次に送るもので上書きされるので、ずれは 1 回の知らせのあいだに収まる。
- ペンの線を始めるときに指の線を取り消すのは、その指の線がまだ描いている途中のときだけ。すでに離した指の線は消さない。

## 確かめ方

テストで固めること。

- `engine.test.ts` で、戻った人が次から当てる人になること、点数を引き継ぐこと、描く番は戻らないこと、終わった遊びでは何もしないこと。
- `party.svelte.test.ts` で、切れた番号を先に渡すこと、戻ったら `join` が流れること。
- 審判のテストで、打っている字を描く人にはそのまま、ほかの当てる人には ● で送ること、本人には送らないこと。
- `Board.svelte.test.ts` で、ペンが指より優先されること、`getCoalescedEvents()` の点を拾うこと、描き足しで全部を描き直さないこと。
- `KanaPad` と `TopBar` と `Menu` の画面のテストで、打った字の知らせ・帯の出方・ぬけるときの確かめ。

通しで確かめること。3 ページと偽カメラの仕組みで、途中で 2P を切って呼び直す流れ、打っている字の出方、メニューから抜けるときの確かめを撮る。WebKit でペンの線を撮る。最後に Pencil の描き心地と、実機のつなぎ直しをユーザーに iPad で見てもらう。

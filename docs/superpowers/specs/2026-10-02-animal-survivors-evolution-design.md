# Animal Survivors 進化・BGM・群れ 設計

## ねらい

ヴァンパイアサバイバーと比べて足りない点のうち、遊んでいる最中の盛り上がりと作戦の余地に効く 3 つを足す。武器の進化（組み合わせを探す楽しさ）、BGM（ずっと流れる曲）、群れの大波とリザルトのダメージ表（時刻ごとの山場と、次の作戦の手がかり）。遊ぶのは大人 2 人で、端末は iPad Air。

ステージの追加・壊せる燭台と特別な品・能力の種類・3 択の除外・図鑑・アルカナは次の回に回す。

## 1. 武器の進化

### 組み合わせ

| 武器（id）                 | 対のパッシブ | 進化形（id）                       | 変わること                         |
| -------------------------- | ------------ | ---------------------------------- | ---------------------------------- |
| ワンワンショット（`woof`） | するどい牙   | ホネのあられ（`woofEvo`）          | 骨が 4 本ずつ、敵を貫く            |
| ネコパンチ（`paw`）        | 野生の勘     | ネコ百烈拳（`pawEvo`）             | 前と後ろを同時に、当たると少し回復 |
| 遠吠え（`howl`）           | 大きな声     | 月夜の大遠吠え（`howlEvo`）        | 輪がとても大きく、強く吹き飛ばす   |
| ブーメラン（`boomerang`）  | かるい足     | つむじブーメラン（`boomerangEvo`） | 3 本、どこまでも貫く               |
| 羽（`feather`）            | ひげアンテナ | 風切り羽の舞（`featherEvo`）       | 羽が増え、ずっと回り続ける         |
| かみなり（`thunder`）      | はやい鼓動   | 雷雲の嵐（`thunderEvo`）           | 落ちる数がとても多い               |
| サカナ（`fish`）           | 鼻ききの勘   | サカナの群れ（`fishEvo`）          | 追いかける魚が 5 匹                |
| 爪（`claw`）               | ぶあつい毛皮 | 大熊の爪（`clawEvo`）              | 大きく重い一撃、当たると少し回復   |
| ダッシュアタック（`dash`） | かるい足     | はやて突進（`dashEvo`）            | 速く、多く、貫く                   |
| どんぐり（`acorn`）        | 薬草         | どんぐりの大樹（`acornEvo`）       | 全方向に倍の数                     |
| 炎（`flame`）              | 大きな心臓   | 燃える心臓（`flameEvo`）           | 太く長く残る炎、当たると少し回復   |
| ツタ（`vine`）             | 薬草         | 森の守り（`vineEvo`）              | 広く長く絡む                       |

かるい足と薬草は 2 組で使う。パッシブ 10 種はどれも 1 組以上に入る。

### 条件と出し方

- Lv5 の武器と、その対のパッシブ（Lv は問わない）を持って宝箱を開けると、1 つめの中身が必ず進化になる。宝箱の画面に金色で「進化！ ホネのあられ」と出す。進化できる武器が 2 つ以上あれば、持っている順の最初の 1 つ。
- 時刻の条件は付けない（1 回が 15 分と短いため）。
- 進化形は同じ枠に入れ替わり、それ以上は上がらない。HUD の Lv の数字は「★」になる。3 択と宝箱の候補にも出ない。

### しくみ

- 進化形は `weapons.ts` に、同じ動き方（`kind`）で数値の強い武器として 12 個足し、`evolved: true` を持たせる。上げ幅（`ups`）は空。
- 当たると少し回復する進化形は `drain`（1 回の当たりで戻す HP）を持つ。回復は 1 秒に最大 HP の 3% まで（大群に当てて一瞬で満タンにならないように）。
- 組み合わせは `evolutions.ts` の表（`from`・`with`・`to`）に持ち、`evolvable(w)` が今進化できる組を返す。
- 記録に `evolved`（作った進化形の id）を足す。

### 絵

- 進化形のアイコンと弾は、元の絵を `bake()` の金色の版で描き、アイコンの右上に小さな ★ を重ねる（元の武器がひと目で分かる）。描いたら見本を見せて止まる。

### 見せ方

- レベルアップの 3 択で、持っている武器と対になるパッシブの札と、対のパッシブを持っている武器の札に「進化」の印を付ける。
- 実績の画面に「進化」の表を足す。12 行に、武器・対のパッシブ・進化形を並べ、まだ作っていない進化形は名前を「？？？」、絵を黒い影にする。組み合わせは最初から見える。
- 実績を 2 つ足す。「はじめての進化」（コイン 100）と「12 種すべて進化」（コイン 500、途中経過あり）。表の末尾に足す。

## 2. BGM

| 場面                                 | 曲の感じ                                            | テンポ |
| ------------------------------------ | --------------------------------------------------- | ------ |
| キャラ選択・店・実績・リザルト       | 軽く弾むピコピコ音（長調）                          | 110    |
| 森で遊んでいる最中                   | 8 ビートで走る明るく急かす曲（長調、16 小節で一周） | 140    |
| ボス戦（WARNING からボスを倒すまで） | 短調で速く、太鼓が強い                              | 160    |

- 共通の `$lib/music` に、ピコピコ音の楽器（矩形波の旋律 `pulse`、三角波の低音 `tri`、ノイズの太鼓 `kick`・`hat`）と、伴奏の刻み方 `drive`（8 ビートで低音を刻み、太鼓を鳴らす）を足す。旋律の種類（`Lead`）に `chip` を足す。どれも足すだけで、わんにゃんハウスの曲は変わらない。
- 曲を繰り返し流す部品 `$lib/music/loop.ts` を新しく作る。鳴らしたい曲を `play(song, bpm, gain)` で渡し、毎フレーム `tick()` を呼ぶ。曲が変わると 0.4 秒でつなぐ。ミュート中（`bus()` が無い）と画面が隠れているあいだは消し、戻ったら頭から流す。わんにゃんハウスの `Bgm` には触らない。
- Animal Survivors は楽譜を `songs.ts` に持ち、画面ごとに曲を選ぶ。WARNING が出たらボス戦の曲、ボスを倒したら森の曲に戻す。
- BGM は効果音より小さめにする。一時停止のメニューのあいだは小さくして流し続ける。
- 3 曲を headless Chrome で WAV に書き出して利用者に聞いてもらい、よければゲームにつなぐ（そこで止まる）。

## 3. 群れの大波とダメージ表

### 群れの大波

森のステージの表に、時刻ごとの出来事（`events`）を足す。

| 時刻  | 出来事                             |
| ----- | ---------------------------------- |
| 1:30  | コウモリ 30 匹の群れが画面を横切る |
| 3:00  | ネズミ 40 匹の輪が迫る             |
| 4:30  | コウモリ 50 匹の群れ               |
| 6:30  | イノシシ 12 頭の突進が横切る       |
| 8:00  | イモムシ 40 匹の輪                 |
| 11:00 | コウモリ 80 匹の群れ               |
| 12:30 | ヘビ 60 匹の輪                     |
| 14:00 | イノシシ 20 頭の突進               |

- 横切る群れ（`swarm`）は、画面の外の片側に帯になって現れ、追いかけずにまっすぐ反対側へ抜ける（ふだんの 1.5 倍の速さ）。抜けたら消え、倒した数にも経験値にも入らない。遠くの敵を進む先へ置き直すしくみからは外す。
- 迫る輪（`ring`）は、自分を囲む大きな輪に並んで現れ、ふつうに追ってきて輪が縮む。
- どちらも同時に出せる数の上限（`cap`）とは別に出す。敵の入れ物（400 体）より多くは出さない。体力はそのときの `toughness` を掛ける。
- 倒せば経験値の玉を落とす。
- 始まると画面の上に小さな帯で「コウモリの大群！」を 2 秒出し、短い音を鳴らす（ボスの WARNING より控えめ）。

### ダメージ表

- `damageEnemy` に武器の id を渡し、武器ごとにダメージの合計と倒した数を数える（`World.dealt`）。進化形は進化前と別の行。15 分クリアの一掃と、復活の吹き飛ばしはどの武器にも数えない。
- リザルトの「取った武器とパッシブ」のアイコンの並びを、ダメージ表（`DamageTable.svelte`）に置き換える。武器ごとに 1 行で、アイコン・名前・Lv（進化形は ★）・ダメージ・倒した数を、ダメージの多い順に並べ、行の地にいちばん多い武器を 100% とした帯を敷く。パッシブはその下にアイコンで並べる。

## 5. 確かめ方

- vitest で次を確かめる。
  - 進化の条件、宝箱の 1 つめが進化になること、進化形が枠に入れ替わってそれ以上上がらず候補に出ないこと。
  - `drain` の回復が 1 秒に最大 HP の 3% までであること。
  - 進化の表がどのパッシブも 1 組以上に使い、進化形がどれも表にあること、2 つの実績の判定。
  - 群れがまっすぐ抜けて消え、倒した数に入らないこと、輪が自分を囲んで出ること、どちらも 400 体を越えないこと。
  - ダメージが武器ごとに数えられ、一掃が数えられないこと。
  - 楽譜の行が小節の長さに合い、音名とコードが読めること。新しい楽器が音を出すこと。
- headless Chrome で、進化の宝箱・群れと輪・リザルトの表・実績の画面の進化の表を撮る。
- ボットで、強化なしと全部最大の生存時間を測り、群れで強化なしの中央値が大きく下がらないことを確かめる。
- `pnpm verify` を通す。

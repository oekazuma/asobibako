# Animal Survivors ボスとヌシの登場演出 設計

## ねらい

ボスが出るときは WARNING の帯と音だけで、画面の外から歩いてくるので、どこに何が来たのかが分かりにくい。ヌシは小さな帯が出るだけで、ふつうの敵にまぎれる。ボスは一度ゲームを止めてカメラで見せ、二つ名つきの名前で「強いのが来た」と感じられるようにする。ヌシはゲームを止めずに、場所と名前が分かるようにする。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い | 決めたこと                                                                |
| ---- | ------------------------------------------------------------------------- |
| ボス | ゲームを約 2.4 秒止め、カメラがボスへゆっくり寄って名前を出し、自分へ戻る |
| 揺れ | 画面は揺らさない。土ぼこりの輪・縁の光・低い地響きの音で重さを出す        |
| ヌシ | ゲームは止めない。王冠が光り、名前の帯を今より大きく出し、画面の端に矢印  |
| 名前 | ボスごとに二つ名を付ける                                                  |

## 1. ボスの登場

- 3:00・6:00・9:00・12:00 のボスと 13:30 の面の主が出たとき（延長戦のボスは出さない。1 分ごとに止まると遊べない）。
- 流れ（ゲームの時計は止まり、端末の時間で進む）。
  1. 0〜0.6 秒：カメラが自分からボスへなめらかに動く。
  2. 0.6〜1.8 秒：ボスの足もとに土ぼこりの輪が広がり、画面の縁が赤く光り、名前の札を出す（上に小さく二つ名、下に大きく名前）。
  3. 1.8〜2.4 秒：カメラが自分へ戻る。
- 面の主は 2 体のあいだへ寄り、札は「面の主」と 2 体の名前。
- 出た瞬間に低い地響きの音を鳴らす。
- あいだは 3 択・宝箱・一時停止を開かない（`Prompts.busy`）。画面が隠れたら、終わってから一時停止を開く（今の `PendingPause`）。
- 動きを減らす設定（`prefers-reduced-motion`）では、カメラは動かさず、札だけを 1.2 秒出す。
- WARNING の帯は今のまま 3 秒前に出す。

## 3. ヌシの登場

- ゲームは止めない。
- 名前の帯（「ヌシ出現！」と名前）を今の小さな帯より大きく、2 秒出す。
- ヌシの王冠の上にきらめきの粒を出す。
- ヌシが画面の外にいるあいだ、画面の端にヌシの向きを指す矢印を出す（宝の地図の矢印と同じ描き方で、色は黄色、残り秒は出さない）。倒すか画面に入ったら消す。

## 4. しくみ

| ファイル                                       | 変えること                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------------ |
| `enemies.ts`                                   | ボスの `epithet`                                                         |
| `bosses.ts`・`world.ts`                        | ボスとヌシが出たときの出来事（位置と、延長戦のボスかどうか）             |
| `prompts.svelte.ts`                            | 登場の状態（`intro`、端末の時間で進め、`busy` に含める）、カメラの寄る先 |
| `draw.ts`・`draw-boss.ts`・`draw-events.ts`    | カメラを寄る先へ動かす、土ぼこりの輪、縁の光、ヌシの矢印                 |
| `PromptLayer.svelte`・`BossIntro.svelte`（新） | 名前の札、ヌシの帯                                                       |
| `effects.ts`・`sounds.ts`                      | 地響きの音、王冠のきらめき                                               |

## 5. 確かめ方

- vitest で次を確かめる。
  - ボスが出ると登場が始まり、2.4 秒のあいだ `busy` で、ゲームの時計が進まない。終わると戻る。延長戦のボスでは始まらない。面の主は 2 体で 1 回。
  - カメラの寄る先が 0 秒で自分、0.6〜1.8 秒でボス、2.4 秒で自分。動きを減らす設定では自分のまま。
  - 二つ名が 6 体ぶんある。
  - ヌシが出ると帯が出て、画面の外のヌシに矢印の向きが出る。
- headless Chrome で、ボスの登場の 3 つの場面（寄る途中・札・面の主）とヌシの帯と矢印を撮る。
- `pnpm verify` を通す。

# Animal Survivors 日替わりお題 設計

## ねらい

遊ぶたびに動物と面を自分で選ぶので、慣れた組み合わせばかりになりやすい。日付ごとに動物・面・しばりを決めた「今日のお題」を出し、その日に初めてクリアするとしばりの難しさに応じたコインをもらえるようにする。ふだん使わない動物や、つらいしばりに挑む理由を作る。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い     | 決めたこと                                                                |
| -------- | ------------------------------------------------------------------------- |
| お題     | 仲間にいる動物 1 匹・選べる面 1 つ・しばり 2 つを、その日の日付から決める |
| ごほうび | その日のお題を初めてクリアしたときだけ、しばりの難しさに応じたコイン      |
| 回数     | 何度でも挑戦できる。ごほうびはその日に 1 回                               |
| しばり   | 敵が強い・自分が弱い・選び方を縛る・うれしい変化                          |

## 1. お題の決め方

- 日付は端末の時計の日付（`YYYY-MM-DD`）。その日に初めてキャラ選択を開いたときに、日付から作った乱数で決めて記録に残す（`Records.daily`）。同じ日のあいだに仲間や面が増えても、お題は変わらない。
- 動物は仲間にいる動物から、面は選べる面から選ぶ。
- しばりは 2 つ。1 つめは「うれしい変化」以外から、2 つめは残り全部から選ぶ（同じものは選ばない）。

## 2. しばり

| 種類         | id          | 中身                                   | コイン |
| ------------ | ----------- | -------------------------------------- | ------ |
| 敵が強い     | `tough`     | 敵の硬さ 1.3 倍                        | 200    |
|              | `fury`      | 敵の攻撃 1.4 倍                        | 200    |
|              | `swarm`     | ふつうの敵の出る速さ 1.4 倍            | 150    |
|              | `bossHp`    | ボスの体力 1.6 倍                      | 150    |
| 自分が弱い   | `noShop`    | 店の強化なし                           | 300    |
|              | `noMeat`    | 肉が出ない（ランタン・宝箱・3 択とも） | 150    |
|              | `halfHp`    | 最大 HP が半分                         | 200    |
| 選び方を縛る | `oneWeapon` | 武器は最初の 1 つだけ                  | 300    |
|              | `noTools`   | 引き直す・飛ばす・除外が使えない       | 100    |
| うれしい変化 | `growth`    | 経験値 2 倍                            | -150   |
|              | `might`     | 攻撃 +30%                              | -150   |

- コインの値はボットで確かめて直す（§6）。しばりの難しさとコインの釣り合いを見る。
- ごほうびは `(200 + 2 つのしばりのコイン) × 面のコインの倍率` を 10 枚単位に丸め、200 を下回らない。
- 面の表を変えるしばり（`tough`・`fury`・`swarm`・`bossHp`）は面の表を写して変える（元の表は書き換えない）。

## 3. 遊ぶ

- キャラ選択に「今日のお題」の札を出す（動物の絵・面・しばり 2 つ・ごほうび、クリアしたら「クリア済み」）。押すとお題の画面（`Daily.svelte`）で中身を大きく見せ、「挑戦する」で面を選ばずに始まる。
- お題の回は、リザルトの「もう一度」とやり直しも同じお題で始める。キャラ選択から選んだ回はしばりなし。
- 延長戦はふつうと同じに選べる。お題のごほうびは 15:00 のクリアの記録で入る。

## 4. 記録

- `Records.daily`：今日のお題（日付・動物・面・しばり・クリアしたか）。日付が変わったら作り直す。
- `Records.dailyDays`：お題をクリアした日の数。
- 実績を 2 つ足す。お題を 1 日クリア（100 コイン）、7 日クリア（500 コイン）。
- お題の回のまとめに日付とごほうびを入れ（`RunSummary.daily`）、`record()` はクリアした回で、記録のお題と日付が同じでまだクリアしていなければ、ごほうびを足してクリア済みにする。日をまたいで遊んだ回も、始めた日のお題として数える（記録のお題が次の日に作り直されていたら、ごほうびは入らない）。
- リザルトにお題のごほうび（「お題クリア +N」）を出す。

## 5. しくみ

| ファイル                                                            | 変えること                                                                                     |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `daily.ts`（新）                                                    | しばりの表、日付からお題を作る、ごほうびの計算、しばりを World に当てる                        |
| `world.ts`                                                          | `createWorld` がしばりを受ける、`World.mods`・`World.daily`、`summary` の `daily`              |
| `drops.ts`・`chest.ts`・`choices.ts`                                | 肉が出ない、武器は最初の 1 つだけ                                                              |
| `records.ts`・`achievements.ts`                                     | `Records.daily`・`dailyDays`、お題のごほうび、実績 2 つ                                        |
| `CharSelect.svelte`・`DailyCard.svelte`（新）・`Daily.svelte`（新） | お題の札と画面。キャラ選択の店・実績・図鑑の口は `onopen` 1 つにまとめる（props の上限のため） |
| `Survivors.svelte`・`Play.svelte`・`Result.svelte`                  | お題で始める、もう一度、お題のごほうび                                                         |

## 6. 確かめ方

- vitest で次を確かめる。
  - 同じ日付と記録からは同じお題、日付が変わると作り直す。動物と面は仲間と選べる面から。しばり 2 つは重ならず、1 つめはうれしい変化でない。
  - しばりがそれぞれ効く（面の表の元は変わらない、肉が出ない、武器が増えない、道具が 0、HP 半分、経験値と攻撃）。
  - ごほうびの計算。その日の初クリアだけコインが入り、2 回めと別の日のお題では入らない。実績。
  - お題の札と画面、リザルトのごほうび。
- ボットで、店を半分にしたときの、しばりごとのクリアの割合を森で測る。割合が低いしばりほどコインが多くなるよう、表のコインを直す。
- headless Chrome でキャラ選択の札・お題の画面・リザルトを撮る（iPad の縦と iPhone の幅）。
- `pnpm verify` を通す。

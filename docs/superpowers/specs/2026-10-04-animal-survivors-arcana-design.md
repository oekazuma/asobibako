# Animal Survivors アルカナ 設計

## ねらい

1 回ごとの育ち方が、武器とパッシブの選び方だけで似てきている。その回だけルールを変える札（アルカナ）を、はじめに 1 枚と、ボスを倒したときに足していく。強いだけの札と、大きく効くかわりに悪いところのある引き換えの札を混ぜ、組み合わせで回ごとの遊び方を変える。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い       | 決めたこと                                                                      |
| ---------- | ------------------------------------------------------------------------------- |
| 手に入れ方 | はじめに 3 枚から 1 枚、4:00 と 8:00 のボスを倒すとまた 3 枚から 1 枚。3 枚まで |
| 札の中身   | うれしい札と引き換えの札を混ぜる。3 枚のうち 1 枚は引き換え                     |
| 枚数       | 16 枚。8 枚は最初から、8 枚は実績で開く                                         |

## 1. 流れ

- 釜で「はじめる」を押すと、遊び始める前（0:00、時間は止まったまま）に 3 枚から 1 枚を選ぶ。3 択と同じく盤面の外に出す。
- 4:00 と 8:00 のボス（面の表のその行）を倒すと、3 枚から 1 枚を選ぶ。宝箱より先に出す。持てるのは 3 枚までで、3 枚持っていれば出さない。
- 選ぶ画面は「選ばない」を持たない。すでに持っている札は出さない。
- お題の回はアルカナを出さない（しばりの難しさを変えない）。延長戦では増えない。
- 一時停止の画面に持っている札を並べる。リザルトにも出す。

## 2. 札

うれしい札は穏やかに強く、引き換えの札は大きく効くかわりに悪いところがある。★は実績で開く。数はボットで合わせる（6 章）。

| 札             | 種類     | 良いところ                             | 悪いところ                                 | 開く実績                 |
| -------------- | -------- | -------------------------------------- | ------------------------------------------ | ------------------------ |
| 大きな牙       | うれしい | 攻撃の範囲 +20%                        |                                            | 最初から                 |
| 早足のお守り   | うれしい | 速さ +15%、引き寄せ +40%               |                                            | 最初から                 |
| 知恵の実       | うれしい | 経験値 +20%                            |                                            | 最初から                 |
| 四つ葉の冠     | うれしい | 運 +30%                                |                                            | 最初から                 |
| ふたつめの影 ★ | うれしい | 弾と攻撃の数 +1                        |                                            | 釜 5.0 以上でクリア      |
| 時の砂 ★       | うれしい | 効く時間 +30%、攻撃の間 −10%           |                                            | 延長戦で 5 分生き延びる  |
| 命の泉 ★       | うれしい | 最大 HP +30、少しずつ回復（1 秒に 1）  |                                            | 雪山をクリア             |
| 会心の目 ★     | うれしい | 会心 +15%                              |                                            | きらきらハリネズミを倒す |
| いちかばちか   | 引き換え | 攻撃 +50%                              | 最大 HP 半分                               | 最初から                 |
| 重いよろい     | 引き換え | 防御 +4                                | 速さ −20%                                  | 最初から                 |
| 宝の呪い       | 引き換え | 宝箱の中身がいつも 3 つ以上            | 肉が出ない                                 | 最初から                 |
| 欲ばりの壺     | 引き換え | コイン 1.5 倍                          | 敵の体力 1.15 倍                           | 最初から                 |
| ガラスの大砲 ★ | 引き換え | 攻撃の間 −40%                          | 防御 −3                                    | 武器 3 つを Lv5 にする   |
| 背水の陣 ★     | 引き換え | HP が減るほど攻撃が上がる（最大 +80%） | 回復が半分                                 | 延長戦で 10 分生き延びる |
| 群れの呼び声 ★ | 引き換え | 敵が多いぶん経験値とコインが増える     | 敵の出る数 1.6 倍、ふつうの敵の攻撃 1.3 倍 | 1 回で 3000 体倒す       |
| 血の契約 ★     | 引き換え | 敵を 10 体倒すたびに HP 1 回復         | 肉が出ない、少しずつの回復なし             | 今日のお題を 7 日クリア  |

- 開いている札は記録に新しく残さず、達成済みの実績から決める。前から達成している実績の札は、はじめから開いている。
- 3 枚の候補は、開いていて持っていない札から選ぶ。引き換えの札が 1 枚以上残っていれば、そのうち 1 枚を必ず入れる。残りが 3 枚に満たなければ、ある分だけ出す（0 枚なら出さない）。
- 敵の出る数・体力・攻撃は、その札を取った時点から面の表を写して増やす（お題のしばりと同じ写し方）。

## 3. 記録と図鑑

- 図鑑に「札」のタブを足す。開いた札は名前と効果、まだの札は影と開く実績の名前を出す。図鑑のコインは出さない。
- 実績の表の行に、開く札（`arcana`）の欄を足す。リザルトの実績の札に「NEW! ○○の札」を出す。

## 4. 画面と絵

- 札を選ぶ画面（`ArcanaPick.svelte`）は 3 択と同じ `as-` の枠で、札は縦長の枠に印・名前・効果を並べる。引き換えの札は枠の色を変え、悪いところを赤で出す。出た直後の合成 click は `Lock` で止める。
- 札の印はドット絵。今ある武器やパッシブの印で合うものは使い回し、足りない分だけ新しく描く。新しい絵は使う前に見本を見せて決める。

## 5. しくみ

| ---------------------------------------------------------- | ---------------------------------------------------------------- |

## 6. 確かめ方

- vitest で、札ごとの効き方、候補の 3 枚（持っている札を出さない、引き換えを 1 枚入れる、少ないとき）、開いている札と古い記録、はじめと 4:00・8:00 のボスのあとに出ること、3 枚で止まること、お題の回で出ないこと、を確かめる。
- ボットで、森と墓地の店半分で、札ごとに「その札を最初に取ったとき」のクリアの割合と 1 回のコインを測り、引き換えの札がうれしい札より飛び抜けて強くも弱くもならないよう合わせる。
- `pnpm verify` を通す。

## 7. 調整の結果

ボットで、犬・キツネ・パンダを 6 回ずつ、店を半分にして、はじめにその札を取って遊ばせた。森ではどの札でもほぼクリアするので、差は夜の墓地で見た。

| ------------ | ------------ | ------------------- |

| 大きな牙     | 18/18        | 5815                |
| 早足のお守り | 13/18        | 4513                |
| 知恵の実     | 13/18        | 4712                |
| 四つ葉の冠   | 13/18        | 4684                |

| 時の砂       | 16/18        | 5630                |

| 重いよろい   | 14/18        | 4774                |

| 欲ばりの壺   | 10/18        | 5110                |

- 敵が多いほど経験値とコインが増えるので、敵の出る数を増やすだけでは悪いところにならない（はじめの群れの呼び声は 17/18 でコイン 2 倍、欲ばりの壺もコイン 2 倍）。群れの呼び声には攻撃を、欲ばりの壺には出る数の代わりに体力を足し、危ないぶん稼げる札にした。
- 命の泉は少しずつの回復を 1 秒に 1 へ、血の契約は回復を 10 体ごとに強めた（はじめは 12/18 と 10/18）。
- 大きな牙と背水の陣はほかより強めだが、18 回のぶれ（±2 回ほど）を少し超える程度なので数を変えない。

# アニマルサバイバー 総点検（重さ・バランス・小さな点） 設計

## 目的

協力プレイまでの機能を足し終えたところで、ゲーム全体を点検して直す。重さは端末で遊ぶ前に直し、バランスは延長戦と限界突破を中心に、ボットで測って直す。各回であと回しにした小さな点のうち、遊ぶ人に見えるものも直す。

## 1. 重さ

測定では、いちばん重い場面（協力プレイの親が、合体武器と限界突破を全部持っている場面）でも、WebKit で 1 フレームの計算は平均 9ms ほどで、60fps に収まった。重さのもとは、数に上限の無い炎・ツタ・弾・地面のコインと、協力プレイの様子の送り方だった。

| 点                       | 決め方                                                                                                                                                                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 協力プレイが途中で切れる | 1 回に送る様子が 256KB を超えると、2 台のつながりが切れる（終盤に 130〜350KB）。子の画面のまわり（画面の対角線ぶんの余白）にある弾・効果・品・玉だけを送り、ダメージの数字は 60 個まで送る。送る前に大きさを測り、上限に近ければ遠いものから落とす |
| 炎とツタが増えすぎる     | 地面に残る炎（`trail`）と足もとのツタ（`snare`）は、武器の枠 1 つにつき同時に 48 個まで。超えたら古いものから消す                                                                                                                                  |
| 画面の外まで描いている   | 弾・コイン・玉・品は、画面の中（少しの余白つき）にあるものだけ描く                                                                                                                                                                                 |
| 湯気の出る岩の絵         | 500 秒に 1 回しか切り替わっていない（ミリ秒と秒の取り違え）。0.5 秒ごとに切り替える                                                                                                                                                                |

## 2. バランス

ボットは「うまい人」と「適当に選ぶ人」の 2 種類で測り、遊ぶ人の腕はそのあいだに入るとみる。

| 点                       | 狙い                                                                                                                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 延長戦に終わりを         | 延長戦の敵の強まり方を、1 分ごとの掛け算にする。店・伝説の装備・遺物を全部そろえたうまいボットでも、延長戦の 20〜30 分（中央値）で倒れるくらいにする。延長戦のコインの倍率は 4 倍で止める |
| 限界突破に頭打ち         | 同じ武器の同じ能力を上げるほど、上がり幅を小さくする。10:00 までのクリアの割合は今と同じくらい（差が 1〜2 回の揺れの中）に保つ                                                            |
| 夜の墓地の 4:00 をゆるく | 4:00 のボスの体力を下げ、店を半分にしたボットで、夜の墓地のクリアの割合が雪山と同じくらいになるようにする                                                                                 |
| 釜 9.0 をもっと厳しく    | 全部そろえたうまいボットで 9.0 のクリアがおよそ 6〜7 割、適当なボットで 3 割ほどになるよう、9.0 に向かう敵の体力と攻撃の伸びを強める。賭けは 9.0 で 6000 枚くらいまで大きくする           |

10 分の回の店・装備・ガチャの値段は、延長戦を直したあとで測り直す。変えるかどうかは数字を見て決める（今回は変えない）。

## 3. 小さな点

| 点                                    | 直し方                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------ |
| 連携のゲージの色                      | 満タンで使えるときだけ明るい黄色にし、たまっている途中と見分ける         |
| 連携の技のあと半透明に見える          | 技のあとの当たらない時間は、被弾のあとの半透明で描かない                 |
| 「いっしょに！」が矢印に重なる        | 右端の矢印は、ボタンのある高さを避けて置く                               |
| 止める 1 秒の一時停止で帯が先に消える | 帯の時間を、止めている時間と同じく一時停止で止める                       |
| 抜けた相棒のぶんの空いた帯            | 相棒が抜けたら、ボスの体力バーを元の位置に戻す                           |
| 重い宝箱が狭いすき間で揺れる          | 押し出しが落ち着かないときは、その場に止める                             |
| 重い宝箱にうしろの障害物がかかる      | 重い宝箱は、障害物と足もとの高さの順に混ぜて描く                         |
| 自分の列が色だけ                      | 「ふたりの活躍」の自分の列に「じぶん」と字で出す                         |
| すぐ抜けて組み合わせを稼げる          | 60 秒より短い回は、組み合わせと遊んだ回数に数えない                      |
| 子の祠めぐりに親の祠が入る            | 祠を使った動物ごとに数える                                               |
| 待ち時間の札の文                      | 回る武器（羽根の嵐など）では、待ち時間ではなく回る速さが上がることを書く |

## 確かめ方

- 重さは、同じ測り方（WebKit と Chrome、いちばん重い場面）で直す前とあとを比べ、協力プレイの様子が 256KB を超えないことを vitest で確かめる。
- バランスは、同じ 2 種類のボットで直す前とあとを比べた表を作る。数字の決め方は表と一緒に見せる。
- 小さな点は、それぞれ vitest で確かめる（絵の位置は位置を決める関数で確かめる）。
- 画面で、協力プレイの終盤・連携のゲージ・ふたりの活躍を撮って見せる。

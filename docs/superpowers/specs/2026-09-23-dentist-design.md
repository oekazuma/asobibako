# 歯医者さん（dentist）設計

1 人用のゲームを 1 本足す。動物の患者さんの口の中を、道具を持ちかえながら治してクリアする。
id は `dentist`、一覧の名前は「はいしゃさん」、`meta.levels` は 20、`minutes` は「1分」。

## 遊びの流れ

1 面は患者さん 1 人。口の中にある症状をすべて治せばクリアで、時間制限はない。
患者さんが泣いたら（いたいメーターが満タン）しっぱい。しっぱいの条件はこれだけにする。

画面は縦長の盤面で、横向きの iPad では既存の `.stage` の回転に任せる。

| 場所      | 置くもの                                                            |
| --------- | ------------------------------------------------------------------- |
| 上の 7 割 | 大きく口を開けた患者さんの顔。口の中に上下の歯                      |
| 左上      | いたいメーター（顔アイコンつきの丸い表示）                          |
| 口の右下  | ゴミ箱                                                              |
| 画面下    | 道具トレイ。その面で使う道具だけを横 1 列に並べ、タップで持ちかえる |
| 画面の上  | SoloShell の吹き出し（`onhint`）。いまやることを出す                |

持っている道具は、指の少し上に大きく描く。治療に効くのは道具の先端で、指で先端が隠れないようにするため。

## 症状と治し方

| 症状         | 見た目             | 治し方                                                                                                        |
| ------------ | ------------------ | ------------------------------------------------------------------------------------------------------------- |
| 汚れ・歯石   | 歯の上の黄色いしみ | ブラシでこする。こすった距離に応じて薄くなり、消えたらキラッと光る                                            |
| 虫歯         | 歯の黒い点         | ドリルを当てて削る → 穴からバイキンが 1〜3 匹顔を出す → ピンセットでつまんでゴミ箱へ運ぶ → 詰め物で穴をふさぐ |
| ぐらぐらの歯 | 揺れている歯       | ペンチでつまみ、歯ぐきと反対の向きへ引っぱると抜けて飛んでいく                                                |

ゴミ箱にバイキンを落とすと「バイバイキン！」の太い文字（`.sticker` と同じ書体）が飛び出し、合成の効果音が鳴る。
声の読み上げは使わない。ゴミ箱の外で離したバイキンは穴へ逃げ帰る。

健康な歯は、ペンチではつかめずにすべる。ドリルを当てると削れはしないが、いたいメーターが速くたまる。

## いたいメーター

麻酔していない歯にドリルやペンチを当てているあいだ、メーターがたまる。健康な歯に当てると速くたまる。
注射を歯ぐきにタップすると、その歯と両どなりはその面のあいだ痛くない。
よしよし（手）で患者さんの頭をなでると、なでた距離に応じてメーターが下がる。
メーターが 1 になったら患者さんが泣き、少し泣く演出を見せてから `onfinish(false)` を呼ぶ。

## 道具

| 道具       | 使い方                                   | 効く相手                       |
| ---------- | ---------------------------------------- | ------------------------------ |
| ブラシ     | 歯の上でこする                           | 汚れ・歯石                     |
| ドリル     | 虫歯に当て続ける                         | 虫歯（削る）                   |
| ピンセット | バイキンをつまんで運び、ゴミ箱の上で離す | バイキン                       |
| 詰め物     | 空になった穴に当て続ける                 | 削ったあとの穴                 |
| ペンチ     | ぐらぐらの歯をつまんで引っぱる           | ぐらぐらの歯                   |
| 注射       | 歯ぐきをタップ                           | その歯と両どなりを痛くなくする |
| よしよし   | 患者さんの頭をなでる                     | いたいメーターを下げる         |

## 迷っている・間違っている子への手助け

罰は与えず、正しいやり方へ自然に誘う。次にやることを 1 つ選ぶ判断は純粋な関数 `advice(state)` にまとめ、
雪原サバイバルの `guide.ts` と同じようにテストする。

| きっかけ                                           | 手助け                                                                                        |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 何も治らないまま 5 秒たつ                          | 次に使う道具のボタンがぴょんと跳ね、治す場所の上で半透明の指がこする動きを見せる              |
| 効かない道具を症状に当てた（虫歯にブラシなど）     | 道具がぷにっとはね返り、吹き出しに「むしばには ドリルだよ」と出て、正しい道具のボタンが揺れる |
| 順番をまちがえた（バイキンが残っている穴に詰め物） | バイキンが顔を出して押し返し、「さきに バイキンを すてよう」と出る                            |
| その面でもう使わない道具                           | トレイで薄く表示する（押せるが、押しても使い道がない）                                        |
| 道具が初めて出る面                                 | 半透明の手が使い方（こする・運ぶ・引っぱる）を一度だけ実演する                                |
| いたいメーターが 6 割を超え、よしよしが使える      | 手のボタンが光り、「よしよし してあげよう」と出る                                             |

## 20 面の構成

面は `levels.ts` に 1 面ずつ手で書く（乱数で組み立てない）。1 面ごとに、患者さん・症状の組み合わせ・考えどころのどれかが前の面と違う。

患者さんは 8 種類。歯の本数は動物ごとに違い、うさぎの 8 本からワニの 20 本まで増える。

| 動物     | 特徴                           |
| -------- | ------------------------------ |
| うさぎ   | 長い耳、大きな前歯             |
| ねこ     | 三角の耳、ひげ                 |
| いぬ     | たれ耳                         |
| ぶた     | 大きな鼻                       |
| くま     | 丸い耳                         |
| ライオン | たてがみ                       |
| カバ     | 横に広い口、小さな耳、歯が多い |
| ワニ     | 長い口、とがった歯がずらり     |

| 面     | 段階             | 内容                                                                                                                                                                      |
| ------ | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1〜2   | 汚れを覚える     | 1 はうさぎの汚れ 2 つ（ブラシだけ）。2 はねこの上下に汚れ 4 つ                                                                                                            |
| 3〜4   | 虫歯を覚える     | 3 はいぬの虫歯 1 つ（バイキン 1 匹）。4 はくまの虫歯（バイキン 2 匹）と汚れ                                                                                               |
| 5〜6   | ぐらぐらを覚える | 5 はぶたのぐらぐら 1 本。6 はうさぎのぐらぐらと虫歯                                                                                                                       |
| 7〜8   | 痛みを覚える     | 7 で注射が登場し、深い虫歯は麻酔しないと泣く。8 でよしよしが登場し、怖がりの患者さんは最初からメーターが半分                                                              |
| 9〜14  | 組み合わせ       | 9 は虫歯がとなり合い、健康な歯を削らないよう狙う。10 はカバの厚い歯石。11 はすばしっこいバイキン。12 は怖がりとぐらぐら 2 本。13 はワニの奥歯の虫歯。14 は注射が 1 回だけ |
| 15〜19 | 仕上げ           | 上の要素を 2〜3 個ずつ重ね、歯の多い動物にする                                                                                                                            |
| 20     | 最終面           | ワニの全部入り。最後にバイキンのおやぶんが出る                                                                                                                            |

面の定義で指定できる数値は次のとおり。エンジンの分岐ではなく、データで難しさを変える。

| 値                   | 意味                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| 汚れの厚さ           | こする距離の量                                                                                   |
| 虫歯の深さ           | 削る時間とバイキンの数                                                                           |
| バイキンの種類       | ふつう・すばしっこい（穴の中を逃げ回る）・おやぶん（大きく、運ぶと抵抗してゆっくりしか動かない） |
| 最初のいたいメーター | 怖がりの患者さん                                                                                 |
| 注射の回数           | 0 は無制限                                                                                       |
| メーターのたまる速さ | 痛がりの度合い                                                                                   |

## グラフィックと演出

絵柄は絵本風。こげ茶（`#4a2e1f`）のふち線に、ベタ塗りと影 1 段と小さなつやを重ねる。
背景はあたたかいクリーム色の診察室の壁に、うすいタイル模様と上からのライトの光。
ブレインストーミングで見せた絵柄 C と配置 A を基準にする。

すべて canvas 1 枚に描く。患者さんの顔と歯の土台は面の始めに 1 回描いて `fx.ts` の `sprite` でキャッシュし、
毎フレーム描くのは症状・バイキン・道具・粒の演出だけにする。DPR に合わせて線をにじませない。

患者さんの表情は、口を開けたまま目・まゆ・ほお・汗・涙で見せる。

| 状態                             | 見せ方                                         |
| -------------------------------- | ---------------------------------------------- |
| ふつう                           | 3〜5 秒ごとにまばたきし、呼吸で少し上下する    |
| 不安（メーター 5 割以上）        | まゆが上がり、汗がひとつぶ出る                 |
| いたい（痛みがたまっている最中） | 目をぎゅっとつぶり、涙がにじみ、ぷるぷる震える |
| 泣く（しっぱい）                 | 涙が流れて大泣きする                           |
| にっこり（クリア）               | 目が「^ ^」になり、ほおが赤くなる              |

道具ごとの演出。

| 道具       | 演出                                                   |
| ---------- | ------------------------------------------------------ |
| ドリル     | ぶるぶる震え、削りかすの粒が飛び、「ウィーン」という音 |
| ブラシ     | 泡の粒                                                 |
| ピンセット | 閉じる動き。つまんだバイキンは足をじたばたさせる       |
| 詰め物     | 白くのびて穴がふさがる                                 |
| ペンチ     | つかむと歯がきしみ、抜けると回転しながら飛ぶ           |
| 注射       | 青いキラキラ                                           |
| よしよし   | ハート                                                 |

バイキンはぷにぷに伸び縮みし、目でピンセットを追う。ゴミ箱に落ちるとふたがはね、「バイバイキン！」がばねの動き（`--spring` 相当）で飛び出す。

クリアでは患者さんがにっこりして歯にピカッと光が走り、そのあと SoloShell の結果画面（紙吹雪あり）へ移る。
しっぱいでは大泣きしてから結果画面へ移る。

効果音は既存と同じく Web Audio の合成音で、ドリル・ブラシ・抜ける・つまむ・バイバイキン・詰める・注射・なでる・キラッを作る。
`prefers-reduced-motion` では揺れと震えを止める。一覧のカードの絵（`Thumb.svelte`）は CSS だけで描く小さなクマと歯。

## 構成

既存の 1 人用ゲームと同じく、ルールは DOM に依存しない純粋なモジュールに閉じ、`.svelte` は描画の呼び出しと Pointer Events の配線だけを持つ。
`.svelte` は 200 行未満に保つ。

| ファイル                        | 役割                                                                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `meta.ts`                       | 一覧用の情報と `load()`。`levels: 20`                                                                                                                 |
| `engine.ts`                     | 状態（歯・症状と進み具合・バイキン・いたいメーター・持っている道具・注射の残り）と `step()`、道具を当てる・つまむ・離すの操作。出来事をイベントで返す |
| `advice.ts`                     | 次にやること（道具・場所・ひとこと）を 1 つ選ぶ。効かない道具・順番ちがいのひとことも返す                                                             |
| `animals.ts`                    | 8 種類の動物の歯の並び（本数・位置・形）と色                                                                                                          |
| `levels.ts`                     | 20 面の定義                                                                                                                                           |
| `paint/`                        | 顔・歯と症状・バイキン・道具・背景の描画。キャッシュする絵と毎フレームの絵を分ける                                                                    |
| `sounds.ts`                     | 効果音                                                                                                                                                |
| `Dentist.svelte`                | 盤面と入力の配線                                                                                                                                      |
| `Tray.svelte`                   | 道具トレイ（DOM のボタン、`aria-label` つき）                                                                                                         |
| `Howto.svelte` / `Thumb.svelte` | タイトルの遊び方と一覧の絵                                                                                                                            |

道具のアイコンは `src/lib/icons.ts` に SVG パスで足し、トレイは `Icon.svelte`、canvas は `fx.ts` の `icon()` で描く。
入力は `BoardInput`、ループは `loop.ts` に載せる。座標は盤面の幅を 1 とする固定の箱で、高さは既存のゲームと同じく定数で持つ。

## テスト

| テスト       | 確かめること                                                                                                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全面クリア   | `advice()` に従って道具を選び操作するボットで、20 面すべてがクリアできる。`advice()` の手助けが正しい道順を指していることも兼ねる                                                                          |
| 痛み         | 7 面以降の痛みがある面は、注射もよしよしも使わずにドリルを当て続けると泣く                                                                                                                                 |
| 同じ面がない | 20 面の定義がすべて違う                                                                                                                                                                                    |
| 面の数       | 面の数が `meta.levels` と同じ                                                                                                                                                                              |
| エンジン     | 汚れはこすった距離で減る、虫歯は削るとバイキンが出る、バイキンが残る穴は詰められない、ゴミ箱の外で離したバイキンは穴へ戻る、健康な歯はペンチでつかめない、注射の範囲は痛くない、よしよしでメーターが下がる |
| 手助け       | 効かない道具・順番ちがい・5 秒の放置・メーター 6 割で、それぞれ正しいひとことと道具を返す                                                                                                                  |

## 進め方

実装の最初に、8 種類の動物（5 つの表情）とバイキン 3 種を描いた「キャラクター表」を作り、ゲームの部品を組む前に利用者に見てもらう。
絵が決まってから、エンジン・面・手助け・演出の順に組む。

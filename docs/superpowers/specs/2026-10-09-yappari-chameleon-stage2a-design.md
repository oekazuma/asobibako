# やっぱりカメレオン 2a 設計（つないで遊ぶ試合）

## 目的

1 段めの試作（1 台で塗る・隠れる・フリーカメラで見る）を、2〜3 人がそれぞれの iPad を持ってつなぎ、かくれんぼの試合を通しで遊べるようにする。全体の設計は `2026-10-08-yappari-chameleon-design.md`、本家の仕様は `2026-10-08-yappari-chameleon-original.md` に従い、この書面は 2 段めを 2 つに分けた前半（2a）の範囲と決めごとを書く。

2a のあとに iPad 2 台で遊んでもらい、撃つ・隠れる・答え合わせの手ざわりを聞いてから 2b へ進む。

| 段  | 中身                                                                                                                                                           |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2a  | つなぐ・ロビー（今の屋敷の中）・マップの設定・通常と増え鬼・控室・ハンターの銃・発見・観戦・口笛と強制挑発・HUD・答え合わせ・もうええよ・効果音・よびなおす    |
| 2b  | ダブル・見落としポイントと見逃しランキング・ええやん・ロビーの部屋（HUNTER の赤い台）・残りの部屋・BGM・ハンターの三人称・小物の置き方の乱数・埋まりすぎの警告 |

## 入口

- `meta.ts` を `PartyMeta`（`players: 2`、`party: true`）に替え、一覧の「ふたりで」へ移してカードに「2〜3にん」を出す。共通のシェルを通らないので、横持ちの扱い（`.stage` を回さない、縦持ちのあいだは絵を止めて「横向きにしてください」）はゲームが自分の `<main>` で持つ。
- 開くと入口の画面を出す。おえかきのもりのロビーと同じ形で、「なかまを呼ぶ」「なかまに入る」「ひとりで試す」の 3 つ。「ひとりで試す」は 1 段めの試作をそのまま開く（隠れタイムの時計とフリーカメラつき）。
- 遊び方は入口の画面に短く出す（本家の言葉で、塗って隠れる・ハンターは撃って探す、と「自分の iPad の画面は見せないでね」）。
- つなぐのは `src/lib/net/` の `Handshake.svelte` と `Party`（3 台まで、親が中継）。

## ロビー

- つながると、全員が屋敷の大広間に出る。歩く・塗る・ポーズ・挑発ができ、ほかの人の体と塗りが見える。
- 人の名前は席の番号で「プレイヤー1」〜「プレイヤー3」と呼ぶ。ロビーと答え合わせでは頭の上に名前の札を出し、隠れタイムと探索のあいだは出さない（本家は 2 キーで切り替えられるが、探索中にハンターから見えてよいかは分からないので、出さないほうに倒す）。
- 右端のボタンに「ハンター希望」を足す（本家では赤い台に乗る。台は 2b のロビーの部屋で作る）。押しているあいだ自分の頭の上に小さな赤い印を出し、ほかの人にも見える。
- 親だけが「マップの設定」を開き、「ゲームを始める」で始める。子の画面には「ホストが始めるのを待っています」を出す。

| 項目                           | 既定   | 選べる値       |
| ------------------------------ | ------ | -------------- |
| ゲームモード                   | 増え鬼 | 通常・増え鬼   |
| ハンターの人数                 | 1      | 1〜人数−1      |
| ハンター待機時間（隠れる時間） | 60 秒  | 30〜300 秒     |
| 探索時間                       | 300 秒 | 60〜600 秒     |
| 答え合わせ時間                 | 30 秒  | 10〜120 秒     |
| 強制挑発間隔                   | 0      | 0 か 5〜120 秒 |

- 設定は親の端末の localStorage（`asobibako:yappari-chameleon:settings`）に覚える。
- ハンターは、希望した人から乱数で人数分を選び、足りなければ残りから乱数で足す。
- 2 人のときは増え鬼と通常の勝ち方が同じになる。設定はそのまま選べる。

## 試合の流れ

親の審判（`referee.ts`）がフェーズと時計を持ち、全員に配る。

| フェーズ   | 長さ           | 隠れる人                               | ハンター                               |
| ---------- | -------------- | -------------------------------------- | -------------------------------------- |
| 紹介       | 3 秒           | 黒い帯とモード名と説明 2 行            | 同じ                                   |
| 隠れタイム | 待機時間       | 屋敷を歩く・塗る・ポーズ・挑発         | 控室にいて屋敷は見えない。自分を塗れる |
| 探索       | 探索時間       | 動ける・塗り直せる・フリーカメラ・挑発 | 屋敷の入口へ移り、一人称で撃って探す   |
| 答え合わせ | 答え合わせ時間 | 全員の場所が光る。見て回れる           | フリーカメラで見て回れ、撃ち続けられる |

- 試合の始めに、全員の塗りを白に戻し、隠れる人を大広間の決まった場所へ移す。ハンターは控室へ移す。
- 探索は、隠れる人が全員見つかるか時間切れで終わる。隠れタイムか探索のあいだにハンターが全員抜けたときも終わる（隠れる人の勝ち）。
- 答え合わせのあとはロビーへ戻り、塗りは白に戻る。
- 「もうええよ」のボタンを隠れタイムと答え合わせのあいだ画面の下の中央に出す。いる人の全員が押したら、そのフェーズをすぐ終える。押した人数を「もうええよ 1/3」と出す。

### 紹介の言葉

| モード | 名前   | 説明                                                     |
| ------ | ------ | -------------------------------------------------------- |
| 通常   | 通常   | 鬼と人間に分かれて隠れる。1 人でも最後まで隠れ切ると勝利 |
| 増え鬼 | 増え鬼 | 捕まると鬼になる。最後まで隠れ切ると勝利                 |

増え鬼の説明は本家の言葉。通常のゲーム内の説明は見つからなかったので、公式の発売告知の「鬼と人間に分かれてシンプルなかくれんぼです。」を、増え鬼と同じ調子の 2 行にする。

### 控室

屋敷から離れた所に置く小さな部屋（4m 四方、白い壁と木の床、出口なし）。ハンターは隠れタイムのあいだここにいて、隠れる人と同じ三人称の操作で歩く・塗る・ポーズができる（銃は持たない、しゃがむは出さない。本家も待機中のハンターはしゃがめない）。屋敷の殻とは別の箱なので、屋敷は見えない。探索になると一人称と銃に替わり、屋敷の入口（大広間の扉の前）へ移る。

## ハンター

- 一人称で、画面の中央に細い十字を出す。視野は縦 72 度（フリーカメラと同じ）。左のスティックで歩き、右で見回す。跳べるが、壁には張り付かない（フリーカメラと同じ動き）。
- 画面の右下に、白い丸い手と、ショットガン型のペイント銃（木の銃床と虹色のまだら）を出す。撃つと銃が少し跳ねる。ほかの人から見えるハンターの体も、同じ銃を両手で持ち、撃つと銃口に虹色の粒を出す。
- 右下に大きな「うつ」ボタン、その上に「しゃがむ」（押すたびに切り替え、目の高さを下げて低い所をのぞく）と「ジャンプ」。
- 撃つと 2.0 秒は次を撃てない。ボタンのふちを時計のように埋めて残りを見せる。
- 弾は十字の向きを中心に、半角 2 度の円すいの中に 5 本の線を飛ばす（中心と、上下左右に 2 度）。どれかが壁や家具より手前で隠れる人の体に当たれば発見。
- 体の当たりは骨ごとのカプセル（`doll.ts` の形の表から作る。頭・胴・腕と脚の上下）で見る。ポーズと張り付きを反映する。
- 弾は虹色の粒の筋を 0.3 秒引く。外れた線は当たった面にペンキのしぶきの板を残す（1 試合で 60 枚まで、古いものから消す）。
- 撃たれた人は 20 個ほどの破片に砕けて飛び散り、1.5 秒で消える（破片は撃たれた人の塗りの色を持つ）。
- 右下にモード名（緑）と説明 2 行を出し続ける。

### 当たりの決め方

- ハンターの端末が撃った位置と向きを親へ送る（`shot`）。親は自分の手元の屋敷の当たりと、届いている全員の体の位置・ポーズで 5 本の線を調べて決める。ハンターが当たったと見た人は参考に送るが、決めるのは親。
- 親は 2.0 秒より早い撃ちを捨てる。
- 撃つ側と隠れる側の見え方のずれを小さくするため、親は隠れる人の位置を撃った時刻（送った時刻）の 0.1 秒前までさかのぼって調べる。届いた動きの履歴（`Timeline`）を使う。
- 発見したら親が全員に `found` を配り、しぶきは全員の画面に出す。

## 見つかった人

- 通常では観戦になる。左下に「観戦中」と、見ている人の名前を出す。左右の矢印でほかの人を順に見るか、「フリーカメラ」で見て回る。見ている人がいなくなったら次の人へ移る。
- 増え鬼では、その場でハンターになる。破片が消えたら、白い体のまま一人称と銃に替わり、続きから探す。HUD の人形が白から赤へ移る。
- ペイントモードのあいだに見つかったら、ペイントモードを自動で抜ける。
- 見つかった人は挑発できない。

## 勝ち負け

| モード | 勝ち                                                             |
| ------ | ---------------------------------------------------------------- |
| 通常   | 時間内に全員見つかればハンター。1 人でも残ればカメレオン         |
| 増え鬼 | 最後まで隠れ切った人（カメレオン）。全員見つかれば最初のハンター |

勝ち負けの記録は残さない（本家にも通算の勝ち数は無い）。

## 答え合わせ

- 全員の体が壁を透かして見え、見つかっていない人は赤、見つかった人は青のふちで光る（見つかった人は撃たれた場所に体を戻して光らせる）。
- 上の HUD の下に白い字で「勝者カメレオン!」か「勝者ハンター!」を出し、その後ろに画面いっぱいの緑のペンキの飾り文字（同じ言葉を太い筆で描いた canvas の絵）を重ねる。
- 全員がフリーカメラで見て回れる。ハンターは撃ち続けられ、しぶきが残る（発見にはならない）。

## 口笛と強制挑発

- 隠れる人は右端の黄色い「挑発」ボタン（本家のキー案内の言葉）で口笛を吹ける。吹いたあと 1 秒は吹けない。フリーカメラ中も吹ける。ハンターは吹けない。ロビーでは全員が吹ける。
- 強制挑発の間隔が 0 でなければ、探索のあいだ、その間隔ごとに隠れる人の全員が自動で吹く。親が人ごとに時計を持ち、自分で吹くとその人の時計が巻き戻る。砂時計の右に、自分の次の強制挑発までの残り秒を黄色の小さな数字で出す（隠れタイムと答え合わせのあいだは止める）。
- 口笛は親を通って全員に届く。ほかの人の端末では、吹いた人の位置から水平に 2m 以内で乱数にずらした所に白い ♪（黒いふち）を 2 秒浮かべ、口笛の音を位置に合わせて左右と大きさを変えて鳴らす（Web Audio の `PannerNode`）。

## HUD

本家の並びに合わせ、字は白に黒い影の明朝（端末のヒラギノ明朝）にする。

- 上の中央に緑の砂の砂時計、その下に残り秒とフェーズの言葉。

| フェーズ   | 隠れる人       | ハンター     |
| ---------- | -------------- | ------------ |
| 隠れタイム | 探索開始まで   | 探索開始まで |
| 探索       | 隠れつづけよう | 探索時間     |
| 答え合わせ | 答え合わせ     | 答え合わせ   |

- 砂時計の左に隠れている人の白い人形を、右にハンターの赤い人形を人数分並べる。
- 隠れる人の右下に大きく「残り人数 N」（N は見つかっていない隠れる人の数）。
- 右端のボタンを縦に並べる。隠れる人は挑発（黄色）・ポーズ・ペイントモード・回転ロック・フリーカメラ。ハンターはジャンプ・しゃがむ・うつ。
- ペイントモードのあいだは、左上のパネルと上の残り秒だけを出す（1 段めと同じ）。

## 音

声は無い。効果音だけを `$lib/audio.svelte` の `bus()` から出す。

- 銃声（短いノイズ、小さめ）・口笛（上がる 2 音、方向つき）・砕ける音・紹介の音・フェーズが変わる音・見つけた音。
- 1 段めの吹き付け・張り付き・ボタンの音はそのまま。

## 通信

親の端末が審判（フェーズ・時計・ハンターの決め方・発見・勝敗・強制挑発の時計）を持つ。動きと塗りは各自が自分の体の分を決めて送り、親が `Party` の `act` と `tell` で中継する。

| 知らせ  | 向き          | 中身                                                                       | 頻度                  |
| ------- | ------------- | -------------------------------------------------------------------------- | --------------------- |
| `hello` | 子 → 親       | このゲームの版（`CHAMELEON_VERSION`）                                      | つないだとき          |
| `me`    | 各自 → 全員   | 位置・向き・見る向き・ポーズ・張り付き・しゃがみ・ペイント中か・送った時刻 | 1 秒に 20 回          |
| `dabs`  | 各自 → 全員   | 吹き付けの列の追加分と、もどす                                             | 0.05 秒ごとにまとめる |
| `wish`  | 子 → 親       | ハンター希望のオンとオフ                                                   | 押したとき            |
| `ready` | 子 → 親       | もうええよ                                                                 | 押したとき            |
| `shot`  | ハンター → 親 | 撃った位置・向き・送った時刻・当たったと見た人                             | 撃つたび              |
| `taunt` | 子 → 親       | 挑発した                                                                   | 吹いたとき            |
| `phase` | 親 → 全員     | フェーズ・残り秒・役・発見済みの人・勝者・もうええよの数・設定             | 変わるたびと 1 秒ごと |
| `found` | 親 → 全員     | 見つかった人と、当たった位置                                               | 発見のたび            |
| `splat` | 親 → 全員     | しぶきの位置と向き、弾の筋                                                 | 撃つたび              |
| `toot`  | 親 → 全員     | 口笛を吹いた人と位置                                                       | 吹くたび              |
| `paint` | 親 → 戻った子 | 全員の吹き付けの列と、今のフェーズ                                         | 戻ったとき            |

- 吹き付けは 1 つを数の列（位置 3・向き 3・半径・色 4・艶 2）にし、1 回の知らせを 32KB までに分けて送る（データチャンネルの上限 256KB より十分小さく）。
- 相手の動きは、アニマルサバイバーの `Timeline` で送った時刻から 0.1 秒遅らせてつなぐ。
- ほかの人の体は、その人の吹き付けの列を自分の端末の `PaintSurface` で塗り直して描く（3 人分の 2048² でも iPad Air の GPU に収まる）。
- 親の版がちがうか、3 秒で `hello` が届かなければ切る（おえかきのもりの `MISMATCH` と同じ扱い）。
- 切れた子は、親の「よびなおす」（おえかきのもりの `Invite.svelte` と同じ）で同じ番号に戻り、`paint` で全員の塗りと今のフェーズを受け取る。試合中に切れた隠れる人は、戻るまでその場に体を残す（撃てば発見になる）。切れたハンターは試合から抜け、ハンターが全員抜けたら探索を終える。
- 親が切れたら、子は入口の画面へ戻り「ホストとの接続が切れました」を出す。

## 確かめ方

- vitest で次を確かめる。
  - 審判のフェーズが時計どおりに進み、もうええよの全員一致で飛び、全員見つかると答え合わせへ入る。
  - 通常と増え鬼で勝者が決まる。増え鬼で見つかった人がハンターに替わる。ハンターが全員抜けると隠れる人の勝ち。
  - ハンターの決め方が希望を先に取り、足りなければ足す。
  - 撃つ間隔より早い撃ちを捨てる。壁の向こうの体には当たらない。5 本のうち 1 本でも当たれば発見。ポーズと張り付きの体にも当たる。

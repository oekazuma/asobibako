# やっぱりカメレオン プチカメレオン 設計

## 目的

隠れる人が体を半分の大きさ（プチカメレオン）にできるようにして、本家と同じく見つけにくい隠れ方を選べるようにする。全体の設計は `2026-10-08-yappari-chameleon-design.md`、本家の仕様は `2026-10-08-yappari-chameleon-original.md`、CPU と遊ぶは `2026-10-10-yappari-chameleon-cpu-design.md` に従う。

本家で確かめられたのは、0.5 倍とホストが許したときだけ使えること（v4.0.0 のパッチノート）と、体型は各自が試合の前に選ぶこと（v1.9.0）。速さ・当たり・カメラの扱いは本家で分からないので、このゲームで決める。本家の「隠れ側の大きさを変える設定」（v1.6.0、中身は不明）は入れない。

## 体型の持ち方

- 体型は `normal`（通常）と `petit`（プチカメレオン、0.5 倍）の 2 つ。
- 体型は試合の様子（`View`）に席ごとの値として親が持つ。子は選んだ体型を親へ送り（新しい知らせ `body`）、親はマップの設定の「プチカメレオンを許可」がオンのときだけ `petit` を受け付け、全員へ配る。許可がオフになると全員を `normal` に戻す。
- 体の動きの知らせ（`me`）には大きさを載せない。体型は親が許したかで決まり、ロビーで選んで試合のあいだは変えないので、様子で配れば足りる。
- 来た・戻った子にも様子で届くので、ほかの人の体の大きさがそろう。
- 知らせの形と体の当たりが変わるので、`CHAMELEON_VERSION` を 4 に上げる。

## プチの体

| 項目                                                  | プチカメレオン                                                                 |
| ----------------------------------------------------- | ------------------------------------------------------------------------------ |
| 見た目                                                | 人形をそのまま 0.5 倍（背 0.575m）                                             |
| 撃たれる当たり（骨ごとのカプセル）                    | 0.5 倍。親が撃った弾を調べるときも同じ大きさ                                   |
| 埋まりの判定・見落としポイントの体の点                | 0.5 倍の体で調べる                                                             |
| 歩くときの当たり（`move.ts` のカプセル）              | 半径と高さを 0.5 倍。段差を越える高さは今のまま                                |
| 壁や天井への張り付きの置き方（`placement` と `sink`） | 0.5 倍の体で面から離す                                                         |
| 歩く速さ・跳ぶ高さ・よじ登りの速さ                    | 通常と同じ                                                                     |
| 塗るブラシの大きさ                                    | 屋敷の中で通常と同じ大きさ（体に対しては 2 倍の太さに見える）                  |
| 三人称のカメラ                                        | 見る中心の高さと距離を体に合わせて縮め、体が画面で小さくなりすぎないようにする |

- 体型が効くのは隠れる役のときだけ。ハンターと観戦は通常の体で、増え鬼で見つかってハンターになったら通常の体に戻る（本家は一人称のハンターを既定の体にそろえている。三人称のハンターの扱いは本家で分からないので、こちらもそろえる）。ダブルの残した体は隠れたときの体型のまま。
- 答え合わせで置く見つかったときの体も、その人の体型の大きさで置く。

## 選ぶ画面

- ロビーの上の帯に「体型」のボタンを足す。押すたびに「通常」と「プチカメレオン」が切り替わり、選んだ体型はその場で自分の人形に出る。選んだものは端末に覚え（好みなので記録ありには数えない）、次につないだときも使う。
- 親のマップの設定に「プチカメレオンを許可」（既定はオフ）を足す。オフのあいだはロビーの「体型」を押せず、全員が通常の体になる。
- CPU と遊ぶでは、CPU の設定に「プチカメレオン」（許可しない・許可する）を足す。許可すると、隠れる CPU は全員プチカメレオンになり、自分の体型もロビーと同じボタンで選べる（CPU と遊ぶは始めるとロビーを通らないので、CPU の設定の画面にも「体型」を置く）。
- 本家は役が決まったあと試合の前に全員へ体型を選ぶ画面を出すが、このゲームではロビーで選ぶ（ユーザーが選んだ簡略化。隠れタイムの頭がせわしなくならない）。許可がオフのときは選ぶものが無いので、「体型」のボタンは押せない形で出す。
- 画面の言葉の「プチカメレオン」は本家の告知のとおり。「体型」「通常」「プチカメレオンを許可」は、本家の画面の表記が分からないので、このゲームで決めた言葉。

## CPU

- 隠れる CPU がプチのとき、隠れ場所の候補は同じ表を使い、プチの体で埋まらない・動く物にかからない・置いても動かないことをテストで確かめる。
- 見えにくさの表（`pnpm spots`）は体型ごとに測り、強さごとの選び方（強い 25%・普通 60%・弱い全部）は同じ。
- 探す CPU は、目立ちの測り方（体の画素のうち背景と違う割合）は変えず、怪しさの足し方と届きに使う距離を「距離 ÷ 体の倍率」にする。小さい体は、同じ大きさの体が遠くにいるのと同じ見え方なので、プチは同じ場所の通常の体の 2 倍遠くにいる扱いになる。

## 確かめ方

- 審判: 許可がオフなら `petit` を受け付けない、オンにすると受け付け、オフに戻すと全員 `normal`、来た子に体型が届く。
- 当たり: プチの体のカプセルは 0.5 倍で、通常なら当たる位置の弾がプチには当たらない。埋まり・見落としの体の点も 0.5 倍。
- 動き: プチの体で屋敷の道順の網の全部の辺を歩ける、壁と天井に張り付ける。
- CPU: プチの隠れ場所が今の確かめを通る、体型ごとの表がそろっている。
- 3 台の通しの試合（2b の e2e）にプチを混ぜて最後まで回す。CPU と遊ぶの通しの試合で、プチを許したときに隠れる CPU が小さくなる。
- 通常とプチの人形を並べた絵と、プチの三人称のカメラの絵を撮る。
- `pnpm verify` が通る。ユーザーが iPad で遊んで、プチの見つけにくさとカメラを確かめる。

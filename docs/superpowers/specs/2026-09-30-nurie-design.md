# ぬりえ 設計

線画の、線で囲まれたところをタップで塗りつぶす 1 人用の自由あそび。一覧の「ひとりで」に入れる（`players: 1`、`levels: 1`、らくがきパレードと同じくクリアのない自由あそび）。id は `nurie`、名前は「ぬりえ」。

線画は、コードで描いたテンプレート 8 枚と、写真から作ったもの。塗り方はタップで塗りつぶすだけで、ペンは置かない。

つないだ端末で同じ絵をいっしょに塗る「みんなでぬりえ」（おえかきのもりの遊び方）は、このあとの別の設計で作る。塗った状態を「場所の番号 → 色」で持つのは、そのとき送り合う中身をこれだけにするため。

## 画面

### えらぶ

タイトルの次に出る。上から順に次の 3 つを並べる。

- テンプレート 8 枚（絵の小さな見本）
- 「しゃしんから つくる」
- ぬりえちょう（途中の作品と塗り終わった作品。新しい順）

テンプレートを押すと新しい作品として、ぬりえちょうの作品を押すと続きから、ぬる画面を開く。ぬりえちょうの作品は、「けす」を押してから作品を押すと消える（らくがきパレードのずかんと同じ。押し間違いで消えないように）。

### ぬる

- 真ん中に正方形の線画。色を選んでタップすると、線で囲まれたところがその色になる。
- 下に 16 色と白。白で塗ると消したのと同じ見た目になる。
- 「1つ もどす」で、最後に塗ったところを塗る前の色に戻す（何回でも戻せる）。
- 「できた！」でぬりえちょうに保存して、えらぶ画面に戻る。
- 「しゃしんに ほぞん」で写真アプリへ入れる（`src/lib/share.ts` の `saveImage`）。
- 線の上をタップしたときは、近くの線でない場所を塗る。
- 塗るたびに自動でぬりえちょうへ保存する（途中で閉じても続きから塗れる）。

### しゃしんから

1. 写真を選ぶか撮る（`<input type="file" accept="image/*">`）。
2. 輪郭を拾った線画を見ながら、「せんの おおさ」のスライダーで線の量を変える。
3. 「これで ぬる」で新しい作品として、ぬる画面を開く。

写真は端末の中だけで扱い、外へは送らない。

## 仕組み

### 線画

線画は 768 × 768 の白黒の画像（線のあるところだけ 1 の `Uint8Array`）として持つ。

テンプレートは 100 × 100 の座標の SVG パスと線の太さで持ち（`templates.ts`）、画面では同じパスを canvas の `Path2D` でなめらかに描く。塗る場所を分けるための白黒の画像は、同じパスを 768 × 768 の canvas に描いて作る。テンプレートは線が途切れないよう、閉じた形で描く。

写真から作る線画（`lineart.ts`）は、DOM を使わない純粋な関数で次の順に作る。

1. 写真を 768 × 768 に収まるよう縮め、余白は白にする（切り取らない）。
2. 灰色にしてぼかす。
3. 明るさの変わり目の強さを出し、強いほうから 1% の強さを基準にして、その 60%（線が少ない）〜15%（線が多い）より強いところを線にする。「せんの おおさ」はこの割合を動かす（強さの割合で決めると、白地に黒い四角のような単純な形で輪郭の一部しか線にならず、線が閉じないため）。
4. 小さすぎる点（数十画素より小さいかたまり）を消す。
5. 線を 1 画素太らせて、線のすき間をふさぐ。

### 塗る場所

線でない画素を、上下左右のつながりでまとめて番号を振る（`regions.ts`）。線の画素は番号なし。タップした位置の番号の場所を、その色で塗る。

塗った状態は「場所の番号 → 色」の表と、戻すための「場所・前の色」の並びだけで持つ。番号は同じ線画から同じ順で振るので、保存するのは表だけでよい。

描くときは、塗りの画像（画素ごとに場所の色）を置いてから、その上に線を描く。塗りは線の下まで届くので、線と塗りのあいだに白いすき間が出ない。

### 保存

ぬりえちょうは IndexedDB（`asobibako-nurie`）に 30 作品まで残し、あふれたら古いものから消す。作品ごとに次を持つ。

- 線画のもと（テンプレートの id か写真の印）と、塗る場所を分けた線画（1 画素 1 ビットに詰める。テンプレートのパスをあとで直しても、保存した作品の場所の番号がずれないように）
- 場所の番号 → 色の表
- 見本の小さな画像
- 最後に塗った日時

写真から作った線画は大きいので、アプリのバックアップ（`asobibako:` の localStorage の書き出し）と控え（`mirror.ts`）には入れない。

## テンプレート

りんご・おうち・さかな・ねこ・ロケット・ちょうちょ・くるま・おはな の 8 枚。どれも丸と曲線の組み合わせのシンプルでかわいい線画にし、塗れる場所がそれぞれ 5〜15 か所ほどになるよう、内側に模様の線を入れる。

作りはじめてすぐに、8 枚と写真から作った線画の見本を画像にして見てもらい、方向を確かめる。

## コードの分け方

`src/lib/games/nurie/` に閉じる。

| ファイル                                                                   | 役目                                                                         |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `regions.ts`                                                               | 線画から場所の番号を振る・タップした位置の場所（線の上なら近くの場所）を探す |
| `paint.ts`                                                                 | 塗った状態（色の表と戻す並び）を進める純粋な関数                             |
| `lineart.ts`                                                               | 写真の画素から線画を作る純粋な関数                                           |
| `templates.ts`                                                             | テンプレート 8 枚のパスと名前                                                |
| `book.ts`                                                                  | ぬりえちょうの IndexedDB への保存・読み込み・上限                            |
| `Nurie.svelte`                                                             | えらぶ・ぬる・しゃしんから の切り替え                                        |
| `Picker.svelte` / `Canvas.svelte` / `Palette.svelte` / `PhotoMaker.svelte` | それぞれの画面の部品                                                         |

盤面の指は `BoardInput` で読む（横向きで回しても座標がずれないため）。`.svelte` は 200 行未満に保つ。

## 確かめ方

vitest で次を確かめる。

- `regions.ts` で、線で囲んだ場所が別々の番号になり、線の画素に番号が付かないこと、線の上のタップが近くの場所になること
- `paint.ts` で、塗る・何回でも戻す・白で塗る
- `lineart.ts` で、テスト用の小さな画像（白地に黒い四角など）から輪郭の線ができること、「せんの おおさ」を上げると線の画素が増えること、小さな点が消えること、線が閉じてすき間ができないこと
- `book.ts` で、31 作品目を入れると最も古い作品が消えること（IndexedDB は `fake-indexeddb` を使わず、保存の上限を決める純粋な関数を分けて確かめる）

見た目は playwright の headless Chrome で、テンプレート 8 枚を塗った画面と、見本の写真から作った線画を撮って確かめる。テンプレートごとに場所の数を数え、線が閉じていない（外と中がつながった）テンプレートが無いことも同じ確認で見る。

# Animal Survivors 火の鳥のひな 設計

## ねらい

火山をクリアしたごほうびに、10 匹めの動物「火の鳥のひな」を足す。強さの段は竜の子と同じ最強で、一度だけその場でよみがえる強みと、専用の武器「火の羽根」を持つ。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い | 決めたこと                                                       |
| ---- | ---------------------------------------------------------------- |
| 強み | 倒れると一度だけその場でよみがえる（店の復活とは別）             |
| 武器 | 専用の「火の羽根」。まわりへ飛んで戻り、折り返すところに炎を残す |
| 解放 | 実績「火山をクリア」                                             |

## 1. 動物

- id は `chick`。名前は「火の鳥のひな」、育つと「炎の若鳥」「火の鳥」（ボスの「不死鳥」と紛れないよう分ける）。
- 段は最強（`tier: 4`）。HP は竜の子より少なめ、速さは 10 匹でいちばん速く、攻撃は竜の子と同じくらい。数はボットで合わせる（6 章）。
- 実績「火山をクリア」の動物にする。前に火山をクリアした記録は、読み込んだときに仲間になる（今の `parseRecords` が達成済みの実績の動物を足す）。
- キャラ選択の「とくい」は「一度だけ、倒れてもその場でよみがえる」。

## 2. よみがえり

- 倒れると（HP が 0 以下）一度だけ、その場で HP 半分でよみがえる。店の「復活」より先に使い、店の復活はそのあとに残る。
- よみがえるときは、まわりの敵を押し返さず（店の復活と同じ押し返しは使わない）、2 秒の無敵と光る演出、帯「よみがえった！」を出す。
- 倒れた回の記録（リザルトの GAME OVER、記録の倒れた回）は、よみがえりと店の復活を使い切って本当に倒れたときだけ。
- お題のしばり「HP 半分」でも同じく HP 半分（その回の最大 HP の半分）でよみがえる。

## 3. 火の羽根と専用進化

- 火の羽根（`fireFeather`）は、今のブーメランの動き方（`boomerang`）で、自分のまわりへ数枚を投げ、戻ってくる。行きと帰りで当たる。
- 羽根が折り返すところに、炎の武器と同じ小さな炎（`zones.ts` の炎）を少し残す。
- この動物だけの武器（`exclusive`）で、ほかの動物の 3 択に出ず、ふつうの進化はない。
- 専用進化形は「火の鳥の翼」（`fireFeatherSp`）。3 段階めに育って火の羽根が Lv5 になると入れ替わる。羽根の数と炎の大きさが増え、強さは同じ型の進化形のおよそ 1.5 倍（最強の段の決まり）。

## 4. 絵

- 3 段階の姿（16・20・24 ドット）を、今の動物と同じく歩き 4 コマ・攻撃・やられで描く。黒い丸目とほっぺのかわいい顔にし、強さは羽と炎の飾りで見せる。
- 火の羽根と、専用進化形の印（金色に赤い王冠）を描く。
- 絵は使う前に見本を見せて決める。

## 5. しくみ

| ファイル                                         | 変えること                                              |
| ------------------------------------------------ | ------------------------------------------------------- |
| `animals.ts`                                     | `chick`（段・能力・武器・専用進化・解放の文）           |
| `art/animals.ts`・`art/grown.ts`・`art/items.ts` | 3 段階の姿と武器の印                                    |
| `weapons.ts`                                     | `fireFeather`・`fireFeatherSp`（`exclusive`）           |
| `arms.ts`・`zones.ts`                            | 折り返すところに炎を残す                                |

| `achievements.ts`                                | 「火山をクリア」に `animal: 'chick'`                    |
| `book.ts`                                        | 動物の姿に 3 段階が増える（表から作るので自動）         |

## 6. 確かめ方

- vitest で、一度だけよみがえる・店の復活より先・2 回めは店の復活か倒れる・お題の HP 半分、火の羽根が他の動物の 3 択に出ない・折り返しに炎、専用進化の入れ替わり、火山のクリアで仲間になる・古い記録でも仲間になる、を確かめる。
- ボットで、10 匹の店なし・半分の森と火山のクリアの割合を比べ、竜の子と同じくらいの強さにする（よみがえりのぶんは能力を少し下げる）。
- `pnpm verify` を通し、キャラ選択・育つ瞬間・よみがえりを headless で撮る。

## 7. 調整の結果

ボットで、ひなと竜の子を 12 回ずつ遊ばせた（店なしの森、店半分の雪山と火山）。

| 案                                           | 店なしの森 | 店半分の雪山 | 店半分の火山 |
| -------------------------------------------- | ---------- | ------------ | ------------ |
| 竜の子（比べる元）                           | 5/12       | 12/12        | 10/12        |
| はじめの数（HP 110・羽根 14）                | 1/12       | 8/12         | 7/12         |
| HP 125・羽根 19（使う）、Lv の伸びと翼を強く | 3/12       | 10/12        | 9/12         |

- はじめの数は竜の子よりはっきり弱く、店なしでは 6 分ほどで倒れた。羽根のダメージと間（19・1.3 秒）、Lv の伸び、火の鳥の翼（56・0.9 秒）、HP 125 にして、竜の子と 12 回のぶれの範囲で同じくらいにした。

# おえかきのもりの動物・保存・長さ 設計

## ねらい

家族（子どもも入る）で遊び続けやすくする。次の 5 つを入れる。

1. 版のちがう端末どうしでつなごうとしたとき、理由を出す（今は QR を読んでも何も起きない）。
2. みんなでぬりえで、親が絵を配り終える前に戻った子が、絵を受け取れずに止まるのを直す。
3. 1P・2P のかわりに、端末ごとに選んだ動物で人を表す。
4. 結果の画面から、その回の絵をまとめた 1 枚を写真アプリへ保存する。
5. 遊ぶ長さを「みじかめ・ふつう・ながめ」から選ぶ。

## 決めたこと

| 問い             | 決めたこと                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| 何で人を表すか   | 動物を 8 つから選ぶだけ。名前は打たない。端末ごとに覚える                                          |
| 結果の保存       | 順位とその回の絵を並べた 1 枚を、どの端末からでも保存できる                                        |
| 長さの選び方     | 3 つの中から。親が遊び方を選ぶ画面で一緒に選ぶ                                                     |
| 版をどう比べるか | アプリの版ではなく、つなぎ方の版（`PROTOCOL`）を比べる。ほかのゲームを直しただけでは更新を求めない |

## 1. 版ちがいの知らせ

- `src/lib/net/party.svelte.ts` に `PROTOCOL`（いまは 3）を置く。知らせの形を変えるたびに 1 上げる。
- 子は `Party.guest` を作るとすぐ、最初の知らせ `{ t: 'hello', v: PROTOCOL, was, look }` を送る（`was` は切れる前の番号、`look` は動物）。
- 親の `add()` は `hello` を待つ。`v` が自分とちがえば `{ t: 'mismatch' }` を送って閉じる。3 秒待っても `hello` が来なければ、古い版の子とみなして同じように閉じる。どちらの場合も `add()` は `'mismatch'` を返す。
- 親の画面（ロビーと呼び直しの重ね）は、`'mismatch'` なら「アプリの はんが ちがうよ。どちらも さいしんに してね」を出す。
- 子は `mismatch` を受け取ったら `Party.mismatch` を立てる。画面はロビーに戻り、同じ文を出す。古い版の子はこの知らせを知らないので「つながりが きれました」になる。そのときも親の画面に理由が出るので足りる。

## 2. みんなでぬりえの取りこぼし

- 親の `Together.svelte` は、配る線画の知らせを作る処理（`encodeLines`）を `Promise` として持つ。
- 子が戻ったら、その `Promise` を待ってから線画を送り、そのあと塗った色と「できた！」を送る。
- 配る前（親がまだ絵を選んでいる）なら何も送らない。子は「おやが えを えらんでいます…」のまま待ち、配られたときに受け取る。

## 3. 動物のアイコン

- 動物は、いぬ・ねこ・ねずみ・くま・おおかみ・ひつじ・はちの 7 つ（`src/lib/icons.ts` にある `dog` / `cat` / `mouse` / `bear` / `wolf` / `sheep` / `bee`）と、新しく描く `rabbit`（うさぎ）。表は `looks.ts` に、名前（ひらがな）とアイコンの組で持つ。
- 選んだ動物は `asobibako:oekaki-mori:look` に覚える。はじめての端末は、表からランダムに 1 つ選んでおく。
- つながる前のロビーに「あなたは」と 8 つの動物を並べ、押すと選び直せる。
- 親は自分の動物と、子から `hello` で届いた動物を `Party.looks`（番号 → 動物）に持ち、顔ぶれの知らせ `members` に `looks` を添えて全員に配る。
- 画面で「2P」と出していた所を、動物の絵と名前に替える。名前の部品 `Face.svelte` は、番号の色の丸に動物の絵を入れ、`name` があれば名前を添える。
  - 上の帯の点数の丸（`TopBar`）、あつまった画面の顔ぶれ（`Lobby`）、結果の順位と絵（`Result`）は、絵と名前を出す。
  - 吹き出し（`Bubbles`）、「〜が じゅんびしています」（`Play` と `TopBar`）、「〜が こたえています」（`Buzzer`）、「〜の つながりが きれました」（`Invite`）は、名前を文の中に入れる。
- 同じ動物を選んだ人どうしは、今の番号の色（1 が青、2 が赤、3 が緑）で見分ける。
- 動物の表を引く関数 `who(seat, looks)` は、届いていない番号には番号（「2P」）を返す。

## 4. 結果の絵を保存

- 結果の画面に「しゃしんに ほぞん」を置く。どの端末からでも押せる。
- `album.ts` が 1 枚の画像を作る。上に「おえかきのもり」と順位（動物の絵・名前・点数）、下にその回の絵を 2 列（3 枚以下なら 1 列）で並べ、それぞれにお題と描いた人の動物を添える。地は紙の色。
- 絵の大きさと位置は `layout(n)` が決める（DOM を使わない純粋な関数で、テストで固める）。描くのは `strokes.ts` の `render` と `fx.ts` の `icon()` を使う。
- 保存は `src/lib/share.ts` の `saveImage`（共有シート）。ファイル名は `oekaki-mori.png`。

## 5. 遊ぶ長さ

- `engine.ts` に長さの表を置く。

  | 長さ                | ひとりが描く回数 | エゴコロクイズの描く時間 | はやおし検定の描く時間 |
  | ------------------- | ---------------- | ------------------------ | ---------------------- |
  | みじかめ（`short`） | 1 回             | 60 秒                    | 45 秒                  |
  | ふつう（`normal`）  | 2 回             | 90 秒                    | 60 秒                  |
  | ながめ（`long`）    | 3 回             | 120 秒                   | 80 秒                  |

- `create()` は長さを受け取り、描く順番の回数と描く時間を決める。`Quiz` は長さを持ち、`start()` が描く時間を表から引く。ヒント（残り 45 秒と 20 秒）は今のまま。
- はやおし検定の点の段（残り 40 秒以上で 3 点、20 秒以上で 2 点）は、描く時間に対する割合（2/3 と 1/3）に替える。ふつうでは今と同じ点になる。
- 遊び方選びの上に 3 つのボタンを並べ、選んだものを `asobibako:oekaki-mori:length` に覚える。審判は `start(mode, length)` で受け取る。
- みんなでぬりえには時間がないので、長さを使わない。

## 部品と流れ

| 部品                                                                   | 変えること                                                                                     |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `src/lib/net/party.svelte.ts`                                          | `PROTOCOL`、`hello` の `v` と `look`、`add()` の版の確かめと 3 秒の見切り、`looks`、`mismatch` |
| `looks.ts`（新）                                                       | 動物の表、覚えた動物の読み書き、`who()`                                                        |
| `Face.svelte`（新）                                                    | 番号の色の丸と動物の絵（と名前）                                                               |
| `src/lib/icons.ts`                                                     | `rabbit` を足す                                                                                |
| `Lobby.svelte`                                                         | 動物を選ぶ列、顔ぶれを動物で出す、版ちがいの知らせ                                             |
| `TopBar` / `Bubbles` / `Play` / `Buzzer` / `Invite` / `Result`         | 番号のかわりに動物                                                                             |
| `album.ts`（新）と `Result.svelte`                                     | 1 枚の画像を作って保存                                                                         |
| `engine.ts` / `referee.ts` / `ModeSelect.svelte` / `OekakiMori.svelte` | 長さ                                                                                           |
| `Together.svelte`                                                      | 配り終えるのを待って送り直す                                                                   |

コンポーネントは 200 行未満に保つ。`Together.svelte` は 199 行なので、送り直しの処理は別の `.ts` に出す。

## まちがったとき

- 子の `hello` が届かないまま親が閉じたら、子の画面は今どおり「つながりが きれました」になる。
- 覚えた動物が読めない（localStorage が空、知らない名前）ときは、表からランダムに選び直す。
- 保存の共有シートが開けない端末では、今のぬりえと同じく何もしない。

## 確かめ方

テストで固めること。

- `party.svelte.test.ts` で、版がちがう `hello` を断って `mismatch` を返すこと、3 秒で見切ること（偽のタイマー）、`looks` が全員に届くこと。
- `engine.test.ts` で、長さごとの描く順番の回数と描く時間、はやおし検定の点の段が割合で決まること。
- `looks.test.ts` で、覚えた動物の読み書きと、読めないときに選び直すこと、`who()` が届いていない番号に番号を返すこと。
- `album.test.ts` で、`layout(n)` が絵の数に合わせて重ならずに並べること。
- `Together.svelte.test.ts` で、配り終える前に戻った子にも、配り終えたあとで線画が届くこと。
- 画面のテストで、帯と吹き出しに動物の名前が出ること。

通しで確かめること。3 ページと偽カメラの仕組みで、動物を選んでつなぎ、帯・結果・保存する 1 枚を撮る。長さの「みじかめ」で、ひとり 1 回で結果まで進むこと。

# Animal Survivors 図鑑 設計

## ねらい

面・敵・ボス・動物が増え、何に会ってきたかを振り返る場所が無い。会った敵・倒したボス・育てた姿・拾った品を集める図鑑を足し、新しく載るたびに少しコインをもらえるようにして、集める楽しみを店の強化へつなげる。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い       | 決めたこと                                         |
| ---------- | -------------------------------------------------- |
| 載せるもの | 敵・ボス・動物の姿・品                             |
| ごほうび   | 新しく載るたびにコイン、種類ごとに全部そろうと実績 |

## 1. 載せるもの

| 種類     | 中身                                                                           | 数  |
| -------- | ------------------------------------------------------------------------------ | --- |
| 敵       | 3 つの面のふつうの敵と、ボスの手下。倒した数、強化個体とヌシを倒した印         | 20  |
| ボス     | 6 体のボスときらきらハリネズミ。倒した回数と、出てから倒すまでのいちばん速い秒 | 7   |
| 動物の姿 | 9 匹 × 3 段階。その姿まで育てると載る。名前を出す                              | 27  |
| 品       | 肉・コインの小袋・大袋・磁石・金の磁石・十字架・時計・宝箱・経験値の袋         | 9   |

- まだ載っていないものは黒い影で出し、名前は「？？？」にする。
- 載せる敵の表は `book.ts` が敵の表から作る（`prop`・`boss`・`metal` でない敵）。ボスは `boss` を持つ敵ときらきらハリネズミ。

## 2. ごほうび

| 新しく載ったもの | コイン |
| ---------------- | ------ |
| 敵               | 10     |
| 品               | 10     |
| 動物の姿         | 30     |
| ボス             | 50     |

- 種類ごとに全部そろうと実績（4 つ、各 300 コイン）。
- 載ったときのコインは記録のコインに足し、リザルトで「図鑑 +N コイン」と見せる。
- 今の記録で分かるもの（倒したボス、育ったことの分かる 1 段階め＝仲間の動物）は、記録を読むときに載せる。ごほうびのコインはそのときには渡さない（あとから昔の記録でコインが急に増えないように）。

## 3. 記録

- `Records.book`：`enemies`（敵の id → 倒した数）・`elites`・`chiefs`（倒したことのある敵の id）・`bosses`（ボスの id → 倒した回数）・`fastest`（ボスの id → いちばん速い秒）・`forms`（`dog:0` の形）・`items`（品の種類）。
- その回のまとめ（`RunSummary.book`）に、敵ごとの倒した数・強化個体とヌシの id・ボスを倒すまでの秒・育った段階まで・拾った品を入れ、`record()` が足して、新しく載った数からコインを出す。
- 古い記録は空で読み、壊れた値（数でない数・知らない id）は捨てる。

## 4. 画面

- キャラ選択の下に「図鑑」のボタンを足す（「パワーアップ」「実績」と並べる）。
- 図鑑の画面（`Book.svelte`）は「敵・ボス・動物・品」のタブと絵の格子。上に種類ごとの「載った数 / 全部」。
- 札を押すと、下の帯に名前と記録（倒した数・速い秒など）を大きく出す。

## 5. しくみ

| ファイル                                                                                         | 変えること                                             |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| `book.ts`（新）                                                                                  | 載せるものの表、まとめから記録へ足す、ごほうびの計算   |
| `world.ts`                                                                                       | その回の敵ごとの倒した数・ボスを倒すまでの秒・拾った品 |
| `records.ts`                                                                                     | `Records.book` の読み書き、`record()` から図鑑を足す   |
| `achievements.ts`                                                                                | 図鑑の実績 4 つ                                        |
| `Book.svelte`・`BookCard.svelte`（新）・`Survivors.svelte`・`CharSelect.svelte`・`Result.svelte` | 画面                                                   |

## 6. 確かめ方

- vitest で次を確かめる。
  - 載せる表の数（敵 20・ボス 7・姿 27・品 9）。
  - 1 回のまとめで記録に足され、新しく載った分だけコインが入り、同じものは 2 度コインを出さない。
  - 古い記録から倒したボスと仲間の 1 段階めが載り、そのときコインは出ない。壊れた値は捨てる。
  - 種類ごとに全部そろうと実績。
  - 図鑑の画面が、載ったものは絵と名前、載っていないものは影と「？？？」を出し、札を押すと記録を出す。
- headless Chrome で図鑑の画面を撮る（iPad の縦と iPhone の幅）。
- `pnpm verify` を通す。

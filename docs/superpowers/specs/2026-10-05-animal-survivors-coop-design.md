# アニマルサバイバー ふたり協力プレイ 設計

## 目的

2 人がそれぞれの iPad を持ち、同じステージを 2 匹で 10 分生き延びる。つなぎ方はおえかきのもりの QR の手順（`src/lib/net/Handshake.svelte`）と `Party`（`src/lib/net/party.svelte.ts`）を使う。

手ざわりが主役なので、先に「2 台で 2 匹が動き、敵を倒し、経験値が共通でたまる」だけの試作を作り、iPad 2 台で触ってもらってから作り込む。

## 決めたこと

| 項目         | 決め                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| 人数         | 2 人まで                                                                                                      |
| 進め方       | 親がゲームを進め、子に様子を配る                                                                              |
| 経験値       | 2 匹で共通。レベルが上がると止め、2 人がそれぞれ自分の端末で自分の動物の 3 択を選び、2 人とも選んだら再開する |
| 倒れたとき   | 倒れた子はその場に残り、もう 1 匹が 3 秒そばにいると HP 半分で起き上がる。2 匹とも倒れたら終わり              |
| 記録         | 各自の端末の動物・パワーアップ・装備で遊び、コイン・券・実績・図鑑・動物ごとの記録は各自の端末に入る          |
| ステージと釜 | 親が選ぶ。賭けは親だけが払う                                                                                  |
| アルカナ     | 2 人で共通にして親が選ぶ                                                                                      |
| 今日のお題   | 1 人用のまま                                                                                                  |

## 作り込みで決めたこと

試作を端末 2 台で触ってもらったあとに決めた。

| 項目                         | 決め                                                                                                                                                                              |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| コインとガチャ券             | どちらが拾っても 2 人ともらえる。その回のコインと券を、2 台ともそれぞれの記録に入れる                                                                                             |
| 宝箱                         | 拾った動物の持ち物が上がり、拾った人の端末で開ける演出を見る。そのあいだは 2 人とも止まる                                                                                         |
| 一時停止                     | どちらが押しても 2 人とも止まり、相手の画面には「なかまが とめています」を出す。止めた人の「つづける」で再開する。止めた人が「やめる」と、その人だけが抜けて、相手は 1 人で続ける |
| 3 択                         | 子の 3 択は子の端末で選ぶ。引き直し・飛ばす・除外は、その動物の回数を使う                                                                                                         |
| 起こす                       | 倒れた動物のそばにもう 1 匹が 3 秒いると、HP 半分で起き上がる                                                                                                                     |
| ボスの登場と育つ瞬間         | 子の端末でも見せる。育つ瞬間は自分の動物のときだけ                                                                                                                                |
| 延長戦                       | 親が選ぶ。子の画面には「おやが えらんでいます」を出す                                                                                                                             |
| 動物・ステージ・釜・アルカナ | つながったあと、2 人がそれぞれ動物を選ぶ。親がステージと釜を選び、始めのアルカナも親が選ぶ                                                                                        |
| 終わったとき                 | 2 台ともリザルトを出し、それぞれの記録に入れる。賭けは親だけが払い、戻るのも親だけ。「もう一度」は親が押すと 2 人とも同じ動物・ステージ・釜で始まる                               |
| 切れたとき                   | 子が切れたら、親は 1 人で続け、子の動物は消える。親が切れたら、子は親から最後に届いたその回のまとめを記録して終わる（親は 10 秒ごとに子のぶんのまとめを送る）                     |

## 全体の形

親の端末だけが `World` を進める。子の動物も親の端末で計算する。

子は自分の動物を自分の端末で動かし、位置と向きを親へ送る（スティックの向きを送って親に動かしてもらうと、Wi-Fi の遅れのぶん自分の動きがもたつく）。敵・玉・弾・効果・品・予告・溶岩・相棒は、親から届く様子を間をなめらかにつないで描く。

敵との当たり・ダメージ・拾った品・3 択の中身・宝箱の中身は、すべて親が決める。子の端末は決まった結果を見せるだけにする。

## ゲーム本体の 2 匹化

自分の動物にかかわる値を 1 匹ぶんのまとまり `Hero` にまとめ、`World` は `heroes` に持つ。まとめる値は次のとおり。

- 動物（`animal`）・育ちの段階（`form`）・能力（`stats`・`boost`・`fx`）・装備（`worn`・`greed`）
- 道具の回数（`rerolls`・`revives`・`rebirths`・`skips`・`banishes`・`banished`）
- 位置と HP（`player`）・武器（`weapons`）・パッシブ（`passives`）
- 武器ごとのダメージ（`dealt`）・その回に作った進化形（`evolvedNow`）

経験値・レベル・時計・敵・玉・弾・品・予告・出来事・アルカナ・釜は `World` に残し、2 匹で共通にする。

動物ごとに進める部分（武器を撃つ・品を拾う・当たってダメージを受ける・育つ）は 1 匹ずつ順に回す。敵は近いほうの動物を追う。経験値の玉と品は、近いほうの動物が拾う。

1 人で遊ぶときは `heroes` が 1 匹で、今と同じに動く。今あるテストは書き換えずにそのまま通るようにする（`w.player` などの読み口は 1 匹めを指す形で残す）。

## つなぎ方と知らせ

`Party` を 2 人までに限って使う。アニマルサバイバーの知らせには自分の版の番号（`COOP_VERSION`）を付け、2 台の版が違えばつながったあとすぐに知らせて切る。

子から親へは `act` で送る。

| 知らせ  | 中身                                     | 回数             |
| ------- | ---------------------------------------- | ---------------- |
| `move`  | 自分の位置・向き・動いているか           | 1 秒に 30 回ほど |
| `pick`  | 3 択で選んだもの・引き直し・飛ばす・除外 | その時だけ       |
| `chest` | 宝箱を開けた                             | その時だけ       |
| `ready` | 動物を選び終えた、もう一度の用意ができた | その時だけ       |

親から子へは `tell` で送る。

| 知らせ   | 中身                                             | 回数         |
| -------- | ------------------------------------------------ | ------------ |
| `snap`   | 画面に要るものの様子                             | 1 秒に 20 回 |
| `prompt` | 3 択の候補・宝箱の中身・ボスの登場・育つ瞬間・帯 | その時だけ   |
| `over`   | 決着とその回のまとめ（子の動物のぶん）           | その時だけ   |

`snap` は、敵・玉・弾・効果・品・予告・溶岩を、種類の番号と座標の数の列にして小さくする。いちばん多いとき（敵 400・玉 400・弾 180・効果 450）でも 1 回 20KB ほどに収め、試作で実際の大きさと iPad での読み込みの時間を測る。

子が切れたら、親は 1 人で続ける（子の動物は消える）。親が切れたら、子は「つながりが きれました」を出し、その回の記録だけを残して終わる。

## 画面の流れ

1. キャラ選択のメニューに「ふたりで遊ぶ」を足す。押すと QR で親と子に分かれる。
2. つながったら、2 人とも自分の端末で、自分の記録の仲間の中から動物を選ぶ。
3. 親がステージと釜を選び、アルカナを選ぶ。子の端末には、親が選んでいるあいだの待ち画面を出す。
4. 遊ぶ。一時停止はどちらが押しても 2 人とも止まる。
5. 終わったら、それぞれの端末にリザルトを出し、それぞれの記録に入れる。「もう一度」は親が押すと 2 人とも始まる。

## 試作の範囲

| 入れるもの                                           | まだ入れないもの                                             |
| ---------------------------------------------------- | ------------------------------------------------------------ |
| 本体の 2 匹化（1 人のときは今と同じ）                | 各自の端末での 3 択（試作では親の端末が 2 匹ぶん自動で選ぶ） |
| 「ふたりで遊ぶ」から QR でつなぐ                     | 起こす動き・宝箱・ボスの登場と育つ瞬間の演出                 |
| 2 匹が森で同時に動き、敵を倒し、経験値が共通でたまる | 延長戦・リザルトと記録・もう一度                             |
| 子の端末で敵・玉・弾・相棒をなめらかに描く           | 切れたときの扱い（試作では止めるだけ）                       |

試作のあと、iPad 2 台で子の動きのもたつき・敵の動きのなめらかさ・重さを見てもらい、それから残りを作り込む。

## 確かめ方

- 本体の 2 匹化は vitest で確かめる。1 人のときの今のテストはそのまま通し、2 匹のときは敵が近いほうを追うこと・経験値が共通でたまること・それぞれの武器が撃つことを足す。
- `snap` の作り方と読み方は、作って読んだ結果が元の様子と同じになることを vitest で確かめる。
- つないだ通しは、headless Chrome の 2 ページと偽カメラで QR を渡して確かめる（おえかきのもりで使った形）。
- 試作は iPad 2 台で触ってもらう。

# Animal Survivors 3D のガチャの演出 設計

## ねらい

ガチャを引く瞬間をもっと楽しくする。装備の画面のガチャを引いたあとの演出だけを、ガチャガチャの機械の 3D にする。ハンドルを自分で回して、転がり出たカプセルを割り、光の色でレア度が分かる。レア以上は割れる前に光る前ぶれがある。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い     | 決めたこと                                                                |
| -------- | ------------------------------------------------------------------------- |
| 題材     | ガチャガチャの機械（ガラスの球にカプセル、ハンドル、取り出し口）          |
| 絵の味   | 低い解像度で描いて拡大する、ドット風の粗い 3D。品のアイコンは今のドット絵 |
| 手ざわり | 指でハンドルを回すと始まる。タップで早送り、「とばす」で結果へ            |
| 前ぶれ   | レア以上は割れる前にカプセルが青や金に光る。伝説はまれに「青から金」      |
| 進め方   | 核だけの試作を実機で触ってもらってから、10 連と仕上げを作る               |

## 1. 流れ

1. 装備の画面で引き方を押すと、今と同じく先に引いて記録に保存する（演出の途中で閉じても品は失わない）。そのあと、全画面の 3D の演出を開く。
2. 機械が出て、ハンドルの上に「まわしてね」の印が出る。ハンドルのまわりを指でなぞると回り、4 分の 3 回ったら止まらずに 1 回転して、中のカプセルがかき混ぜられる。
3. カプセルが取り出し口へ転がり出る。カプセルの色は品のレア度とは関係のない飾りの色。
4. 前ぶれ（2 章）のあと、カプセルを押すと上下に割れ、レア度の色の光（白・青・金）が立って、品のアイコンと名前とレア度が浮かぶ。
5. もう一度押すと閉じて装備の画面に戻る。

- 10 連は、1 回回すとカプセルが続けて 10 こ転がり出て並ぶ。押すと左から順に割れ、伝説のところだけ少し間を取る。最後に 10 こを並べて見せる。
- どこでも画面を押すと、今の動きを最後まで早送りする。右上の「とばす」で、すぐに結果の並びへ行く。

## 2. 前ぶれ

| 品のレア度  | 前ぶれ                                                       |
| ----------- | ------------------------------------------------------------ |
| ふつう      | なし                                                         |
| レア        | 転がり出たカプセルが青く光る                                 |
| 伝説        | 回すときに機械が揺れ、カプセルが金に光る                     |
| 伝説（1/4） | はじめは青く光り、押すと止まって揺れてから金に変わる（昇格） |

- 前ぶれは引いた結果から決め、乱数は演出のためだけに使う（結果は変えない）。
- 10 連では、10 この中でいちばん高いレア度で機械の揺れを決める。

## 3. 絵

- 機械は three の球・円柱・箱などの組み合わせで作る。赤い台、透明なガラスの球、色とりどりのカプセル、白いハンドル、取り出し口。
- 描く大きさを画面の 3 分の 1 にして、拡大するときにぼかさない（`image-rendering: pixelated`）。光や揺れも同じ粗さで描く。
- 品のアイコンは `art/gear.ts` のドット絵を板に貼って浮かべる。
- 光の柱と粒はレア度の色。金は数を増やし、ゆっくり回る光の筋を足す。

## 4. しくみ

| ファイル                   | 役目                                                                                                                  |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `gacha-show.ts`（新しい）  | 演出の段取り（待つ・回す・転がる・前ぶれ・割れる・見せる）と、ハンドルの角度、前ぶれの決め方。DOM も three も使わない |
| `gacha3d.ts`（新しい）     | three の場面（機械・カプセル・光）。段取りの状態を受けて描く                                                          |
| `Gacha3D.svelte`（新しい） | 全画面の重ね、指の入力、「とばす」、three を読み込むまでの待ち                                                        |
| `Gacha.svelte`             | 引いたあとに `Gacha3D` を開く                                                                                         |
| `sounds.ts`                | ハンドルのカチカチ、転がる音、割れる音、伝説のファンファーレ                                                          |

- three は演出を開くときに読み込み、装備の画面やゲームの一覧には載せない。
- WebGL が使えないときと、動きを減らす設定では、今の 2D のカプセルの並び（`Capsule.svelte`）で結果を見せる。
- 演出を閉じたら three の場面を捨てる（遊ぶ画面へ持ち越さない）。

## 5. 進め方

1. 試作。機械・ハンドルを回す・カプセル 1 こ・割れて光る・品が浮かぶ、までを作る。headless の Chrome で撮って見せ、実機で回す手ざわりを触ってもらう。
2. 感想で直してから、前ぶれ・10 連・早送りと「とばす」・音・2D の代わり、を作る。

## 6. 確かめ方

- vitest で、段取りの進み方（回した角度で始まる・押すと早送り・とばすで結果へ）、前ぶれの決め方（ふつうはなし、伝説の 1/4 が昇格、結果は変えない）、10 連の機械の揺れ、WebGL が無いときに 2D で結果を出すこと、を確かめる。
- headless の Chrome で、回す途中・転がり出た・前ぶれ・割れた瞬間・10 連の並びを撮る。
- `pnpm verify` を通す。

## 7. 2 段め（試作のあと）

試作を触ってもらい、3D はこのまま進める。10 連も 3D にし、レア度が高いほど豪華にして、確定演出を入れる。

### 割れる瞬間

|      | ふつう     | レア                   | 伝説                                           |
| ---- | ---------- | ---------------------- | ---------------------------------------------- |
| 光   | 白い光の柱 | 青い光の柱と光の筋     | 金の太い光の柱、二重に回る光の筋、金の粒が降る |
| 画面 | そのまま   | 少し暗くなる           | 真っ暗になって機械が金に照らされ、一瞬白く光る |
| 音   | 割れる音   | 割れる音とキラッの和音 | 割れる音とファンファーレ                       |

### 確定演出（割れる前）

- レア以上の品のカプセルは、転がり出たときに青く光り、キラキラの音が鳴る。
- 伝説の品があれば、ハンドルを回し終えたとたんに明かりが落ち、機械に金の稲妻が落ちて、カプセルが金に光って出てくる。
- 伝説の 4 回に 1 回は昇格にする。はじめは青く光り、押すと割れずに震えてひびが入り（「ピキッ」）、金に変わってから割れる。昇格するカプセルは稲妻の知らせに数えない。
- 10 連では、10 こ（昇格するものは青として数える）のいちばん高いレア度で、回すときの機械の揺れと稲妻を決める。

### 10 連

- 1 回回すと、カプセルが 10 こ続けて転がり出て、手前に 2 段で並ぶ。
- 押すと左から順に割れていき、レア以上と伝説のところだけ間を長く取る。押すと早送り、「とばす」で全部割れる。
- 最後に 10 この品をドット絵で並べ、名前とレア度を出す。

### 音

今の効果音と同じく、音の波の組み合わせで作る（録音した音は使わない）。ハンドルのカチカチ、転がるコロコロ、割れるポン、レアの和音、伝説のファンファーレ、稲妻、昇格のひび。段取りが出来事（`events`）を出し、画面がそれを音に換える。

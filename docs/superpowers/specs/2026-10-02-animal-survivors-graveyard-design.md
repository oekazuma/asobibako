# Animal Survivors 2 面め「夜の墓地」 設計

## ねらい

森だけだった Animal Survivors に 2 面め「夜の墓地」を足す。森をクリアしたあとの新しい目標と、色も敵も違う景色で、くり返し遊ぶ楽しさを広げる。遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い   | 決めたこと                                                                  |
| ------ | --------------------------------------------------------------------------- |
| 場所   | 夜の墓地（紫がかった暗い地面に墓石と枯れ木）                                |
| 選び方 | キャラ選択のあとに面を選ぶ画面。森を 1 度クリアすると選べる                 |
| 強さ   | 森より 1 段むずかしく（敵の体力と攻撃 1.3 倍、出る数も多め）、コイン 1.5 倍 |
| 敵     | おばけ・ガイコツ・ゾンビの 3 種。コウモリとクモは森の絵のまま出す           |
| ボス   | 5:00 かぼちゃ大王（女王グモの動き）、10:00 ガイコツの騎士（巨大ベアの動き） |
| 曲     | 墓地用の短調の 8 ビートを 1 曲。ボス戦の曲は今のもの                        |

## 1. 面を選ぶ

- キャラ選択で動物を選ぶと、面を選ぶ画面（`StageSelect.svelte`）に進む。「森」「夜の墓地」のカードを並べ、まだ行けない面は影にして「森をクリアすると行ける」と出し、押せない。
- 前に遊んだ面を記録（`Records.stage`）に覚え、選ばれた状態で出す。
- 面を選ぶ画面の左上の ✕ でキャラ選択へ戻る。
- 「もう一度」と「最初からやり直す」は同じ動物・同じ面で始める。

## 2. 面の表

- 面の表は `stages/` に面ごとのファイルで持ち（`forest.ts`・`graveyard.ts`）、`stages/index.ts` の `STAGES` が並べる。
- `Stage` に足すもの
  - `art`: 地面と飾りの絵の id（`'forest' | 'graveyard'`）
  - `coin`: コインに掛ける倍率（森 1、墓地 1.5）
  - `song`: 遊んでいるあいだの曲の id（森 `field`、墓地 `grave`）
  - `unlock`: 選べる条件の文（墓地「森をクリアすると行ける」）
- `createWorld(id, seed, view, ranks, stage = 'forest')` で面を選ぶ。
- 墓地の出現表は森の時刻の流れに合わせ、ネズミの代わりにおばけ、ヘビの代わりにガイコツ、イモムシの代わりにゾンビを出し、コウモリとクモはそのまま。`toughness` と `fury` は森の 1.3 倍、`cap` は 1.15 倍。
- 墓地の出来事

| 時刻  | 出来事               |
| ----- | -------------------- |
| 1:30  | おばけの大群が横切る |
| 3:00  | ガイコツの輪が迫る   |
| 4:30  | コウモリの大群       |
| 6:30  | ゾンビの輪           |
| 8:00  | おばけの大群         |
| 11:00 | コウモリの大群       |
| 12:30 | ガイコツの輪         |
| 14:00 | ゾンビの輪           |

- コインの倍率は `coinsOf(w)` が強欲と一緒に合計へ掛ける。
- ランタンは墓地でもそのまま出す。

## 3. 敵とボス

| id            | 名前           | 動き                   | 体力 | 速さ | 攻撃 | 経験値 |
| ------------- | -------------- | ---------------------- | ---- | ---- | ---- | ------ |
| `ghost`       | おばけ         | `wave`（ゆらゆら速い） | 8    | 52   | 6    | 1      |
| `skeleton`    | ガイコツ       | `chase`                | 26   | 36   | 11   | 3      |
| `zombie`      | ゾンビ         | `chase`（重い）        | 80   | 18   | 16   | 8      |
| `pumpkinling` | ちびかぼちゃ   | `chase`                | 10   | 46   | 7    | 1      |
| `pumpkin`     | かぼちゃ大王   | ボス（女王グモの動き） | 950  | 36   | 26   | 0      |
| `knight`      | ガイコツの騎士 | ボス（巨大ベアの動き） | 1300 | 30   | 26   | 0      |

- 敵の表に `ai`（`'bear' | 'queen'`）を足し、`bosses.ts` は `boss` ではなく `ai` で動き方を選ぶ。手下（`minion`）も表に持ち、女王グモは子グモ、かぼちゃ大王はちびかぼちゃを呼ぶ。
- ボスの id（`BossId`）に `pumpkin` と `knight` を足す。記録の倒したボスに入り、実績に使う。
- かぼちゃ大王の飛び道具は、糸の玉と同じ当たり方（足が遅くなる）で、絵をかぼちゃの種にする。

## 4. 絵

- 共通の色の表（`art/palette.ts`）に夜の地面の色を足す（今の色は変えない）。
- 地面は 16 ドットのタイル（芝 4 コマと土）、飾りは 5 種（墓石・十字の墓・枯れ木・ろうそく・骨）。
- 敵 3 種は 2 コマ、ちびかぼちゃは 2 コマ、ボス 2 体は森のボスと同じくらいの大きさ（ガイコツの騎士は 3 コマ目に剣を振り上げた地ならし）、かぼちゃの種。
- 見本は 2 回に分けて見せて止まる（地面・飾り・敵 3 種、そのあとボス 2 体・ちびかぼちゃ・種）。
- 描画は面の `art` から地面と飾りの絵と飾りの出方を選ぶ（`draw.ts` の `ground`）。

## 5. 曲

- `songs.ts` に墓地の曲 `grave` を足す（短調、8 ビートの `drive`、テンポ 132）。WAV で聞いてもらってからつなぐ（止まる）。
- `Survivors.svelte` は遊んでいる最中の曲を面の `song` から選ぶ。ボス戦の曲は今の `boss`。

## 6. 記録と実績

- 記録に `stages`（クリアした面の id）と `stage`（前に遊んだ面）を足す。古い保存は、`clears` が 1 以上なら森をクリアしたことにする。
- 墓地は `stages` に `forest` があると選べる。
- 実績を 2 つ足す（表の末尾）。「夜の墓地をクリア」（コイン 300）、「墓地の 2 体のボスを倒す」（コイン 200。`pumpkin` と `knight` の両方を倒したことがある）。
- 「15 分生き延びてクリア」「7 匹すべてでクリア」などは、どの面のクリアでも数える。

## 7. 確かめ方

- vitest で次を確かめる。
  - 墓地の表がそろっていること（出来事は時刻の順でボスの時刻を避ける、出現表の敵がどれも敵の表にある）。
  - 墓地の強さが森の 1.3 倍、コインが 1.5 倍になること。
  - 新しいボスが `ai` の動きで動き、手下と種を出し、倒すと記録と実績に入ること。
  - 墓地は森をクリアしてから選べること、古い保存の読み方、前に遊んだ面を覚えること。
- headless Chrome で、面を選ぶ画面・墓地の画面・ボス 2 体を撮る。
- ボットで、墓地の強化なしと全部最大の生存時間を測り、森より短いが 0 にならないこと。
- `pnpm verify` を通す。

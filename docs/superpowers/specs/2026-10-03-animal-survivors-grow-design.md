# Animal Survivors 育つ瞬間の溜め 設計

## ねらい

動物が Lv10 と Lv25 で育つとき、いまは光の粒と上の小さな帯だけで、遊びながらだと見逃しやすい。ゲームを少し止め、前の姿と新しい姿が入れ替わってはじける「進化した！」の瞬間を作り、名前の札で何が強くなったかを伝える。

遊ぶのは大人 2 人で、端末は iPad Air。

## 決めたこと

| 問い   | 決めたこと                                                                       |
| ------ | -------------------------------------------------------------------------------- |
| 止める | 約 2.6 秒止める（ボスの登場と同じく、そのあいだは当たらない）。終わってから 3 択 |
| 見せ方 | 体が白く光り、前の姿と新しい姿の白い影がだんだん速く入れ替わり、光がはじける     |
| 知らせ | 「子犬 → 勇者の犬」の札と、強くなったこと（攻撃 +10%・最大 HP +20・HP 全快）     |

## 1. 流れ

ゲームの時計は止まり、端末の時間で進む。

1. 0〜1.4 秒：まわりを暗くし、自分だけを照らす。前の姿と新しい姿の白い影が交互に入れ替わり、入れ替わりの間は 0.3 秒から 0.04 秒へ縮む。上がっていく音。
2. 1.4〜1.6 秒：白い光が自分からはじけ（輪と光の筋）、画面がうっすら白く光る。はじける音。
3. 1.6〜2.6 秒：新しい姿に戻り、名前の札を出す。暗さはだんだん戻る。

- 3 択（Lv10 と Lv25 のレベルアップ）や宝箱は、終わってから開く。経験値の袋や宝箱で育ったときは、開いている 3 択や宝箱を閉じてから始める。
- ボスの登場と重なったら、ボスの登場を先に見せる。
- 動きを減らす設定（`prefers-reduced-motion`）では、影の入れ替わりとはじける光を出さず、新しい姿と札だけを 1.2 秒出す。
- 今の上の帯「〜は〜に育った！」は札に置きかえる。

## 2. しくみ

| ファイル                                       | 変えること                                                            |
| ---------------------------------------------- | --------------------------------------------------------------------- |
| `prompts.svelte.ts`                            | 育つ演出の状態（`evolve`、端末の時間で進め、`busy` に含める）、出す順 |
| `grow.ts`（新）                                | 時間から、見せる姿（前か新しいか）・暗さ・はじける光の強さを返す      |
| `draw.ts`                                      | 暗さ、白い影の姿、はじける輪と光の筋                                  |
| `PromptLayer.svelte`・`GrowPlate.svelte`（新） | 名前の札                                                              |
| `effects.ts`・`sounds.ts`                      | 上がっていく音とはじける音（育ったときの光の粒はやめる）              |

## 3. 確かめ方

- vitest で次を確かめる。
  - 育つと演出が始まり、終わるまで `busy`。同じときのレベルアップの 3 択は、終わってから開く。
  - 経験値の袋で育ったときは、開いている 3 択を閉じるまで進まない。
  - ボスの登場と重なると、ボスの登場が先。
  - 見せる姿が、はじめは前と新しいで入れ替わり、入れ替わりの間が縮み、1.6 秒からは新しい姿だけ。
  - 動きを減らす設定では 1.2 秒で終わり、影の入れ替わりをしない。
  - 帯「〜に育った！」が出ない。
- headless Chrome で、影の入れ替わり・はじける瞬間・札を撮る。
- `pnpm verify` を通す。

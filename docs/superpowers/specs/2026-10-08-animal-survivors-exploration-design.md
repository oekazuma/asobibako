# アニマルサバイバー ステージの探索 設計

## 目的

ヴァンパイアサバイバーのように、ステージを歩き回る理由を足す。ステージごとに決まった場所に遺物を隠し、拾うとその後の回でずっと効く。野原には祠を立て、触れるとその回だけのご利益がある。

## 遺物

ステージごとに 2 つ、全部で 8 つ。

| ステージ | 遺物           | ずっと効くこと                                   |
| -------- | -------------- | ------------------------------------------------ |
| 森       | 古い地図       | 遠くにある、まだ拾っていない遺物にも矢印が出る   |
| 森       | 魔法のランプ   | 自分のまわりに灯るランタンが 1 つ増える（5 → 6） |
| 夜の墓地 | 古い懐中時計   | 時計の品で敵が止まる時間が 2 秒のびる            |
| 夜の墓地 | 銀の鈴         | 宝の地図の宝箱が 10 秒長く残る                   |
| 雪山     | 雪の結晶       | 1 回ごとに、3 択の引き直しが 1 回ふえる          |
| 雪山     | 氷の鏡         | 祠のご利益が 1.5 倍長く続く                      |
| 火山     | 炎の宝玉       | 宝箱の中身が 3 つ以上になる割合が 1 割上がる     |
| 火山     | 黒曜石のかけら | 溶岩の池と噴火の岩から受けるダメージが半分になる |

- 置き場所は、始めの位置から 1 つめが 700 ドットほど、2 つめが 1500 ドットほど離れたところ。向きはステージごとに決め、毎回同じ場所に置く。障害物の中には置かない。
- 上を歩けば拾える（宝箱と同じ）。拾うと「遺物を手に入れた！」の帯を出し、記録に入れる。拾ったあとの回には置かない。
- 記録には、倒れた回・やめた回でも、拾った時点で入れる（回の終わりを待たない）。
- 遺物から 400 ドットほどに入ると、画面の端にきらめく矢印を出す。古い地図を拾ったあとは、どの距離の遺物にも矢印を出す。古い地図は森の 1 つめ。
- ステージを選ぶ画面の札に「遺物 1 / 2」を出す。図鑑に遺物のタブを足し、まだのものは影で出す。
- ふたりで遊ぶときは、どちらが拾っても 2 人とももらえる（コインと同じ扱い）。
- 遺物の絵（地面に置いた姿と、図鑑のアイコン）は、使う前に見本を見てもらう。

## 祠

- 位置から決まる場所に立てる（障害物と同じ作り）。量は 160 ドットの区画 10 個に 1 つほど。始めの位置のまわりと障害物の上には置かない。ふたりで遊ぶときも 2 台で同じ場所。
- 触れるとその回だけのご利益があり、その祠は消える。その回のあいだは戻らない。
- 種類は場所で決まる 5 種。

| 祠       | ご利益                           |
| -------- | -------------------------------- |
| 力の祠   | 30 秒のあいだ攻撃 +30%           |
| 風の祠   | 30 秒のあいだ速さ +30%           |
| 知恵の祠 | 30 秒のあいだ、拾う経験値が 2 倍 |
| 宝の祠   | その場に宝箱が出る               |
| 癒しの祠 | HP が全快する                    |

- 時間のあるご利益は、HUD に印と残りの秒を出す。同じご利益が続けば残りの秒をのばす。氷の鏡があれば 1.5 倍長く続く。
- ご利益の時計は step の中で進めるので、3 択・一時停止・時計の品のあいだは止まる。
- ふたりで遊ぶときは、触れた動物にだけ効く。宝の祠の宝箱は触れた動物のもの。
- 絵は祠 1 つの形に、種類ごとの色の玉を載せる。使う前に見本を見てもらう。

## 確かめ方

- 遺物と祠の置き方（毎回同じ・始めの位置のまわりに無い・障害物の中に無い）と、拾う・触れる・効き目・記録への入り方を vitest で確かめる。
- ボットで、祠のある回とない回のクリアの割合を比べ、強すぎないかを見る。

# メガホンダッシュ 設計

背中側から見る 3D のランゲーム。3 レーンの通学路を学校まで走り、メガホンで通行人を撃ってファンにし、コンボで加速する。1 人用（`players: 1`）で 15 面、1 回は 1 分前後。

主役は走って撃つ手触りで、キャラの見た目は市販級を狙わない。人や物は丸や筒を組み合わせたデフォルメで、コードだけで作る。遊ぶのは子どもと大人の両方で、はじめの面は易しく、面が進むと手ごたえが出る。

入れないもの（あとで足せる）は、お店・着せ替え・場所の切り替わり（通学路から校舎へ）。

## ルール

### 1 面の流れ

家から学校まで 3 レーンの道を走る。制限時間内に校門へ着けばクリア、時間切れでしっぱい。5・10・15 面は校門の手前でボスと戦う。

### 操作

画面に触れた瞬間、いまのレーンの前へメガホンを撃つ（間隔は 0.25 秒以上）。触れた指をそのまま左右へ 30px ずらすと 1 レーン移り、ずらし続ければ続けて移る。上へ 30px ずらすと跳ぶ。指は 1 本ずつ別に見分けるので、片手でスワイプしながら反対の手で撃てる。撃ち外しても損はないので、スワイプで撃ってしまっても困らない。

### 通行人とコンボ

撃ち当てた通行人はファンになって後ろをついて走り（見えるのは 20 人まで）、フォロワーが増える。当て続けるとコンボが伸び、障害物にぶつかるか、当てずに通行人とすれ違うと切れる。速さはコンボで決まる。

| コンボ  | 速さ |
| ------- | ---- |
| 0〜4    | ×1.0 |
| 5〜9    | ×1.2 |
| 10〜19  | ×1.5 |
| 20 以上 | ×2.0 |

速いほど早く着き、残り時間が増える。

### 障害物

| 種類           | よけ方                           |
| -------------- | -------------------------------- |
| 低いバリケード | 跳ぶか、レーンを移る             |
| 高い柵・電柱   | レーンを移る（跳んでもぶつかる） |

ぶつかると 1 秒よろけて遅くなり、コンボが切れる。ライフはなく、時間を失うことが罰になる。

### ボス

前に浮かんだままレーンを移り、一定の間隔で障害物を投げる。ボスのあいだ通行人は出ない。同じレーンにいるときに撃つと当たり、速さの段階が高いほど多く減らせる。体力が 0 になると校門が現れる。制限時間は数え続ける。

### ランク

着いたら残り時間・フォロワー・最大コンボから S / A / B / C を出す。ゲームの中にランクのカードを 2 秒ほど見せてから `onfinish(true)` を呼ぶ。`SoloShell` と共通の結果画面には手を入れず、`ownResult` も使わない。しっぱいは `onfinish(false)` で共通の結果画面に任せる。

### 面ごとの難しさ

面が進むと、道のりが長くなり、通行人と障害物が増え、高い障害物と複数のレーンをふさぐ並べ方が出てきて、制限時間の余裕が減る。1〜2 面は跳ぶことを覚えるための低いバリケードだけにする。面ごとの数字は `course.ts` の表に持ち、ボットの走りで決める（確かめ方を参照）。

## ファイル

`src/lib/games/megaphone-dash/` に閉じ、ほかのゲームのファイルは import しない。雪原サバイバルの `mat()` のような小さな道具はこのフォルダに写す。

| ファイル               | 持つもの                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| `meta.ts`              | 一覧の情報と `load()`。`levels: 15`、`minutes: '1分'`                                      |
| `Howto.svelte`         | タイトルの遊び方（撃つ・移る・跳ぶの 1 行と凡例）                                          |
| `engine.ts`            | `createState(level)` と `step(state, dt, input)`。出来事を events で返す。ランクの計算     |
| `course.ts`            | 面ごとの数字の表と、面の番号から決まる乱数での並べ方                                       |
| `gesture.ts`           | 指 1 本ごとの、触れた・左右 30px・上 30px の見分け                                         |
| `MegaphoneDash.svelte` | `BoardInput`・`animate`・3D と重ね描きの canvas の配線。ランクを見せてから `onfinish`      |
| `Hud.svelte`           | 残り時間・コンボと速さの段階・フォロワー・ボスの体力                                       |
| `world3d.ts`           | three の場面。後ろ上の固定カメラ、区間を使い回して流す道と家並み、形を使い回す人と障害物   |
| `models.ts`            | 走る子（メガホン付き）、服の色違いの通行人、ファン、バリケード、柵、電柱、ボス、家並み、木 |
| `effects.ts`           | 重ね描きの canvas の「+47」・当たりの光・ランクのカード（`$lib/fx.ts` を使う）             |
| `sounds.ts`            | `$lib/audio.svelte` の `bus()` から鳴らすオシレータの効果音                                |

`engine.ts`・`course.ts`・`gesture.ts` は DOM も three も使わない。長さの単位はメートルで、画面の速さの表示（m/s）とそろえる。`engine` の入力は「撃つ」「左右へ移る」「跳ぶ」で、出来事は「撃った」「当てた」「逃した」「ぶつかった」「ボスに当てた」「ボスを倒した」「着いた」「時間切れ」。

ほかに触るのは、`src/lib/games.ts` への 1 行、`scripts/thumbs/scenes.ts` への場面 1 つ、`static/thumbs/megaphone-dash.webp`。

コンポーネントは 200 行未満に保つ。絵文字は使わず、アイコンは `$lib/icons.ts`。3D の準備（`compileAsync`）が済むまで走り出さない。

## 作る順番

1. `models.ts` と場面だけを作り、走る子・通行人・障害物・ボスを本番のカメラの角度から撮った見本を見せて、見た目の方向を確かめる。
2. `engine.ts`・`course.ts`・`gesture.ts` をテストと一緒に作る。
3. 画面をつなぐ。
4. ボットに走らせて、面ごとの制限時間を決める。
5. headless Chrome で遊ばせて撮り、確かめる。

## 確かめ方

### vitest

| ファイル          | 確かめること                                                                                                                                                                                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `gesture.test.ts` | 触れただけなら撃つだけ。左右 30px で 1 レーン、続けてずらすと続けて動く。上 30px で跳ぶ。2 本の指を別々に見分ける                                                                                                                                                                          |
| `engine.test.ts`  | 端のレーンより外へ出ない。同じレーンの通行人だけに当たる。コンボで速さの段階が変わる。ぶつかるか逃すとコンボが切れ、よろける。低いバリケードは跳べばよけられ、高い柵は跳んでもぶつかる。時間切れでしっぱい、校門でクリア。ボスは同じレーンのときだけ減り、0 で校門が出る。ランクのしきい値 |
| `course.test.ts`  | どの列にも通れるレーンが残る。1〜2 面は低いバリケードだけ。同じ面は毎回同じ道                                                                                                                                                                                                              |

### バランス

scratchpad の `*.sim.ts` で、うまいボット（全部当ててよける）と、ふつうのボット（反応を遅らせ、ときどき失敗する）に全 15 面を走らせる。ふつうのボットがぎりぎりクリアでき、うまいボットは S が取れ、1 面は遅いボットでもクリアできるように、制限時間を決める。

### 画面

playwright の headless Chrome で iPad Air の大きさにして遊ばせ、走る・撃って当てる・ボス・ランクのカード・横向きを撮る。1 フレームにかかる時間も測る。最後に `pnpm verify` を通す。

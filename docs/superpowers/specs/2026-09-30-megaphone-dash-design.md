# メガホンダッシュ 設計

背中側から見る 3D のランゲーム。3 レーンの通学路を学校まで走り、メガホンで通行人を撃ってファンにし、コンボで加速する。1 人用（`players: 1`）で 15 面、1 回は 1 分前後。

主役は走って撃つ手触りで、キャラの見た目は市販級を狙わない。人や物は丸や筒を組み合わせたデフォルメで、コードだけで作る。遊ぶのは子どもと大人の両方で、はじめの面は易しく、面が進むと手ごたえが出る。

入れないもの（あとで足せる）は、お店・着せ替え・場所の切り替わり（通学路から校舎へ）。

## ルール

下の数字（m・秒）は最初の値で、遊ばせて調整する。ふるまい（何が起きるか）は変えない。

### 1 面の流れ

家から学校まで 3 レーンの道を走る。制限時間内に校門へ着けばクリア、時間切れでしっぱい。5・10・15 面は校門の手前でボスと戦う。

3D の準備が済むまでは「じゅんびちゅう」を出し、走り出さず、制限時間も数えない。

### 走る・移る・跳ぶ

基本の速さは 5 m/s で、コンボの段階を掛ける。レーンは整数で持ち、移る操作をした瞬間に当たり判定も新しいレーンになる（絵だけ 0.15 秒かけて滑らかに寄せる）。端のレーンより外へは出ない。

跳ぶと 0.6 秒のあいだ空中にいる。空中でもレーンを移れ、撃てる。空中での上スワイプは無視する。

### 指の見分け

指 1 本ごとに、触れた位置を起点にして見る。

- 触れた瞬間に撃つ。
- 起点から横へ 30px ずれたら 1 レーン移り、起点をその向きへ 30px ずらす。ずらし続ければ続けて移る。
- 最初に触れた位置から上へ 30px ずれたら跳ぶ。跳ぶのは 1 回の指につき 1 回で、空中で無視された上スワイプもその 1 回に数える。
- 斜めは、ずれの大きい向きを取る。下へのずれは何もしない。

指の位置は、雪原サバイバルの仮想スティックと同じく毎フレーム `input.fingers.all` から読む。1 フレームのうちに終わる速いフリックは `BoardInput` の `up` で拾う。共通の `board-input.ts` には手を入れない。30px は盤面の中のピクセルで、`input.px()` で直して比べる。

### 撃つ

撃つ間隔は 0.25 秒以上。撃った瞬間に、いまのレーンの前方 15 m 以内でいちばん近い、まだファンでない通行人に当たる（弾が飛ぶのは見た目だけで、当たりはその瞬間に決まる）。いなければ外れで、損はない。スワイプの指で撃ってしまっても困らない。

### 通行人とコンボ

通行人はレーンの中をこちらへ 1 m/s で歩いてくる。撃ち当てるとファンになって後ろをついて走る（見えるのは 20 人まで）。1 人当てるたびにコンボが 1 伸び、フォロワーが「10 ＋ 2 × 伸ばしたあとのコンボ」増える（最初の 1 人は +12、18 人目は +46）。

コンボが切れるのは次の 2 つ。

- 障害物にぶつかる。
- 同じレーンにいるまま、ファンでない通行人とすれ違う。通行人はよけてくれるので、ぶつからずにすり抜ける。

ほかのレーンの通行人とのすれ違いでは切れない（取り逃がすだけ）。レーンを移って追うと、フォロワーとコンボが増える。

速さはコンボの段階で決まる。

| コンボ  | 速さ |
| ------- | ---- |
| 0〜4    | ×1.0 |
| 5〜9    | ×1.2 |
| 10〜19  | ×1.5 |
| 20 以上 | ×2.0 |

速いほど早く着き、残り時間が増える。

### 障害物

| 種類           | よけ方                           |
| -------------- | -------------------------------- |
| 低いバリケード | 跳ぶか、レーンを移る             |
| 高い柵・電柱   | レーンを移る（跳んでもぶつかる） |

ぶつかると 1 秒よろけ、そのあいだ速さは ×0.3 になり、コンボが切れる。よろけているあいだも撃てて、移れる。1 つの障害物にぶつかるのは 1 回だけで、ぶつかったものはすり抜ける。よろけているあいだに別の障害物にぶつかったら、1 秒を数え直す。ライフはなく、時間を失うことが罰になる。

障害物の列どうしは 10 m 以上あける。どの列にも通れるレーンが 1 つ以上残る。

### ボス

ボスは道のりの終わり（`course.ts` の表で持つ位置）で現れ、20 m 先に浮かんで、走る子と同じ速さで前へ進む（こちらは走り続ける）。ボスのあいだ通行人は出ない。ボスは一定の間隔でレーンを移り、いまいるレーンへ障害物を投げる。障害物は走る子の 12 m 前に落ち、落ちる 1.5 秒前からその場所に印を出す。

同じレーンにいるときに撃つとボスに当たり、コンボが 1 伸びる。減る体力は速さの倍率（1 / 1.2 / 1.5 / 2）。投げられた障害物にぶつかるとコンボが切れる。体力が 0 になるとボスは去り、30 m 先に校門が現れる。制限時間は数え続ける。

ボスの体力・レーンを移る間隔・投げる間隔・投げる障害物の種類は、面ごとに `course.ts` の表に持つ。5 面は低いバリケードだけ、10 面から高い柵も投げ、15 面は間隔が短い。

### ランク

着いたら点を出す。

点 ＝ フォロワー ＋ 残り秒 × 20 ＋ 最大コンボ × 10

しきい値は面ごとに `course.ts` の表に持つ。うまいボットの点に対して、S は 90% 以上、A は 70% 以上、B は 50% 以上、それより下は C。

ゲームの中にランクのカードを 2 秒見せてから `onfinish(true)` を呼ぶ。時間切れのときは「じかんぎれ」を 1 秒見せてから `onfinish(false)` を呼び、共通の結果画面に任せる。`SoloShell` と共通の結果画面には手を入れず、`ownResult` も使わない。どちらのタイマーも、画面を閉じたときに `clearTimeout` する。

### 面ごとの難しさ

面が進むと、道のりが長くなり、通行人と障害物が増え、高い障害物と複数のレーンをふさぐ並べ方が出てきて、制限時間の余裕が減る。1〜2 面は、跳ぶことを覚えるための低いバリケードだけにする。面ごとの数字は `course.ts` の表に持ち、制限時間とランクのしきい値はボットの走りで決める（確かめ方を参照）。

## ファイル

`src/lib/games/megaphone-dash/` に閉じ、ほかのゲームのファイルは import しない。雪原サバイバルの `mat()` のような小さな道具はこのフォルダに写す。

| ファイル               | 持つもの                                                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `meta.ts`              | 一覧の情報と `load()`。`levels: 15`、`minutes: '1分'`                                                                      |
| `Howto.svelte`         | タイトルの遊び方（撃つ・移る・跳ぶの 1 行と凡例）。アイコンは `icons.ts` にある `tap`・`arrow`・`kid`                      |
| `engine.ts`            | `createState(level)` と `step(state, dt, input)`。出来事を events で返す。点とランクの計算                                 |
| `course.ts`            | 面ごとの数字の表と、面の番号から決まる乱数での並べ方                                                                       |
| `gesture.ts`           | 指 1 本ごとの、触れた・左右 30px・上 30px の見分け                                                                         |
| `MegaphoneDash.svelte` | `BoardInput`・`animate`・3D と重ね描きの canvas の配線。ランクを見せてから `onfinish`                                      |
| `Hud.svelte`           | 残り時間・コンボと速さの段階（m/s も添える）・フォロワー・ボスの体力                                                       |
| `director.ts`          | engine の出来事を、3D・重ね描き・音へ振り分ける                                                                            |
| `world3d.ts`           | three の場面。後ろ上の固定カメラ、区間を使い回して流す道と家並み、形を使い回す人と障害物、メガホンから飛ぶ音の輪、ボスの印 |
| `models.ts`            | 走る子（メガホン付き）、服の色違いの通行人、ファン、バリケード、柵、電柱、ボス、家並み、木                                 |
| `effects.ts`           | 重ね描きの canvas の「+46」・当たりの光・ランクのカード（`$lib/fx.ts` を使う）                                             |
| `sounds.ts`            | `$lib/audio.svelte` の `tone` / `sweep` / `noise` で鳴らす効果音（雪原サバイバルと同じ）                                   |

`engine.ts`・`course.ts`・`gesture.ts` は DOM も three も使わない。長さの単位はメートルで、画面の速さの表示（m/s）とそろえる。`engine` の入力は「撃つ」「左右へ移る」「跳ぶ」で、出来事は「撃った」「当てた」「逃した」（同じレーンですれ違ってコンボが切れたときだけ）「ぶつかった」「ボスに当てた」「ボスを倒した」「着いた」「時間切れ」。

ほかに触るのは、`src/lib/games.ts` への 1 行、`scripts/thumbs/scenes.ts` への場面 1 つ、`static/thumbs/megaphone-dash.webp`。

コンポーネントは 200 行未満に保つ。出来事の振り分けを `director.ts` に出し、`MegaphoneDash.svelte` は配線だけにする。絵文字は使わない。HUD の大きさは `cqh` / `cqw` で書き、3D と重ね描きの大きさは `BoardInput` の盤面そのものの大きさ（`offsetWidth` / `offsetHeight`）から取る（横向きで回したときのため）。Svelte の状態に載せるのは変化の少ないもの（コンボ・フォロワー・ボスの体力）と、0.1 秒ごとに間引いた残り時間で、走る子や人の位置はループが three に直接書く。3D の準備は、わんにゃんハウスの `world3d.ts` の `precompile()` と同じく `renderer.compileAsync` を待つ。

## 作る順番

1. `models.ts` と場面だけを作り、走る子・通行人・障害物・ボスを本番のカメラの角度から撮った見本を見せる。ここで作業を止め、ユーザーが見た目の方向を認めてから次へ進む。
2. `engine.ts`・`course.ts`・`gesture.ts` をテストと一緒に作る。
3. 画面をつなぐ。
4. ボットに走らせて、面ごとの制限時間とランクのしきい値を決める。
5. headless Chrome で遊ばせて撮り、確かめる。

### バランス

scratchpad の `*.sim.ts` で、4 つのボットに全 15 面を走らせる。

| ボット     | 走り方                                  |
| ---------- | --------------------------------------- |
| うまい     | 当てられるものは全部当て、全部よける    |
| ふつう     | 反応を 0.3 秒遅らせ、ときどき失敗する   |
| ゆっくり   | 反応を 0.6 秒遅らせ、撃つのは半分くらい |
| はしるだけ | 反応を 0.6 秒遅らせ、撃たずによけるだけ |

ふつうのボットがぎりぎりクリアでき、うまいボットが全面を通れて S を取れ、1 面はゆっくりのボットと、撃たずに走るだけのボットでもクリアできるように、制限時間を決める。ランクのしきい値は、うまいボットの点から出す。

### 画面

playwright の headless Chrome で iPad Air の大きさにして遊ばせ、走る・撃って当てる・ボス・ランクのカード・横向きを撮る。1 フレームにかかる時間も測る。最後に `pnpm verify` を通す。
